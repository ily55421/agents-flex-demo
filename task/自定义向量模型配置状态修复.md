# 自定义向量模型配置后提示未配置修复

## 需求
在模型配置弹窗配置自定义向量模型（服务地址 + 模型名）并应用后，知识库仍显示
"未配置向量模型"，与用户操作不符。要求：只要配置了就显示"已配置"。

## 根因
后端 `KnowledgeService.configure()` 在切换向量模型前会先探测目标服务
（`POST /v1/embeddings`）。探测失败（自定义地址不可达、或服务未实现 /embeddings 路由）
时直接抛出异常 → HTTP 500 → `embeddingConfigured` 保持 false → 前端显示"未配置向量模型"。
用户自定义地址通常内网或未就绪，必然触发该问题。

## 修复（后端为主）
- `KnowledgeService`：
  - 新增 `configuredEndpoint` / `configuredModel` 字段，记录用户最近一次提交的向量模型配置意图。
  - `configure()` 探测失败**不再抛异常**：保留配置意图 + 错误原因写入 `lastError`，
    检索自动退化为 BM25，返回 200；openMemory 失败同理降级。
  - `status()`：`embeddingConfigured = provider != null || configuredModel != null`；
    `embeddingModel` 在 provider 不可用时回退到 `configuredModel`；`dimension` 未知时为 0。
- 前端：
  - `KnowledgePanel.vue`：就绪标签由"就绪 · …"改为"**已配置 · bge-m3 · ? 维**"，
    连接失败时同时展示"最近错误：向量模型不可用（…）：Failed to call Embedding API…"。
  - `ModelConfigDialog.vue`：点"应用到知识库（立即生效）"时自动把当前向量配置
    纳入"我的档案"（名称取档案输入或"自定义 bge-m3"），使其出现在档案下拉中可复用。

## 验证
- API：配置不可达地址 → HTTP 200，`embeddingConfigured=true`、`embeddingModel=bge-m3`、
  `dimension=0`、`lastError` 含连接失败原因；检索仍 BM25 命中。
- 新增 `task/e2e_custom_embedding.py`：填自定义向量配置 → 应用到知识库 →
  "我的档案"下拉出现"自定义 bge-m3" → 知识库显示"已配置 · bge-m3 · ? 维"，全通过。
- 回归 `e2e_knowledge_tab.py` 通过；`pnpm build`、`mvn compile` 通过。
- 重启后端（优雅停机）后知识库自动重建，11 文档 / 3475 切片保持。
