# 知识库文档预览查看与编辑及向量数据刷新

## 需求
支持知识库文档的文本预览查看与调整修改；修改保存后自动重新切片并向量化，检索立即使用新内容。

## 后端改动
- `KnowledgeDocumentStore.java`
  - 新增 `content VARCHAR` 列及 `ALTER TABLE` 迁移（`ensureSchema` 按需补列）。
  - `insert()` 改为 8 列写入（含 content）；新增 `update(docId,title,chunkCount,charCount,signature,content)` 与 `loadContent(docId)`。
- `KnowledgeService.java`
  - 新增 `getDocumentContent(docId)`：返回 docId/title/content/contentAvailable/chunkCount/charCount/source；
    旧版本（content 列迁移前）导入的文档 content 为空时标记 `contentAvailable=false` 而不是报错。
  - 新增 `updateDocument(docId,title,content)`：删除旧 namespace 全部向量切片 → 按新文本重新切片 → 逐片写入向量与元数据 → checkpoint → 更新 DuckDB 元数据与全文；写入失败时回滚并抛出异常。
  - 新增 dirty 标记机制：`initialize()` 写 `.dirty`、`shutdown()` 清除；残留标记时隔离疑似损坏的 `knowledge-mem.mem`，避免 JVM 崩溃。
- `KnowledgeController.java`
  - 新增 `GET /api/knowledge/documents/{docId}`（预览）与 `PUT /api/knowledge/documents/{docId}`（编辑保存，body 为 title/content）。
  - 上传扩展名列表加入 `.jsonl`，jsonl 走问答事实库导入。
  - `/search` 支持 namespace 限定。
- `WebConfig.java`
  - CORS `allowedMethods` 增加 `PUT`（此前只有 GET/POST/DELETE/OPTIONS，导致编辑保存 403）。

## 前端改动
- `frontend/src/api/agent.ts`：新增 `knowledgeApi.getDocument`（content 可为 null + contentAvailable）、`knowledgeApi.updateDocument`；`search` 增加 namespace。
- `frontend/src/components/KnowledgePanel.vue`
  - 文档清单每行新增"预览"按钮（眼睛图标），与删除并列。
  - 新增预览/编辑模态框（`<Teleport to="body">`）：标题输入、正文 textarea（预览只读 / 编辑可写）、来源/片数/字数元数据、错误提示、"编辑 / 取消 / 保存并重新向量化 / 关闭"按钮。
  - 旧文档（contentAvailable=false）打开时直接进入编辑态并显示"未保存原始全文"提示，可粘贴新内容覆盖保存。

## 验证

- 新增 `task/e2e_doc_preview_edit.py`：旧文档降级、新文档只读预览、编辑保存、原文刷新、检索命中、清理，ALL PASS。
- 回归：`e2e_knowledge_tab.py`、`e2e_chat_page.py` 全部通过。

## 遇到的问题与修复
1. 旧 23 篇文档 content 列为 NULL（迁移前入库），且 RogueMemory 无按 namespace 枚举切片的 API，无法重建原文 → 后端返回 `contentAvailable=false`，前端降级为直接可编辑态 + 提示重新粘贴或删除重导。
2. 编辑保存返回 403 → `WebConfig` CORS 缺少 `PUT`，已补齐。
3. BM25 对无空格中英数字混合串分词不命中（e2e marker 使用 UUID 片段导致）→ 测试 marker 改用中文自然关键词；真实检索不受影响。
