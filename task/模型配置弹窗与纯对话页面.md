# 模型配置弹窗与纯对话页面

- 日期：2026-09-11
- 类型：功能开发（前端重构 + 后端接口新增）
- 设计文档：`docs/superpowers/specs/2026-09-11-chat-page-model-dialog-design.md`

## 一、需求

1. 模型不能只有预设，必须支持**自定义配置**
2. **优化左侧布局**，模型配置改为**弹窗**
3. 新增**纯对话页面**（在“创建 Agent 工作台”之外，可选择智能体直接对话）

## 二、实现

### 后端（新增接口）
- `ShowcaseRuntime.listAgents()`：合并进程内 `agents` 与 DuckDB 归档 `archivedAgents`，按 agentId 去重、createdAt 倒序；每个视图带 `runnable` 标记（进程内可运行为 true，仅归档为 false）
- `AgentDefinitionController` 新增 `GET /api/agent/agents` → 安全视图列表（**不含 modelApiKey**，已实测确认）
- 修复：补 `LinkedHashMap` 导入

### 前端
- **ModelConfigDialog.vue（新）**：聊天模型 / 向量模型双 Tab 弹窗
  - 顶部预设快捷填充（5 聊天 + 5 向量预设，含 BGE-M3 本地网关/Ollama/Xinference、OpenAI、百炼）
  - 中部**全部字段自由编辑**（服务商/地址/路径/Key/模型/温度/思考/种子/TopP/TopK/MaxTokens/停止序列/Usage/重试/响应格式；向量为地址/模型/Key/检索模式）
  - 底部“另存为档案”（localStorage，同名覆盖）+ 选中档案可删除 + 取消/应用
  - 向量 Tab 内保留**「应用到知识库（立即生效）」**入口（弹窗化时差点丢失，已补回）
- **ChatHome.vue（新）**：纯对话页
  - 智能体下拉（`runnable` 可选 / 归档分组 disabled 并提示需重新创建）+ 刷新
  - 复用 ChatWorkspace、EventStream、动态表单、审批、挂起恢复、结果与预算/压缩/重试面板
  - 空状态引导“去工作台创建”
- **App.vue**：顶部 Tab（Agent 工作台 / 纯对话），`?view=chat` URL 同步与刷新恢复
- **TaskComposer.vue**：移除常驻“模型连接”“向量模型”两大表单组（约 150 行），改为模型摘要卡片（聊天/向量一行）+「⚙ 配置模型」按钮；“执行与上下文”改为默认折叠
- **style.css**：`.page-tabs`、`.chat-shell`、`.model-config-card` 等样式；app-shell 增加 46px Tab 行
- 删除被弹窗取代的 `ModelProfileBar.vue`

## 四、附带发现与处理

1. **归档 Agent 不可直接对话**：重启后 Runner/ChatMemory/API Key 均不重建。用 `runnable` 标记 + 前端 disabled 分组 + 明确文案解决，避免用户选择后收到“Agent not found”。
2. **BGE-M3 接入状态**（回答上一轮提问）：后端知识库当前为 `embeddingConfigured=false`、签名 `KEYWORD_ONLY`，即**尚未真正接入**；本地 18888 网关对 `/v1/embeddings` 与 `/embeddings` 均返回 `Cannot POST`（该服务未实现 embeddings 路由）。需在弹窗中配置一个真正提供 OpenAI 兼容 `/embeddings` 的服务（如 Ollama `http://localhost:11434/v1` + `bge-m3`）后点“应用到知识库”，状态变为 HYBRID + 维度 1024 才算接入成功。
3. 旧 `e2e_knowledge.py` 因档案下拉被弹窗取代而失效，已改为走弹窗选择器；BASE 端口写死问题一并修正为 5173。
