# 加强对话页视觉层次（宽屏可见的一轮）

日期：2026-09-19　提交：`252b520`　范围：仅 `frontend/src/style.css`，16 增 16 删

## 为什么做这一轮

用户连续两次反馈「页面啥变化没有」。核对后确认：前两轮（S1 令牌与窄屏、A 归档会话、B 知识库页）的产物在用户约 2000px 宽屏的默认落地页上**基本不可见** —— 归档态要点历史会话才出现、折行只在窄屏、色值与字号回迁肉眼无差。经确认，用户要的「有变化」= **加强视觉层次（不换风格）**，验收方式 = 打开内置浏览器让我截图对比。

## 直接原因

- `--shadow` 只有 `0 8px 24px rgba(30,54,39,.07)` 单层且极淡，`--border #d9e2dc` 也很浅 → 卡片边界含混、像浮在灰底上。
- 面板主标题 16px/650 与正文 14px 差不到一档 → 扫视时找不到层级锚点。
- 卡片内边距 15px、栏间距 14px → 间隙与内边距几乎相等，没有层次。
- 选中 Tab 只变色不变形 → 当前页不显眼。

## 改了什么（配色与风格不变）

| 项 | 前 | 后 |
| --- | --- | --- |
| `--shadow` | `0 8px 24px rgba(30,54,39,.07)` | `0 1px 2px rgba(30,54,39,.06), 0 10px 26px rgba(30,54,39,.09)` |
| `.section-heading h2` | 16px / 650 | `--font-heading` 18px / 700 + `letter-spacing: -.01em` |
| 卡片内边距 | 15px | `--space-5` 18px（含会话面板 `13px 15px 9px` → `18px 18px 10px`） |
| 三栏与左栏间距 | 14px | 16px（刻意小于内边距形成层级） |
| 选中 Tab | 仅变色 | 增加 `inset 0 2px 0 var(--accent)` 顶边；hover 加浅底 |
| 对话页空状态 | 头像 50px、标题 22px、说明 14px | 56px、28px、16px |
| 会话标题 | 13px | 14px（列表是左栏主内容，原先比说明文字还小） |
| 事件流标题 | 12px | 13px（摘要行上间距 5→4px 以适配固定行高 62px） |
| 指标数值 | 14px | 16px |
| 对话页头部副文案 | 12px | 13px |

## 验证

`pnpm typecheck` 通过、`pnpm build` 成功（1m44s）。浏览器实测计算值：面板内边距 `18px 18px 10px`、面板标题 `18px/700`、卡片阴影双层、选中 Tab `rgb(8,120,88) 0 2px 0 inset`、会话标题 14px、空状态标题 28px、头像 56px；**横向溢出元素 0 个**、`body.scrollHeight 748 === innerHeight 748`（无双滚动条）。
