# 修复归档会话打不开并完成知识库页令牌回迁

日期：2026-09-19　提交：`951b3b1`（A：归档会话）、`f76c657`（B：知识库页）

## A. 归档会话打不开（根因与上一轮的猜测不同）

**根因**（用一对请求实测确认）：后端重启后进程内已无 Runner。
- `GET /api/agent/runs/{id}` → **200**，`ShowcaseRuntime.get()` 有 DuckDB 归档回退，返回 23 条消息；
- `GET /api/agent/runs/{id}/trace` → **409**，`trace()` 只查内存 `requireRun()`，**没有归档回退**；
- 前端 `openRun()` 用 `Promise.all([get, trace])`，trace 一失败整次打开被丢弃 → 会话看起来"打不开"，列表却仍在。

**改动**
| 文件 | 改动 |
| --- | --- |
| `ShowcaseRuntime.java` | `trace()` 命中归档快照时返回只读视图；`get()` 的归档视图补 `archived=true` |
| `RunViewMapper.java` | 新增 `archivedTrace(snapshot)`：与 `trace()` 同构，spans/metrics 置空，token 与时长取自快照 `budget`，事件时间线原样带出；`budgetNumber()` 缺失时回落 0 防前端 null |
| `types/agent.ts` | `AgentRun`、`TraceView` 增加可选 `archived` |
| `useAgentRun.ts` | `connectionState` 增加 `archived`；打开归档会话不再建 SSE（否则反复 409 重连） |
| `AppHeader.vue` | 新增「只读归档」状态标签 |
| `ChatWorkspace.vue` | 归档会话禁用输入并说明「进程内已无执行器，只能回看不能续聊」；占位提示引导「新建会话」 |
| `TraceViewer.vue` / `style.css` | 归档说明条（warning 容器）+ 空态文案区分「未随快照归档」与「等待导出」 |
| `.gitignore` | `runtime/` → `/runtime/`：未锚定时会连带忽略 `src/**/runtime/` 源码包，新增单测文件时被静默忽略才发现（`deploy/runtime/` 有独立规则，不受影响） |

**验证**
- 新增 `RunViewMapperArchivedTraceTest`：`tests="2" errors="0" failures="0"`（有 budget / 无 budget 两种快照）。
- 接口：详情 `http=200 archived=true messages=23`；trace 由 409 → `http=200 archived=true spans=0 events=2836 totalTokens=58135 durationMs=40544`。
- 后端重启后在真实浏览器打开 9-11 的归档会话：`messages=6`、头部「只读归档」(`data-state=archived`)、输入框 `disabled` 且两条中文提示生效、无错误 toast、事件流 15 条；链路面板说明条显示、空态为「该会话的链路片段未随快照归档」、头部统计取到归档值（863 token / 85.63 s）。
- `pnpm typecheck` 退出 0、`pnpm build` 成功。

## B. 知识库页（S3 剩余项）

- **51 处硬编码 hex 全部回迁令牌**，`grep -c "#[0-9a-f]"` 归零；蓝色 chip（`#1d4ed8/#eff6ff/#bfdbfe`）降为中性，不引入第二套信息色；进度条四态映射为 `--retry/--success/--danger/--border-strong`；软边框沿用全局 `color-mix(...)` 写法。
- **字号与圆角**：`10.5/11/11.5/12/12.5/13/14px` 归到七档标尺（消除违反「不低于 11px」约定的 10.5px），`999/12/8/4px` 圆角归到 `--radius-pill/lg/sm`。
- **窄屏挤压**：检索行与建库行由不换行 flex 改为 `flex-wrap` + `flex-basis`，装不下整块折行。554px 实测：检索行分两行，控件宽 190/276/56/323/79px（此前 placeholder 只剩两个字）；建库行 190/190/78px 同行不挤压。
- **FAQ 面板**：去掉 `v-if="selectedKb !== 'all'"` 整块隐藏，改为常显 + 「先在上方选择具体知识库」指引。实测两种状态：全部库 → 显示指引无表单；默认知识库 → summary 变「FAQ 问答条目（0）」、标准问/答案/新增按钮齐全、空态提示正确。

**刻意未做**：chip / modal 抽成全局基元（回归风险大于收益）；媒体查询方案改用 flex-wrap 达成同等窄屏表现。
