# 启动脚本生成与前后端启动

- 日期：2026-09-11
- 类型：脚本开发 + 服务启动验证

## 一、新增启动脚本（项目根目录）

| 脚本 | 用途 |
| --- | --- |
| `start-all.ps1` | 一键启动：检查 java/mvn/node/pnpm → 检查 8080/5173 端口 → 缺依赖先 pnpm install → 分窗口启动前后端 |
| `start-backend.ps1` | 单起后端：JDK/Maven 检查 + 8080 端口检查 + `mvn spring-boot:run` |
| `start-frontend.ps1` | 单起前端：Node/pnpm 检查 + 5173 端口检查 + 缺 node_modules 自动 install + `pnpm dev` |
| `start-all.bat` | 双击入口，调用 start-all.ps1 |
| `start-all.sh` | Linux/macOS 一键启动（后台运行 + logs/ 日志 + 输出 PID 供停止） |

端口冲突防护：三个脚本启动前都用 `Get-NetTCPConnection`（回退 netstat）检测端口占用，被占用时明确报错退出，避免误杀其他进程。

## 二、启动验证（实测）

- 执行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\start-all.ps1` 成功
- 后端 8080 LISTENING，`/api/agent/runs/model` 返回 200
- 前端 5173 LISTENING，`/` 返回 200
- 两个服务保持运行中，浏览器访问 http://127.0.0.1:5173
