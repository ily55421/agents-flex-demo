# 前端统一中文界面并修复事件流、工具入参、链路面板三处可读性

## 用户要求

在上一轮可见改进之后，指定「做这三个，统一全中文」：事件流英文标题、工具调用参数单行截断、链路面板在右栏被横向截断；并把界面文案统一为中文。

## 改了什么

### 1. 事件类型中文标题（覆盖全部枚举）
- 用 `javap` 从 `agents-flex-agent-2.2.9.jar` 导出 `com.agentsflex.agent.event.AgentEventType` 的 **31 个**枚举值，逐条建中文映射（轮次开始 / 步骤完成 / 模型请求开始 / 模型思考增量 / 工具调用完成 / 等待工具审批 / 快照已保存 / 预算耗尽 …）。
- 落在新模块 `src/utils/eventLabels.ts`（`EVENT_LABELS` + `eventLabel()`），**EventStream 与 TraceViewer 共用**：原先两处各有一份英文转换（`label()` 转 Title Case、`title()` 把下划线换空格），现在都走同一映射，未知类型仍回退 Title Case，升级新增枚举不会出现空白标签。
- 顺带中文化：面板标题 `Agent Event Stream`→`Agent 事件流`、详情字段 `Run/Event/Source`→`运行/事件/来源`、摘要兜底 `phase=n/a`→`阶段：无`。

### 2. 工具调用入参多行
`ChatWorkspace.vue` 的 `<code>{{ JSON.stringify(tool.arguments) }}</code>`（被 CSS `text-overflow: ellipsis` 截成一行）改为 `<pre class="tool-args">{{ JSON.stringify(tool.arguments, null, 2) }}</pre>`，配 `white-space: pre-wrap`、`overflow-wrap: anywhere`、`max-height: 180px` 可滚，`.tool-call-row` 由三列改两列让参数独占一行。

### 3. 链路面板横向截断
`style.css`：`.chat-trace-content .trace-viewer` 的 `min-width: 720px` → `0`；`.trace-row > button` 与 `.lifecycle-list div` 的列宽 `minmax(170px,1fr) minmax(100px,.7fr)` → `minmax(0,1fr) minmax(0,.7fr)`（四列硬下限之和原本已超过右栏 420px）。

### 4. 界面文案统一中文
`Execution Trace`→执行链路、`Lifecycle events`→生命周期事件、`Trace ID/Span ID/Parent/Status/Model/Tokens/Arguments/Result/Output`→链路 ID/片段 ID/父片段/状态/模型/Token 数/入参/结果/输出、`ROOT`→根节点、`in / out`→输入/输出、`MODEL REQUESTS/TOOL CALLS/TOOL ERRORS/EXPORTED SPANS`→模型请求/工具调用/工具错误/已导出片段、`HUMAN APPROVAL REQUIRED`→需要人工审批、`Action/Risk/Policy`→操作/风险/审批策略、`Budget Control/NATIVE/Demo Projection`→预算控制/原生/演示估算、`Message Compression/Before/Model Context/estimated tokens`→消息压缩/压缩前/压缩后/估算 token、`Persistent Retry/Attempt N/Last Error`→持久重试/第 N 次/最近错误、`AGENTS-FLEX FORM INPUT`→Agents-Flex 表单输入、`NEXT SAFE CHECKPOINT`→下一个安全检查点、`Agent Runtime Showcase/RUN`→Agent 运行时演示/运行、`JSON Object`→JSON 对象、思考协议占位 `none`→留空使用服务端默认、对话页 `Trace`→链路。

**未译（刻意保留）**：`Agents-Flex`、`Agent`、`OpenTelemetry`、`JSON`、`Token`、`Markdown/Mermaid`、模型名与 URL、后端枚举值本身（如状态 `OK/ERROR`、`phase` 值）。改完后复扫模板，剩余纯英文可见文本仅 `Agents-Flex` 与事件详情的 `Agent` 字段名两处。
