# 模型预算可配置与默认值调大

- 日期：2026-09-12
- 类型：功能增强（模型随时可改 + 输出/上下文预算弹窗化 + 默认值调大）
- 触发：用户反馈"模型还需要可以更改，我需要修改上下文大小，输出现在只有 4000 太少了"

## 一、问题

1. Agent 创建后进入"已就绪"锁定态，「配置模型」按钮被禁用——**模型无法更改**
2. 输出预算默认 `maxOutputTokens=4000`（输入/总也是 4000），长回答直接触发 BUDGET_EXCEEDED（截图中"预算终止"会话即此原因）
3. Token 预算字段藏在左栏"预算控制"折叠组里，与模型配置割裂

## 二、修改

### 预算进入模型配置体系
- `ModelProfile` 类型与 `UpdateModelRequest` 新增 4 字段：`maxInputTokens` / `maxOutputTokens` / `maxTotalTokens` / `maxAttachedTokens`
- `ResearchAgentFactory.applyModelConnection` 同步这 4 项（非空覆盖）
- **弹窗聊天模型 Tab 新增"输出与上下文预算"分组**：输出 / 输入 / 总 / 上下文挂载 4 个输入框（0 表示不限），帮助文案说明 BUDGET_EXCEEDED 与丢历史时如何调整
- 左栏模型摘要卡片新增第三行"预算：输出 X / 总 Y Token"，改后一眼可见

### 默认值调大
- `maxInputTokens: 4000 → 16000`
- `maxOutputTokens: 4000 → 8192`
- `maxTotalTokens: 4000 → 32000`
- `maxAttachedTokens: 0`（保持不限，由模型窗口决定）
- 注意：仅影响**新创建**的 Agent；浏览器 localStorage 已存旧值的用户需在弹窗中手动调整或清除

### 已就绪状态也能改模型
- TaskComposer 新增 `dialogLocked = busy`（仅请求进行中禁用弹窗），与表单 locked 解耦
- 「配置模型」按钮在已有会话时仍可点击；改完模型/预算点「重新配置 Agent」→「创建 Agent」生成新 Agent 生效（旧 Agent 与历史会话不受影响）

## 三、验证（全部通过）

- `mvn test` 81 全绿；`pnpm build` 通过
- E2E `e2e_budget_update.py`：已就绪状态配置按钮可用 → 弹窗改预算（输出 8192→20000、输入→32000、总→64000）→ 应用后摘要即时反映 → 重新创建 Agent → **后端新 Run budget.tokenLimit=64000 实测确认**（此前 4000）
- 回归：纯对话页 E2E 13 项、知识库 E2E 7 项全过
- 说明：E2E 中 Run 状态 FAILED 为本机 Ollama 响应问题（模型未拉取），与预算改动无关，预算值在 Run 创建时即已生效

## 四、用户操作

已就绪状态：⚙ 配置模型 → 聊天模型 Tab 底部"输出与上下文预算"改数值（如输出 8192→20000，或填 0 不限）→ 应用配置 → 重新配置 Agent → 创建 Agent → 新会话按新预算执行。
