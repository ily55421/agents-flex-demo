## 一、Java 基础

- **Java 跨平台原理**：编译成字节码（.class），由 JVM 解释执行，不同平台有不同 JVM。
- **JVM、JDK、JRE 区别**：JVM 运行字节码；JRE = JVM + 核心类库；JDK = JRE + 开发工具。
- **重载与重写**：重载（参数列表不同，编译期多态）；重写（子类覆盖父类方法，运行期多态）。
- **`==` 与 `equals`**：`==` 比较引用（基本类型比较值）；`equals` 默认同 `==`，可重写（如 String 比较内容）。
- **String、StringBuilder、StringBuffer**：String 不可变；StringBuilder 可变非线程安全；StringBuffer 可变线程安全。
- **接口与抽象类**：抽象类可有构造方法、成员变量；接口（JDK8+）可有默认/静态方法，多实现。
- **final、finally、finalize**：final 修饰类/方法/变量；finally 异常处理块；finalize 对象回收前调用（已弃用）。
- **异常体系**：Throwable -> Error（不可恢复）和 Exception（可处理）；RuntimeException（非受检） vs 其他受检异常。
- **反射**：运行时获取类信息、创建对象、调用方法，用于框架、动态代理。
- **泛型**：类型擦除，编译期检查，通配符 `?`、上界 `extends`、下界 `super`。
- **注解**：元注解 `@Retention`、`@Target`；运行时注解可通过反射读取。
- **内部类**：静态/成员/局部/匿名内部类，内存引用区别。
- **线程状态**：NEW、RUNNABLE、BLOCKED、WAITING、TIMED_WAITING、TERMINATED。
- **`synchronized` 与 `Lock`**：`synchronized` 是 JVM 关键字；`Lock` 是 API，可中断、可超时、公平锁。
- **`volatile`**：保证可见性、禁止指令重排，不保证原子性。
- **`ThreadLocal`**：每个线程独立副本，内存泄漏风险（Entry 的 key 为弱引用）。
- **线程池**：`ThreadPoolExecutor` 核心参数（corePoolSize， maximumPoolSize， workQueue， handler）。常用 `Executors` 工厂方法。
- **`wait` vs `sleep`**：`wait` 释放锁，需在同步块中；`sleep` 不释放锁。
- **`notify` vs `notifyAll`**：`notify` 随机唤醒一个等待线程；`notifyAll` 唤醒所有。
- **死锁条件**：互斥、请求保持、不可剥夺、循环等待。
- **集合框架**：`List`（ArrayList/LinkedList）、`Set`（HashSet/TreeSet）、`Map`（HashMap/LinkedHashMap/TreeMap）、`Queue` 等。
- **`HashMap` 实现（JDK1.8）**：数组 + 链表/红黑树，扩容因子 0.75，头插改为尾插。
- **`ConcurrentHashMap` 分段锁（JDK1.7）**：Segment 数组；**JDK1.8**：CAS + `synchronized` 锁节点。
- **`Comparable` vs `Comparator`**：自然排序 vs 定制排序。
- **IO 模型**：BIO（阻塞）、NIO（非阻塞，多路复用）、AIO（异步）。
- **NIO 核心组件**：Channel、Buffer、Selector。
- **序列化**：实现 `Serializable`，`transient` 修饰不序列化，`serialVersionUID`。
- **JUC 常用工具**：`CountDownLatch`、`CyclicBarrier`、`Semaphore`、`Exchanger`。

## 二、JVM

- **内存区域**：程序计数器、虚拟机栈、本地方法栈（线程私有），堆、方法区（线程共享），JDK8 后方法区改为元空间（直接内存）。
- **堆分代**：新生代（Eden + S0 + S1）、老年代。
- **对象创建过程**：类加载检查 -> 分配内存（指针碰撞/空闲列表）-> 初始化零值 -> 设置对象头 -> 执行 `<init>`。
- **对象内存布局**：对象头（Mark Word + 类型指针/元数据指针）、实例数据、对齐填充。
- **GC 判断可达性**：GC Roots（栈引用、静态变量、常量、JNI 引用）出发，不可达对象可回收。
- **GC 算法**：标记-清除、复制（新生代）、标记-整理（老年代）、分代收集。
- **垃圾收集器**：Serial、ParNew、Parallel Scavenge、CMS、G1、ZGC 等。
- **CMS 特点**：并发收集、低停顿、标记-清除产生碎片，使用 `-XX:+UseConcMarkSweepGC`。
- **G1 特点**：分区、可预测停顿、整体标记-整理，局部复制。
- **类加载过程**：加载 -> 验证 -> 准备 -> 解析 -> 初始化。
- **双亲委派模型**：类加载请求先委派给父加载器，避免重复加载，保证核心类安全。
- **破坏双亲委派**：自定义 ClassLoader 重写 `loadClass`（如 Tomcat、热部署）。
- **内存参数**：`-Xms`（初始堆）、`-Xmx`（最大堆）、`-Xmn`（新生代）、`-XX:MetaspaceSize`、`-XX:MaxMetaspaceSize`。
- **栈内存溢出**：`-Xss` 设置栈容量，递归过深导致 `StackOverflowError`。
- **内存泄漏与 OOM**：堆 OOM（对象持续增长）、元空间 OOM（类加载过多）、直接内存 OOM。
- **JVM 调优工具**：`jps`、`jstat`、`jmap`、`jhat`、`jstack`、`jinfo`、`jconsole`、`jvisualvm`、MAT、GChisto。
- **常用调优策略**：设置 `-Xmx` 和 `-Xms` 相等，选择合适的 GC，调整新生代比例，开启大页等。

## 三、Spring 家族（Spring Framework、Spring Boot、Spring Cloud、Spring MVC）

- **Spring IoC**：控制反转，容器管理 Bean 生命周期与依赖，通过 XML/注解/JavaConfig 配置。
- **依赖注入方式**：构造器注入、Setter 注入、字段注入（`@Autowired`）。
- **Spring AOP**：动态代理（JDK 或 CGLIB），切面（Aspect）、连接点、切点、通知（Advice）、织入。
- **Bean 生命周期**：实例化 -> 属性填充 -> Aware 接口方法 -> BeanPostProcessor 前后 -> init -> 使用 -> destroy。
- **Bean 作用域**：singleton、prototype、request、session、application。
- **`@Autowired` vs `@Resource`**：前者按类型，可配合 `@Qualifier`；后者按名称（默认字段名）再类型。
- **事务传播行为**：`REQUIRED`、`SUPPORTS`、`MANDATORY`、`REQUIRES_NEW`、`NOT_SUPPORTED`、`NEVER`、`NESTED`。
- **Spring Boot 自动配置**：`@EnableAutoConfiguration` 基于 `spring.factories` 中的配置类，按条件加载 Bean。
- **Spring Boot Starter**：简化依赖管理的模块，如 `spring-boot-starter-web`。
- **Spring Boot 配置加载顺序**：`bootstrap.yml` -> `application.yml` -> 环境变量 -> 命令行参数。
- **Spring Boot Actuator**：健康检查、指标、端点（`/health`、`/metrics`、`/shutdown`）。
- **Spring Cloud 组件**：Eureka（服务注册发现）、Ribbon（客户端负载均衡）、Feign（声明式 HTTP 调用）、Hystrix（熔断降级）、Zuul（网关）、Config（配置中心）、Bus（消息总线）。
- **Eureka 与 ZooKeeper**：Eureka 保证 AP，ZooKeeper 保证 CP。
- **Ribbon 与 Feign**：Ribbon 需手动拼接请求；Feign 基于接口注解自动生成实现。
- **Hystrix 熔断机制**：三态（关闭、打开、半开），失败阈值触发，`fallback` 降级。
- **Spring MVC 流程**：DispatcherServlet -> HandlerMapping -> HandlerAdapter -> Controller -> ModelAndView -> ViewResolver -> 响应。
- **`@RestController` vs `@Controller`**：前者相当于 `@Controller` + `@ResponseBody`。
- **`@RequestMapping` 派生**：`@GetMapping`、`@PostMapping` 等。
- **`@SessionAttributes`**：将模型属性存入 session。
- **Spring Security 核心**：`UserDetailsService`、`PasswordEncoder`、过滤器链、`@PreAuthorize`。
- **JPA 与 Hibernate**：JPA 规范，Hibernate 是 JPA 实现。
- **MyBatis 核心**：`SqlSessionFactory`、`Mapper` 接口与 XML 映射。
- **MyBatis 动态 SQL**：`<if>`、`<where>`、`<foreach>` 等。
- **MyBatis 缓存**：一级缓存（SqlSession），二级缓存（namespace）。

## 四、Redis

- **数据类型**：String、Hash、List、Set、Sorted Set、Bitmap、HyperLogLog、Geo、Stream。
- **持久化**：RDB（快照，默认）、AOF（追加日志），可混合。
- **过期删除策略**：惰性删除 + 定期删除。
- **内存淘汰策略**：LRU、LFU、Random、TTL、noeviction。
- **主从复制**：全量复制（RDB） + 增量复制（命令传播）。
- **哨兵模式**：监控、故障转移、通知，实现高可用。
- **集群**：16384 个哈希槽，无中心节点，客户端直连。
- **分布式锁**：`SET NX EX` + Lua 脚本，或 Redisson。
- **缓存问题**：雪崩（过期时间随机）、穿透（布隆过滤器）、击穿（互斥锁）。
- **管道（Pipeline）**：批量发送命令，减少 RTT。
- **事务**：`MULTI`/`EXEC`，不支持回滚，可用 `WATCH` 实现乐观锁。
- **`redis-benchmark`**：性能测试工具。

## 五、消息队列（Kafka、RabbitMQ）

### Kafka
- **架构**：Producer、Consumer、Broker、Topic、Partition、Offset、Consumer Group。
- **分区作用**：水平扩展、并发消费、提高吞吐量。
- **ISR**：In-Sync Replicas，与 Leader 保持同步的副本集合。
- **HW & LEO**：HW（高水位）消费者可读的最大 offset；LEO 下一条消息 offset。
- **吞吐量高原因**：顺序写、零拷贝、页缓存、批量压缩、分区并行。
- **Exactly Once**：幂等性（`enable.idempotence=true`） + 事务。
- **消息顺序**：单个分区内有序，多分区不保证全局顺序。
- **丢数据场景**：`acks=0` 或 `acks=1` 且 Leader 宕机；消费者自动提交 offset 后未处理。
- **零拷贝**：`sendfile` 系统调用，避免用户态到内核态拷贝。

### RabbitMQ
- **核心概念**：生产者、消费者、Broker、Exchange、Queue、Binding、Routing Key。
- **交换器类型**：direct、fanout、topic、headers。
- **消息确认**：生产者确认（`confirm`）、消费者确认（`autoAck=false`）。
- **持久化**：Exchange、Queue、Message 均持久化。
- **死信队列**：消息被拒绝、过期、队列满时进入 DLX。
- **延迟队列**：通过 TTL + 死信交换器，或延迟插件。
- **集群**：磁盘节点 + 内存节点，镜像队列提高可靠性。

## 六、Netty

- **核心组件**：Channel、EventLoop、ChannelFuture、ChannelHandler、ChannelPipeline。
- **线程模型**：Boss Group（接收连接）+ Worker Group（处理 I/O），Reactor 模式。
- **零拷贝机制**：`CompositeByteBuf`、`FileRegion`（`transferTo`）、直接内存。
- **编解码**：`ByteToMessageDecoder`、`MessageToByteEncoder`，处理粘包/拆包（固定长度、分隔符、长度字段）。
- **心跳检测**：`IdleStateHandler` 触发空闲事件。
- **内存管理**：`PooledByteBufAllocator`，内存池，减少 GC。
- **高性能原因**：异步非阻塞、零拷贝、内存池、无锁化设计（串行化）。

## 七、数据库（MySQL）

- **存储引擎**：InnoDB（事务、行锁、聚簇索引） vs MyISAM（表锁、非聚簇索引）。
- **索引结构**：B+Tree，支持范围查询，节点存储多条记录。
- **聚簇索引**：叶子节点存储完整行数据；二级索引存储主键。
- **最左前缀原则**：联合索引 (a,b,c) 可使用 a、a,b、a,b,c 条件。
- **索引失效**：`!=`、`%` 开头、函数运算、隐式类型转换、`OR`。
- **事务隔离级别**：读未提交、读已提交、可重复读（MySQL 默认）、串行化。
- **MVCC**：通过隐藏字段（DB_TRX_ID、DB_ROLL_PTR）和 undo log 实现非锁定读。
- **锁**：共享锁（读锁）、排他锁（写锁）；表锁、行锁、间隙锁（Next-Key Lock）。
- **主从复制**：binlog 异步复制，支持半同步。
- **日志**：undo log（事务回滚）、redo log（崩溃恢复）、binlog（主从复制）。
- **分库分表**：水平分片（范围/哈希）、垂直分片；常见中间件 ShardingSphere、MyCat。
- **SQL 优化**：`EXPLAIN` 分析执行计划，避免 `SELECT *`，合理使用索引。

## 八、前端

- **HTML/CSS**：盒模型、Flex、Grid、响应式、BFC、定位、选择器优先级。
- **JavaScript 基础**：原型链、闭包、作用域、事件循环、异步（Promise/async）、深拷贝、防抖/节流。
- **ES6+**：箭头函数、解构、模板字符串、`let`/`const`、`Symbol`、`Set`、`Map`、Proxy。
- **浏览器渲染**：DOM 树 + CSSOM 树 -> 渲染树 -> 布局 -> 绘制。
- **跨域**：JSONP、CORS、代理服务器、postMessage。
- **存储**：cookie（4KB，随请求发送）、localStorage、sessionStorage（5MB+）。
- **性能优化**：减少 HTTP 请求、压缩/合并、懒加载、CDN、缓存策略。
- **安全**：XSS（转义输入）、CSRF（token 验证、SameSite）。
- **框架（Vue/React）**：虚拟 DOM、组件化、响应式原理（Vue 2/3 区别）、Hooks、Redux 等。

## 九、C/C++

- **编译过程**：预处理 -> 编译 -> 汇编 -> 链接。
- **内存分区**：代码区、常量区、全局/静态区、堆、栈。
- **`sizeof` 与 `strlen`**：`sizeof` 编译期计算类型大小，`strlen` 运行时计算字符串长度。
- **指针与引用**：指针可重新指向，引用必须初始化且不变。
- **`new/delete` vs `malloc/free`**：`new` 调用构造函数，`delete` 调用析构函数。
- **虚函数**：动态绑定，虚表（vtable）。
- **多态**：静态多态（重载、模板）和动态多态（虚函数）。
- **RAII**：资源获取即初始化，智能指针（`unique_ptr`、`shared_ptr`、`weak_ptr`）。
- **STL**：容器（vector、list、map）、迭代器、算法。
- **内存对齐**：结构体成员对齐，`#pragma pack`。
- **volatile**：禁止编译器优化，每次从内存读取。

## 十、Linux

- **常用命令**：`ls`、`cd`、`grep`、`find`、`ps`、`top`、`netstat`、`kill`、`chmod`、`tar`。
- **文件权限**：rwx（421），`chmod 755`。
- **进程间通信**：管道、消息队列、共享内存、信号量、Socket。
- **线程 vs 进程**：进程资源分配单位，线程 CPU 调度单位。
- **并发模型**：多进程、多线程、IO 多路复用（select、poll、epoll）。
- **epoll**：边缘触发/水平触发，红黑树 + 就绪链表。
- **硬链接/软链接**：硬链接不能跨文件系统，软链接可跨。
- **查看内存**：`free -h`、`top`、`vmstat`。
- **网络工具**：`ping`、`telnet`、`curl`、`wget`、`ss`。

## 十一、数据结构与算法

- **时间复杂度**：常见排序（快排、归并、堆排 O(nlogn)；冒泡、选择、插入 O(n²)）。
- **稳定排序**：冒泡、插入、归并；不稳定：选择、快排、堆排。
- **链表**：单链表反转、检测环（快慢指针）、合并有序链表。
- **栈与队列**：用两个栈实现队列；单调栈应用。
- **二叉树**：遍历（前、中、后、层序）、重建、最近公共祖先。
- **二叉搜索树**：中序遍历有序，查找 O(log n)。
- **平衡二叉树**：AVL（高度严格平衡）、红黑树（近似平衡，降低旋转）。
- **B+树**：所有数据在叶子节点，非叶子节点只存索引，多路平衡树。
- **哈希表**：解决冲突（链地址法、开放地址法），扩容 rehash。
- **图算法**：DFS、BFS、最小生成树（Prim、Kruskal）、最短路径（Dijkstra、Floyd）。
- **常用算法**：二分查找、KMP、动态规划（背包、LCS）、贪心、回溯、分治。

## 十二、机器学习与深度学习

- **监督/无监督/强化学习**：有标签/无标签/奖励信号。
- **过拟合解决办法**：正则化（L1/L2）、数据增强、早停、Dropout、交叉验证。
- **欠拟合**：增加模型复杂度、特征工程。
- **特征选择**：信息增益、卡方检验、相关系数。
- **模型评估指标**：准确率、精确率、召回率、F1、ROC/AUC。
- **决策树**：ID3（信息增益）、C4.5（信息增益率）、CART（基尼系数/均方误差）。
- **集成学习**：Bagging（随机森林）、Boosting（AdaBoost、GBDT、XGBoost）。
- **XGBoost 优势**：二阶泰勒展开、正则化、并行化、缺失值处理。
- **聚类**：K-Means（需指定 K，对初始值敏感）、DBSCAN（基于密度）。
- **PCA**：降维，最大化方差。
- **神经网络激活函数**：Sigmoid、Tanh、ReLU（解决梯度消失）。
- **反向传播**：链式法则计算梯度。
- **CNN**：卷积层、池化层、全连接层，权重共享。
- **RNN/LSTM/GRU**：处理序列数据，LSTM 门控机制缓解梯度消失。
- **Transformer**：自注意力机制，摒弃循环。
- **Word2Vec**：CBOW（上下文预测中心词）和 Skip-gram（中心词预测上下文）。
- **生成对抗网络（GAN）**：生成器 G 与判别器 D 博弈。
