# 《计算机组成原理》课程内容总结

## 第一部分：课程概况

*   **课程性质**：计算机科学与技术专业的主干硬件课程，承上启下。
*   **核心目标**：建立计算机系统的整机概念，理解数据流和控制流，掌握各部件工作原理及相互连接。
*   **先修课程**：数字逻辑、数字电路、汇编语言。
*   **主要参考教材**：郑秋梅编《计算机组成原理》，白中英、唐朔飞等经典教材。

## 第二部分：核心知识点与章节详解

### 第一章：绪论

**1. 计算机发展简史**
*   **第一代 (1946-1957)**：电子管，机器/汇编语言，科学计算。代表：ENIAC。
*   **第二代 (1958-1964)**：晶体管，磁芯存储器，高级语言出现，应用领域扩展。
*   **第三代 (1965-1974)**：中小规模集成电路，半导体存储器，操作系统、虚拟存储出现。
*   **第四代 (1975-至今)**：大规模/超大规模集成电路 (LSI/VLSI)，微型机与网络普及。
*   **微机发展** Intel 4004 (1971) -> 8080/8086 -> 386/486 -> Pentium系列。

**2. 计算机系统组成**
*   **硬件系统**：运算器、控制器、存储器、输入设备、输出设备（冯·诺依曼结构）。
*   **软件系统**：系统软件与应用软件。
*   **存储程序原理**：指令和数据以二进制形式存放在存储器中，CPU自动逐条取出并执行。

**3. 计算机系统层次结构**
*   **五级层次**：微程序机器级 -> 传统机器级 -> 操作系统级 -> 汇编语言级 -> 高级语言级。
*   **虚拟机**：由软件实现的抽象机器（如Java虚拟机、高级语言编译环境）。

**4. 性能指标**
*   **机器字长**：CPU一次处理数据的位数。
*   **主存容量**：字数×字长 或 字节数。
*   **运算速度**：MIPS (每秒百万条指令), MFLOPS (每秒百万次浮点运算), CPU主频, CPI (每条指令时钟周期数)。

### 第二章：计算机中数据信息的表示

**1. 数值表示**
*   **进位计数制**：二进制、八进制、十六进制及其转换。
*   **定点数与浮点数**：
    *   **定点数**：小数点位置固定（定点整数、定点小数）。
    *   **浮点数**：$N = M \times 2^E$，由阶码（决定范围）和尾数（决定精度组成）。需进行**规格化**处理。
*   **有符号数编码**:
    *   **原码**：符号位+数值位，0有两种表示。
    *   **反码**：正数同原码，负数数值位取反。
    *   **补码**：正数同原码，负数反码+1。**优势**：减法变加法，符号位参与运算，0唯一表示。
    *   **移码**：常用于浮点数阶码，符号位与补码相反。

**2. 非数值数据表示**
*   **字符**：ASCII码（7位或8 an extended ASCII）。
*   **汉字**：输入码 -> 机内码（通常2字节） -> 字形码（点阵）。
*   **BCD码**：8421码、余3码等，用4位二进制表示1位十进制数。

**3. 数据校验**
*   **奇偶校验**：增加1位校验位，检测奇数位错误，无法纠错。
*   **海明码/循环冗余校验 (CRC)**：(文中主要提及奇偶校验及交叉奇偶校验用于纠错)。

### 第三章：运算方法和运算器

**1. 定点加减法运算**
*   **补码加减法规则**：$[X+Y]_补 = [X]_补 + [Y]_补$，$[X-Y]_补 = [X]_补 + [-Y]_补$。
*   **溢出判断**：双符号位法（00正，11负，01正溢，10负溢）或单符号位进位判断。

**2. 移位运算**
*   **逻辑移位**：空位补0。
*   **算术移位**：符号位不变，数值位移动。补码右移补符号位，左移补0。

**3. 浮点加减法步骤**
1.  **对阶**：小阶向大阶看齐（尾数右移，阶码加1）。
2.  **尾数求和**：按定点补码加减法运算。
3.  **规格化**：左规（尾数左移，阶码减1）或右规（尾数右移，阶码加1）。
4.  **舍入**：0舍1入法、恒置1法等。
5.  **溢出判断**：检查阶码是否溢出。

**4. 运算器组成**
*   **ALU**：算术逻辑单元。
*   **加法器**：串行加法器（慢）、并行加法器（快，需解决进位链问题，如先行进位）。
*   **寄存器组**：存放操作数和结果。

---

### 第四章：指令系统

**1. 指令格式**
*   **组成**：操作码 (OP) + 地址码 (A)。
*   **地址码数量**：零地址（堆栈/无操作数）、单地址、双地址、三地址指令。
*   **操作码编码**：定长操作码（RISC常用）、变长操作码（CISC常用）。

**2. 寻址方式**
*   **指令寻址**：顺序寻址 (PC+1)、跳跃寻址。
*   **操作数寻址**：
    *   **立即寻址**：操作数在指令中。
    *   **直接寻址**：EA = A。
    *   **间接寻址**：EA = (A)。
    *   **寄存器寻址**：EA = R。
    *   **基址寻址**：EA = (BR) + A。
    *   **变址寻址**：EA = (IX) + A。
    *   **相对寻址**：EA = (PC) + A。

**3. 指令类型**
*   数据传送、算术运算、逻辑运算、移位、控制转移、I/O、处理机控制。

**4. CISC 与 RISC**
*   **CISC (复杂指令集)**：指令多、格式多、寻址多、微程序控制、访存频繁。
*   **RISC (精简指令集)**：指令少且简单、定长格式、寄存器多、硬布线控制、Load/Store架构、流水线优化。

---

### 第五章：存储器系统

**1. 存储器分类与指标**
*   **分类**：RAM (SRAM/DRAM), ROM (Mask/PROM/EPROM/EEPROM/Flash), Cache, 辅存。
*   **指标**：容量、存取时间、存取周期、带宽。

**2. 半导体存储器**
*   **SRAM**：触发器存储，速度快，成本高，无需刷新，用作Cache。
*   **DRAM**：电容存储，集成度高，需定期**刷新**（集中、分散、异步），用作主存。
*   **扩展**：位扩展（增加字长）、字扩展（增加容量）、字位同时扩展。

**3. 高速缓冲存储器 (Cache)**
*   **原理**：局部性原理（时间局部性、空间局部性）。
*   **映射方式**：
    *   **全相联**：任意主存块可放入任意Cache块，灵活性高，比较电路复杂。
    *   **直接映射**：主存块i只能放入Cache块 $i \mod G$，简单但冲突率高。
    *   **组相联**：折衷方案，主存块映射到特定组，组内任意块。
*   **替换算法**：LRU (最近最少使用), FIFO, RAND等。
*   **写策略**：写直达 (Write Through), 写回 (Write Back)。

**4. 虚拟存储器**
*   **目的**：扩大逻辑地址空间，解决主存容量不足。
*   **实现**：页式、段式、段页式管理。
*   **地址变换**：逻辑地址 -> 物理地址，由硬件(MMU)和操作系统共同完成。
*   **缺页中断**：当访问页面不在内存时产生。

**5. 存储体系层次**
*   Cache - 主存 - 辅存。追求速度接近Cache，容量接近辅存，价格接近辅存。

---

### 第六章：中央处理器 (CPU)

**1. CPU功能与组成**
*   **控制器**：指令寄存器 (IR), 程序计数器 (PC), 指令译码器 (ID), 时序发生器, 操作控制器。
*   **运算器**：ALU, 通用寄存器, 状态寄存器 (PSW)。
*   **数据通路**：内部总线连接各部件。

**2. 指令执行过程**
*   **取指周期**：PC -> MAR -> Mem -> MDR -> IR; PC + 1 -> PC。
*   **间址/执行周期**：根据指令类型不同，涉及地址计算、ALU运算、访存等。

**3. 控制器设计**
*   **组合逻辑控制器 (硬布线)**：速度快，设计复杂，难修改。
*   **微程序控制器**：将微操作编写成微指令存入控制存储器 (CM)。设计规整，易扩充，速度稍慢。
    *   **微指令格式**：操作控制字段 + 顺序控制字段 (下地址)。
    *   **微程序执行**：取微指令 -> 执行微命令 -> 形成下地址。

**4. 流水线技术**
*   **原理**：将指令执行过程分解为多个子过程（取指、译码、取数、执行、写回），重叠执行。
*   **冒险 (Hazard)**：
    *   **结构冒险**：资源冲突。
    *   **数据冒险**：数据依赖（需旁路技术或暂停）。
    *   **控制冒险**：分支跳转（需分支预测）。

---

### 第七章：总线

**1. 总线基本概念**
*   **特性**：机械、电气、功能、时间特性。
*   **分类**：
    *   **片内总线**：CPU内部。
    *   **系统总线**：CPU、主存、I/O接口之间。包括数据总线 (DB, 双向), 地址总线 (AB, 单向), 控制总线 (CB)。
    *   **通信总线**：系统之间。

**2. 总线结构**
*   **单总线**：结构简单，易瓶颈。
*   **多总线**：双总线、三总线、四总线结构，提高吞吐量，分离高速/低速设备。

**3. 总线仲裁与控制**
*   **仲裁方式**：
    *   **集中式**：链式查询 (优先级固定，故障敏感), 计数器定时查询 (优先级灵活), 独立请求 (速度快，线多)。
    *   **分布式**：各模块自带仲裁器。
*   **定时方式**：同步定时 (统一时钟), 异步定时 (握手信号: 请求/回答).
*   **数据传输**：串行、并行、复用、猝发传输 (Burst).

**4. 常见总线标准**
*   **ISA, EISA, PCI, PCI-E** (系统总线)。
*   **USB, IEEE 1394, SATA, SCSI** (外部/设备总线)。

---

### 第八章：输入输出系统 (I/O)

**1. I/O接口功能**
*   数据缓冲、信号转换、设备选择、中断/DMA控制、时序协调。
*   **编址方式**：统一编址 (存储器映像I/O), 独立编址 (专用I/O指令)。

**2. I/O控制方式**
*   **程序查询方式**：CPU不断轮询状态位。简单，但CPU效率极低。
*   **程序中断方式**：外设就绪后发中断请求，CPU暂停当前程序去服务。实现了CPU与I/O并行，适合随机、低速服务。
    *   **中断过程**：请求 -> 判优 -> 响应 (关中断、保存断点) -> 服务 (保护现场、处理、恢复现场) -> 返回。
    *   **中断嵌套**：高优先级中断可打断低优先级服务。
*   **DMA (直接存储器访问)**：硬件控制主存与外设间大批量数据传送，无需CPU干预每个字。适合高速、批量数据。
    *   **DMA控制器**：包含地址计数器、字计数器、数据缓冲寄存器等。
    *   **工作方式**：停止CPU访问、交替访问、周期挪用。
*   **通道方式**：I/O处理器，执行通道程序，进一步解放CPU。用于大型机。
*   **I/O处理机**：更独立的专用处理机。

---

### 第九章：外部设备

**1. 输入设备**
*   **键盘**：编码/非编码，扫描码转ASCII。
*   **鼠标**：机械/光学，坐标定位。
*   **扫描仪**：光电转换 (CCD/CIS)，A/D转换。
*   **其他**：触摸屏、条码阅读器、数码相机。

**2. 输出设备**
*   **显示器**：
    *   **CRT**：电子枪轰击荧光粉，刷新频率，分辨率，点距。
    *   **LCD**：液晶分子偏光，背光，轻薄，低功耗。
    *   **其他**：LED, Plasma, OLED。
*   **打印机**：
    *   **针式**：击打式，复写能力，噪音大。
    *   **喷墨**：非击打，彩色效果好，墨滴控制。
    *   **激光**：非击打，静电成像，速度快，质量高。

**3. 外存储器**
*   **磁盘 (Hard Disk)**：
    *   **结构**：盘片、磁头、驱动电机。
    *   **记录方式**：磁道、柱面、扇区。
    *   **指标**：容量、寻址时间 (寻道+旋转延迟)、数据传输率、误码率。
    *   **RAID**：磁盘阵列技术 (文中未详述但属相关领域)。
*   **光盘 (Optical Disk)**：
    *   **CD-ROM/DVD/Blu-ray**。
    *   **原理**：激光读取凹坑 (Pit) 和平面 (Land) 的反射差异。
    *   **类型**：只读 (ROM), 一次写入 (WORM), 可重写 (RW)。
*   **磁带**：顺序存取，容量大，成本低，用于备份。

**4. 通信与网络设备**
*   **Modem**：数模/模数转换。
*   **网卡 (NIC)**：数据帧封装/解封装。
*   **中继器/集线器 (Hub)**：物理层，信号放大/广播。
*   **网桥/交换机 (Switch)**：数据链路层，MAC地址过滤/转发，独占带宽。
*   **路由器 (Router)**：网络层，IP地址路由选择，互联不同网络。

## 第三部分：学习建议与重点回顾

1.  **整机概念**：始终牢记数据如何在五大部件之间流动（数据流）以及控制信号如何协调（控制流）。
2.  **数据表示**：熟练掌握补码运算、浮点数规格化及IEEE 754标准（虽文中未深入IEEE 754细节，但浮点原理一致）。
3.  **存储层次**：理解Cache-主存-辅存三层结构的设计初衷（速度、容量、价格的平衡）及映射机制。
4.  **CPU设计**：对比硬布线与微程序控制的优劣，理解流水线带来的性能提升及冒险处理。
5.  **I/O演进**：从查询 -> 中断 -> DMA -> 通道，理解CPU参与度逐渐降低、效率逐渐提高的过程。
6.  **总线标准**：了解主流总线（PCI-E, USB, SATA）的特点及应用场景。
