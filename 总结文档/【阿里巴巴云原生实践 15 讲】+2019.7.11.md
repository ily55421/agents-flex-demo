# 《阿里巴巴云原生实践 15 讲》内容总结

## 一、开篇：容器十年——一部软件交付编年史

- **作者**：张磊（阿里云容器平台高级技术专家）
- **核心内容**：
  - 回顾容器技术从 `chroot`、FreeBSD Jails、Linux Cgroups 到 Docker 的发展历程。
  - 阐述 Docker 如何通过“容器镜像”解决应用交付的一致性问题。
  - Kubernetes 如何通过声明式 API、控制器模型、Pod 设计模式等，成为云原生应用管理的核心。
  - 提出“云原生”本质是让应用最大化利用云的能力。
  - 强调 Kubernetes 是“云与应用之间的高速公路”，未来软件必将生长于云上。

---

## 二、阿里云原生实践全景

### 1. 坚持探索与落地并重——阿里巴巴云原生之路全景揭秘

- **作者**：李响（阿里云容器平台资深技术专家）
- **核心内容**：
  - 阿里从2011年开始通过容器实践云原生，逐步构建大规模容器基础设施。
  - 从资源成本驱动（容器化、动态调度）到研发效率驱动（Kubernetes、CI/CD、Service Mesh）。
  - 实现了全站上云，应用与宿主机解耦，基础设施标准化。
  - 提出“Kubernetes on Kubernetes”管理模式，解决集群自身管理难题。
  - 开源项目：OpenKruise、Cloud Native App Hub。

### 2. 1-5-10：如何快速恢复大规模容器故障

- **作者**：宁拙（阿里云容器平台技术专家）
- **核心内容**：
  - 提出“1分钟发现、5分钟定位、10分钟恢复”的故障处理目标。
  - 通过故障复盘、故障预防、故障演练（线下）和可灰度、可止血、可观测、自动修复（线上）实现。
  - 引入 Node Problem Detector（NPD）增强节点异常检测。
  - 开发 Container Debugger 实现自动修复和异常预测。

### 3. 阿里巴巴利用 K8S、Kata 容器和裸金属服务器构建无服务器平台

- **作者**：张翼飞、唐华敏
- **核心内容**：
  - Serverless 解决运维成本高、开发成本高的问题。
  - 通过安全容器（Kata Containers）、VPC 网络隔离、弹性裸金属服务器实现强隔离、高性能、低成本。
  - 基于 Kubernetes 管理资源，支持多租户、VPC 映射。
  - 优化 Kata 的网络（ENI 直通）和 I/O（qcow2 graphdriver）。

### 4. CafeDeployment：为互联网金融关键任务场景扩展的 Kubernetes 资源

- **作者**：吴天、枫晟（蚂蚁金服）
- **核心内容**：
  - 解决 Deployment/StatefulSet 在金融场景下的不足：IP 不可变、高可用部署、灵活发布策略。
  - 定义 CRD `CafeDeployment`，管理多个 `InPlaceSet`，支持分组发布、Beta 验证、自动重调度。
  - 支持 Readiness Gate 控制流量切换，支持跨部署单元的资源调度。

### 5. Serverless 市场观察和落地挑战

- **作者**：隐秀（蚂蚁金服）
- **核心内容**：
  - Serverless 市场快速增长，38% 组织已在用。
  - 挑战：平台可迁移、冷启动性能、调试监控、事件源集成、工作流支持。
  - 蚂蚁推出 SOFAStack Serverless Application Service（SAS），支持 0-M-N 伸缩、日志监控、流量控制等。

### 6. 有效可靠地管理大规模 Kubernetes 集群

- **作者**：沧漠（蚂蚁金服）
- **核心内容**：
  - 设计面向终态的集群管理系统，采用 Kube-on-Kube 架构。
  - 使用 Cluster-Operator 管理业务集群 Master 组件，Machine-Operator 管理工作节点。
  - 实现节点故障自愈、变更限流、健康检查熔断。

## 三、阿里新技术方案

### 1. 云原生应用 Kubernetes 监控与弹性实践

- **作者**：莫源（阿里云容器服务团队）
- **核心内容**：
  - 集成云服务：SLS（日志）、ARMS（APM）、AHAS（架构感知）、Cloud Monitor。
  - 增强开源方案：metrics-server、NPD、Eventer、Prometheus（支持 TSDB、GPU 监控）。
  - 弹性组件：HPA、VPA、cronHPA、Resizer、Cluster-Autoscaler、virtual-kubelet-autoscaler。

### 2. 了解 Kubernetes Master 的可扩展性和性能

- **作者**：陈星宇、曾凡松
- **核心内容**：
  - 针对 10k 节点规模，优化 etcd（支持 100GB 存储）、API Server（Lease 心跳、负载均衡、Watch bookmark）。
  - 优化 Controller 故障转移（<2s）、Scheduler（等价类、松弛随机化）。

### 3. 云原生时代加速镜像分发的三种方法

- **作者**：江勇
- **核心内容**：
  - 问题：镜像大（3~4GB）、下载慢、影响业务。
  - 解决方案：
    1. **蜻蜓（Dragonfly）**：P2P 分发，减少镜像中心压力。
    2. **Gzip 优化**：使用 LZ4 压缩，减少 CPU 抢占。
    3. **远程盘 & DADI**：远端存储镜像层，P2P + 本地缓存 + 高效压缩。

### 4. 在 Web 级集群中动态调整 Pod 资源限制

- **作者**：王程、张晓宇
- **核心内容**：
  - 问题：静态资源配置导致资源浪费或 OOM。
  - 解决方案：Policy Engine 动态调整 Cgroup 参数（CPU/内存）。
  - 特点：插件化、自愈、不依赖先验知识，支持分时复用和在线/离线混部。

### 5. 大规模 k8s 集群下的巡检

- **作者**：陈杰、马金晶
- **核心内容**：
  - 巡检目的：发现资源不一致、IP 冲突、元数据未同步等问题。
  - 基于 Knative 构建 Serverless 巡检框架，支持事件驱动、可扩展。
  - 与自愈系统联动，实现故障自动修复。

### 6. 使用 Istio 管理跨地域多集群的服务

- **作者**：王夕宁、刘晓忠
- **核心内容**：
  - 多集群动机：业务连续性、地理分布、网络成本降低。
  - ACK 集成 Istio，支持多集群统一管理、就近访问、故障转移。
  - 使用 Istio Operator 简化部署和多集群配置。

## 四、阿里云开源贡献

### 1. GPU 共享调度

- **作者**：张凯、车漾
- **核心内容**：
  - 解决 GPU 利用率低的问题，支持多个 Pod 共享一张 GPU 卡。
  - 基于 Extended Resource + Scheduler Extender + Device Plugin 实现。
  - 支持按显存调度，用户可通过环境变量限制显存使用。

### 2. 容器运行时管理引擎 Containerd

- **作者**：傅伟、刘澜涛
- **核心内容**：
  - containerd 是 CNCF 毕业项目，支持 CRI、gRPC API、插件化架构。
  - 支持 Snapshotter、Runtime 插件，集成 Kata、gVisor 等运行时。
  - 性能优于 dockershim，是 Kubernetes 推荐的运行时。

### 3. 基于 P2P 的高可用高性能大规模镜像分发系统：Dragonfly

- **作者**：胡作政
- **核心内容**：
  - 解决大规模镜像下载瓶颈，采用 P2P 分发 + 动态分块 + 预热机制。
  - 架构：SuperNode（调度+缓存+传输）+ DFget（客户端）。
  - 已被阿里云 ACR、浙江移动等广泛采用，下载效率提升 3 倍以上。
