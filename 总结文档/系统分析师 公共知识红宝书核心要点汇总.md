以下是基于《系统架构设计师红宝书一本全2025 (凯恩)》内容的详细总结与要点分析。该文档主要针对**系统架构设计师**和**系统分析师**的公共知识部分，侧重于选择题考点，兼顾案例与论文的基础理论。

# 系统架构设计师/系统分析师 公共知识红宝书核心要点汇总

## 1. 系统规划与分析 (次重点 ★★★☆☆)
*   **核心任务**：系统分析是将用户需求转化为系统需求规格说明书的过程。
*   **业务流程分析**：
    *   **方法**：价值链分析、客户关系分析、供应链分析、ERP分析、BPR（业务流程重组）。
    *   **工具**：业务流程图 (TFD)、业务活动图 (BAM)、UML活动图。
    *   **建模 (BPM)**：标杆瞄准、DEMO、Petri网、BPMN/UML。
*   **可行性分析 (重点)**：
    *   **经济可行性**：成本 vs 收益（直接/间接）。
    *   **技术可行性**：现有技术/资源是否支持。
    *   **法律可行性**：合规性。
    *   **用户使用可行性**：管理支持、运行环境、易用性。
    *   **进度可行性**：期限合理性。

## 2. 系统设计 (超级重点 ★★★★★)
*   **面向对象设计 (OOD)**：
    *   **类分类**：
        *   **实体类**：持久化数据，名词命名（如：学员、课程）。
        *   **控制类**：协调交互，动宾结构命名（如：身份验证器）。
        *   **边界类**：系统与外界接口（如：窗口、API接口）。
    *   **设计原则 (SOLID)**：单一职责、开闭原则、里氏替换、依赖倒置、接口隔离、组合/聚合复用、迪米特法则。
*   **结构化设计 (SD)**：
    *   **模块划分原则**：高内聚、低耦合。
    *   **耦合度 (低->高)**：非直接 < 数据 < 标记 < 控制 < 外部 < 公共 < 内容。
    *   **内聚度 (高->低)**：功能 > 顺序 > 通信 > 过程 > 瞬时 > 逻辑 > 偶然。
    *   **扇入/扇出**：平均3-4，不超过7。
*   **设计模式**：
    *   **创建型**：工厂、抽象工厂、生成器、原型、单例。
    *   **结构型**：适配器、桥接、组合、装饰、外观、享元、代理。
    *   **行为型**：责任链、命令、迭代器、中介者、备忘录、观察者、状态、策略、模板方法、访问者、解释器。

## 3. 软件工程 (重点 ★★★★★)
*   **开发模型**：
    *   **瀑布模型**：需求确定，线性，不适应变化。
    *   **原型/演化模型**：需求不明确，快速反馈。
    *   **螺旋模型**：**瀑布+原型+风险分析**，适合高风险大型项目。
    *   **喷泉模型**：面向对象，阶段重叠，迭代。
    *   **V模型**：测试与开发对应（单元测试-详细设计，集成测试-概要设计，系统测试-需求）。
    *   **RUP**：用例驱动、以架构为中心、迭代增量。9大核心工作流。
    *   **敏捷开发**：以人为本，适应型。XP（极限编程）、Scrum、FDD。
*   **CBSE (基于构件的软件工程)**：
    *   **构件特性**：可组装性、可部署性、文档化、独立性、标准化、无外部可见状态。
    *   **组装方式**：顺序、层次、叠加。
    *   **接口不兼容**: 参数、操作、操作不完备。
*   **CMM/CMMI**：
    *   **CMM五级**：初始、可重复、已定义、已管理、优化。
    *   **CMMI五级**：初始、已管理、已定义、量化管理、优化。

## 4. 系统可靠性 (次重点 ★★★☆☆)
*   **指标**：
    *   **MTBF** (平均故障间隔时间) = MTTF + MTTR。通常 MTTR很小，故 MTBF ≈ MTTF。
    *   **MTTR** (平均修复时间)。
    *   **MTTF** (平均故障前时间，不可修复系统)。
*   **容错技术**：恢复块、N版本程序设计、冗余设计、双机热备、集群。

## 5. 软件需求工程 (超级重点 ★★★★★)
*   **需求获取**：访谈、问卷、采样（公式：$N = \alpha \times (Z/E)^2$）、JRP、原型。
*   **结构化分析 (SA)**：
    *   **DFD (数据流图)**：外部实体、加工、数据存储、数据流。
    *   **平衡原则**：父子图数据流一致；子图无黑洞（只有入无出）、奇迹（只有出无入）、灰洞（输入不足以产生输出）。
*   **面向对象分析 (OOA)**：
    *   **UML图**：
        *   **结构图**：类图、对象图、组件图、部署图。
        *   **行为图**：用例图、顺序图、活动图、状态图、通信图。
    *   **用例关系**：
        *   **Include (包含)**：提取公共行为，指向抽象用例。
        *   **Extend (扩展)**：基本条件满足时的额外行为，指向基本用例。
        *   **Generalization (泛化)**：继承，指向父用例。
    *   **4+1视图**：逻辑、进程、实现、部署、用例。

## 6. 信息安全 (次重点 ★★★☆☆)
*   **加密算法**：
    *   **对称**：AES, DES (56位), 3DES (112/168位), RC4, IDEA, SM1/SM4/SM7 (国密)。
    *   **非对称**：RSA, ECC, SM2/SM9 (国密)。
    *   **哈希/摘要**：MD5, SHA, SM3 (国密)。
*   **认证技术**：数字签名（完整性、不可否认、身份认证）、数字证书 (X.509)、生物特征。
*   **密钥管理**：KMI (封闭网), PKI (开放网), SPK (专用网)。
*   **访问控制**：
    *   **DAC** (自主)：用户自主授权。
    *   **MAC** (强制)：BLP模型（上读下写，保密性），Biba模型（下读上写，完整性）。
    *   **RBAC** (基于角色)：用户-角色-权限。
    *   **TBAC** (基于任务)：动态权限。

## 7. 系统配置与性能评价 (次重点 ★★★☆☆)
*   **Flynn分类**：SISD (单处理), SIMD (阵列处理), MISD (流水线), MIMD (多处理/集群)。
*   **存储系统**：
    *   **Cache**：局部性原理（时间、空间）。映射方式：直接、全相联、组相联。
    *   **RAID**：
        *   RAID 0: 条带，无冗余，最快。
        *   RAID 1: 镜像，50利用率，安全。
        *   RAID 5: 分布式奇偶校验，允许坏1盘。
        *   RAID 6: 双重奇偶校验，允许坏2盘。
        *   RAID 10: 镜像+条带。
*   **流水线技术**：
    *   **执行时间**：$T = T_{first} + (n-1) \times \Delta t$ ($\Delta t$为最长段耗时)。
    *   **吞吐率**：$TP = n / T$。最大 $TP = 1 / \Delta t$。
    *   **加速比**：$S = T_{serial} / T_{pipeline}$。
*   **阿姆达尔定律**：$S = 1 / ((1-f) + f/k)$。

## 8. 数据库系统 (超级重点 ★★★★★)
*   **三级模式两级映像**：外模式、概念模式、内模式；逻辑独立性、物理独立性。
*   **E-R图转换**：
    *   1:1 -> 合并或独立表。
    *   1:n -> n端加1端主键或独立表。
    *   m:n -> 必须独立表，主键为两端主键组合。
*   **规范化理论**：
    *   **1NF**：属性原子性。
    *   **2NF**：消除非主属性对码的**部分依赖**。
    *   **3NF**：消除非主属性对码的**传递依赖**。
    *   **BCNF**：消除主属性对码的部分/传递依赖（所有决定因素都是候选码）。
    *   **4NF**：消除多值依赖。
*   **并发控制**：
    *   **问题**：丢失修改、脏读、不可重复读、幻读。
    *   **封锁**：X锁 (排他/写), S锁 (共享/读)。
    *   **协议**：
        *   一级：防丢失修改。
        *   二级：防丢失修改、脏读。
        *   三级：防丢失修改、脏读、不可重复读。
        *   两段锁协议 (2PL)：保证可串行化，可能死锁。
*   **反规范化**：增加冗余以提高查询性能，牺牲更新性能和数据一致性。

## 9. 操作系统 (次重点 ★★★☆☆)
*   **进程管理**：
    *   **三态/五态**：就绪、运行、阻塞、新建、终止。
    *   **PV操作**：P (Wait, 申请资源, S--), V (Signal, 释放资源, S++)。
    *   **死锁必要条件**：互斥、不剥夺、请求保持、环路。
*   **内存管理**：
    *   **页面置换算法**：OPT (理想), LRU (最近最久未使用), FIFO, Clock。
    *   **虚拟内存**：请求调入 + 置换。
*   **文件管理**：
    *   **索引结构**：直接、一级间接、二级间接。计算逻辑块号对应的索引类型。
    *   **位示图**：字长32位，磁盘块数/32 = 所需字数。

## 10. 计算机网络 (次重点 ★★★☆☆)
*   **OSI七层模型**：物理、数据链路、网络、传输、会话、表示、应用。
*   **TCP/IP四层**：网络接口、网际 (IP)、传输 (TCP/UDP)、应用。
*   **常见协议端口**：
    *   HTTP (80), HTTPS (443), FTP (20/21), SMTP (25), POP3 (110), DNS (53), Telnet (23), SSH (22).
*   **IP地址**：
    *   A类 (1-126), B类 (128-191), C类 (192-223).
    *   CIDR计算：网络地址 = IP & Mask。广播地址 = 主机位全1。
*   **设备层次**：
    *   中继器/集线器：物理层。
    *   交换机/网桥：数据链路层。
    *   路由器：网络层。
    *   网关：高层。

## 11. 企业信息化战略 (次重点 ★★★☆☆)
*   **诺兰模型**：初始、传播、控制、集成、数据管理、成熟。
*   **信息系统类型**：TPS (事务), MIS (管理), DSS (决策支持), ES (专家系统), OAS (办公自动化).
*   **企业应用集成 (EAI)**：
    *   表示集成 (界面), 数据集成 (数据库), 控制集成 (API/中间件), 业务流程集成 (BPM).

## 12. 项目管理 (次重点 ★★★☆☆)
*   **进度管理**：
    *   **关键路径法 (CPM)**：最长路径决定工期。
    *   **时差计算**：总时差 (不影响总工期), 自由时差 (不影响紧后最早开始)。
    *   **三点估算**：$Te = (O + 4M + P) / 6$。
*   **范围管理**：WBS (工作分解结构)，自顶向下分解至工作包。

## 13. 软件测试 (次重点 ★★★☆☆)
*   **黑盒测试**：等价类划分、边界值分析、因果图、错误推测。
*   **白盒测试覆盖标准**：
    *   语句覆盖 < 判定覆盖 < 条件覆盖 < 判定/条件覆盖 < 条件组合覆盖 < MC/DC (修改条件/判定覆盖，最强)。
*   **测试阶段**：单元测试 (白盒为主), 集成测试, 系统测试 (黑盒), 验收测试。

## 14. 系统运行与维护 (次重点 ★★★☆☆)
*   **维护类型**：
    *   **改正性**：修Bug。
    *   **适应性**：适应环境变化 (OS升级等)。
    *   **完善性**：扩充功能/性能 (占比最大)。
    *   **预防性**：提高可维护性。
*   **遗留系统演化策略**：
    *   **改造**：高技术高价值。
    *   **集成**：高技术低价值 (信息孤岛)。
    *   **淘汰**：低技术低价值。
    *   **继承**：低技术高价值 (兼容旧系统逐步替换)。

## 15. 系统架构设计 (超级重点 ★★★★★)
*   **架构风格**：
    *   **数据流**：批处理、管道-过滤器 (编译器)。
    *   **调用/返回**：主程序/子程序、面向对象、层次结构、C/S。
    *   **数据中心**：仓库 (数据库)、黑板 (AI/信号处理)。
    *   **虚拟机**：解释器 (脚本语言)、规则系统。
    *   **独立构件**：事件驱动 (隐式调用)、消息队列。
*   **质量属性 (ATAM关注)**：
    *   **性能**：响应时间、吞吐量。
    *   **可用性**：故障恢复、心跳检测。
    *   **可修改性**：局部化修改、高内聚低耦合。
    *   **安全性**：认证、授权、加密。
*   **质量属性场景六要素**：刺激源、刺激、环境、制品、响应、响应度量。
*   **架构评估方法**：
    *   **SAAM**：侧重可修改性。
    *   **ATAM**：侧重性能、可用性、安全性、可修改性。使用**效用树**排序场景。
    *   **CBAM**：侧重成本效益分析 (ROI)。
*   **敏感点 vs 权衡点**：
    *   **敏感点**：影响单个质量属性的构件特性。
    *   **权衡点**：影响多个质量属性 (如加密强度影响安全性和性能)。

## 16. 法律法规 (重点 ★★★★★)
*   **著作权**：
    *   **保护期**：公民终生+死后50年；单位首次发表后50年。
    *   **职务作品**：一般归作者，单位有权使用；特殊职务作品 (利用单位资源/指定任务) 归单位。
    *   **软件著作权**：代码完成即保护，登记仅为举证。
*   **专利权**：
    *   **保护期**：发明20年，实用新型/外观设计10年 (均从申请日起算)。
    *   **授予条件**：新颖性、创造性、实用性。
    *   **职务发明**：归单位。离职1年内与原工作相关也归单位。
    *   **先申请原则**。
*   **商标权**：注册有效期10年，可续展。先申请原则。

### 备考建议
1.  **刷题结合**：红宝书内容需配合真题（特别是近5年）进行验证，重点记忆标注“重点”和“超级重点”的章节。
2.  **概念辨析**：选择题常考易混淆概念，如耦合/内聚类型、RAID级别、范式判断、加密算法类型、访问控制模型、架构风格适用场景。
3.  **计算题掌握**：流水线、Cache映射、磁盘调度、IP子网划分、三点估算、关键路径、可靠性串并联、采样规模计算。
4.  **案例分析基础**：虽然红宝书侧重选择，但其中的DFD平衡、E-R图转换、用例关系、质量属性场景描述、架构风格选择也是案例分析的高频考点。
