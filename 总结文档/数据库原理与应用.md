# 《数据库原理与应用》课程内容总结

## 第一部分：课程简介与目标

### 1. 课程定位
*   **性质**：大学计算机基础公共核心课，许多专业的必修课。
*   **作用**：连接计算机基础理论与应用技术的桥梁。
*   **工具**：以 **Microsoft Access** 为具体的数据库管理系统（DBMS）。

### 2. 课程目标
*   掌握数据库基本理论、概念及设计方法。
*   熟练掌握 Access 中七大对象的操作：**表、查询、窗体、报表、页、宏、模块**。
*   掌握简单的 SQL 语句。
*   最终能力：独立完成一个小型实用的数据库应用程序设计。

### 3. 教学结构
课程分为八个单元，遵循“理论 -> 对象操作 -> 综合设计”的逻辑：
1.  **理论基础**：数据模型、关系型数据库概念。
2.  **数据构建**：建立数据库、表及表间关系。
3.  **数据检索**：创建各类查询及 SQL 查询。
4.  **数据交互界面**：创建窗体及控件使用。
5.  **数据输出**：创建报表。
6.  **自动化控制**：使用宏实现逻辑控制。
7.  **综合实战**：小型数据库系统全流程设计。

## 第二部分：核心知识点详解

### 第一单元：数据库与表 (基础理论)

#### 1. 基本概念
*   **数据 (Data)**：信息的物理表现形式（符号、文字等）。
*   **信息 (Information)**：经过加工的数据，具有决策价值。
*   **数据处理**：将数据转化为信息的过程。
*   **数据库 (DB)**：长期存储、有组织、可共享的数据集合。特点：冗余小、独立性高、易扩展。
*   **数据库系统 (DBS)**组成：
    *   数据库 (DB)
    *   数据库管理系统 (DBMS，如 Access)
    *   应用系统
    *   人员（DBA 及用户）

#### 2. 数据模型
*   **三要素**：数据结构（静态）、数据操作（动态）、完整性约束（实体、参照、用户自定义）。
*   **分类**：关系型（二维表，本课程重点）、层次型、网状型、面向对象型。
*   **关系运算**：选择 (Selection)、投影 (Projection)、联接 (Join)。

#### 3. Access 基础
*   **文件格式**：`.mdb` (Access 2003及以前) 或 `.accdb`。
*   **七大对象**: 表、查询、窗体、报表、页、宏、模块。

#### 4. 表的设计
*   **结构**：由字段（列/属性）和记录（行/元组）组成。
*   **主键 (Primary Key)**：唯一标识记录，不可重复，不可为空。类型：单字段、多字段、自动编号。
*   **数据类型 (10种)**：
    1.  **文本**：1-255字符，默认50。
    2.  **备注**：<64K，长文本。
    3.  **数字**：整型、长整型、单精度、双精度等。
    4.  **日期/时间**：8字节。
    5.  **货币**：8字节，高精度小数。
    6.  **自动编号**：4字节，系统自动生成。
    7.  **是/否**：逻辑值 (Yes/No, True/False, -1/0)。
    8.  **OLE对象**：多媒体数据 (<1G)。
    9.  **超级链接**：URL地址。
    10. **查阅向导**：从列表选择数据。
*   **字段属性**：字段大小、格式（仅影响显示）、输入掩码（控制输入格式，如密码、电话）、标题、默认值、有效性规则/文本、必填字段。

---

### 第二单元：表间关系与操作

#### 1. 表间关系 (Relationships)
*   **定义**：基于公共字段建立的连接。
*   **建立步骤**：
    1.  主表必须建立主键。
    2.  子表必须有与主表主键类型、长度一致的对应字段。
    3.  关闭所有表，在“关系”窗口中将主表主键拖拽至子表对应字段。
*   **参照完整性**：
    *   **级联更新**：主表主键更改，子表同步更新。
    *   **级联删除**：主表记录删除，子表相关记录同步删除。
*   **关系类型**：
    1.  **一对一 (1:1)**：双方公共字段均为主键。
    2.  **一对多 (1:n)**：主表公共字段为主键，子表为非主键（最常见）。
    3.  **多对多 (m:n)**：无法直接实现，需通过中间表转化为两个一对多关系。

#### 2. 数据输入原则
*   先建立关系，后输入数据。
*   先输入主表记录，后输入子表记录。

#### 3. 表的操作
*   **导入/导出**：支持与 Excel, FoxPro, TXT, HTML 等格式交换数据。
*   **链接表**：数据保留在原文件，Access 中仅存映像，保持数据同步。
*   **复制**：可复制结构+数据，或仅复制结构。

### 第三单元：创建选择查询

#### 1. 查询概述
*   **定义**：根据条件筛选数据形成的动态数据集（虚拟表）。
*   **视图模式**：数据表视图（看结果）、设计视图（建逻辑）、SQL 视图（看代码）。
*   **数据源**：可以是表，也可以是其他查询。多表查询必须先建立正确关系。

#### 2. 查询类型
*   **条件查询**：“与”条件同行，“或”条件不同行。
*   **交叉表查询**：行列转换统计（类似 Excel 透视表），数据源通常为单表或单查询。
*   **参数查询**：运行时提示用户输入条件，提示语用 `[]` 包裹，如 `[请输入姓名:]`。
*   **计算字段**：在字段行输入 `新字段名: 表达式`。

#### 3. 表达式与函数
*   **分界符**：
    *   数值：无。
    *   字符串：`" "` (双引号)。
    *   日期：`# #` (井号)，如 `#2023-01-01#`。
    *   字段名：`[ ]` (方括号)，建议始终使用。
*   **运算符**：
    *   算术：`+ - * / \ (整除) Mod (求余) ^ (幂)`
    *   连接：`&` (强制连接), `+` (类型一致连接)
    *   比较：`= <> < > <= >=`
    *   逻辑：`AND OR NOT`
    *   特殊：`Between...And`, `In(...)`, `Is Null`, `Like` (配合 `*`多字符, `?`单字符)
*   **常用函数**：
    *   数值：`Int()`, `Round()`, `Sqr()`
    *   字符：`Len()`, `Trim()`, `Left()`, `Mid()`, `Space()`
    *   日期：`Date()`, `Now()`, `Year()`, `Month()`, `Day()`
    *   其他：`Iif(条件, 真值, 假值)`, `Ucase()`, `Str()`

### 第四单元：汇总查询、操作查询与 SQL

#### 1. 汇总查询 (总计行)
*   在设计视图点击 `∑` 按钮启用。
*   **聚合函数**：`Sum` (求和), `Avg` (平均), `Min/Max` (最值), `Count` (计数), `StDev` (标准差), `Var` (方差)。
*   **选项**：
    *   `Group By`：分组依据。
    *   `Where`：作为筛选条件，不出现在结果中。
    *   `Expression`：用于包含聚合函数的计算字段。

#### 2. 操作查询 (动作查询)
*   **特点**：直接修改原表数据，不产生结果集，需谨慎使用。
*   **四种类型**：
    1.  **生成表查询**：根据条件创建新表。
    2.  **追加查询**：将记录添加到现有表末尾。
    3.  **删除查询**：批量删除符合条件的记录。
    4.  **更新查询**：批量修改字段值（注意：字段名需加 `[]`）。

#### 3. SQL 查询 (SELECT 语句)
*   **基本语法结构**：
    ```sql
    SELECT [DISTINCT] 字段列表 [AS 别名]
    FROM 表名列表
    [WHERE 行筛选条件]
    [GROUP BY 分组字段]
    [HAVING 组筛选条件]
    [ORDER BY 排序字段 [ASC|DESC]];
    ```
*   **关键点**：
    *   `DISTINCT`：去重。
    *   多表连接：在 `WHERE` 中写明连接条件（如 `Table1.ID = Table2.ID`）。
    *   `HAVING`：必须配合 `GROUP BY` 使用，用于过滤分组后的结果。

### 第五单元：创建窗体 (Form)

#### 1. 窗体功能
*   数据显示与编辑、流程控制、信息提示、打印预览。
*   **区别**：窗体重在**交互与显示**，可输入输出；报表重在**打印**，只读。

#### 2. 窗体结构 (5个节)
1.  **窗体页眉**：标题、按钮（每窗体顶部显示一次）。
2.  **页面页眉**：列标题（每页顶部打印时显示）。
3.  **主体**：主要数据展示区。
4.  **页面页脚**：页码、日期（每页底部打印时显示）。
5.  **窗体页脚**：汇总、按钮（每窗体底部显示一次）。

#### 3. 常用控件
*   **标签 (Label)**：非结合型，显示静态文本。
*   **文本框 (Text Box)**：
    *   结合型：绑定字段。
    *   计算型：来源为表达式。
    *   非结合型：无数据来源。
*   **命令按钮 (Command Button)**：触发宏或 VBA 事件。
*   **组合框 (Combo Box) vs 列表框 (List Box)**：
    *   组合框：节省空间，可输入，下拉选择。
    *   列表框：占用空间大，多选，不可输入。
*   **选项卡控件**：用于多页界面整理。

---

### 第六单元：报表 (Report)

#### 1. 报表特点
*   主要用于格式化打印输出。
*   数据源通常为表或查询（多表建议先用查询整合）。

#### 2. 报表结构 (7个节)
1.  **报表页眉**：首页顶部（标题）。
2.  **页面页眉**：每页顶部。
3.  **组页眉**：分组标题。
4.  **主体**：详细记录。
5.  **组页脚**：分组小计。
6.  **页面页脚**：每页底部。
7.  **报表页脚**：末页底部（总计）。

#### 3. 排序与分组
*   最多支持 10 个排序/分组字段。
*   统计计算（如总和、平均）通常放在**组页脚**或**报表页脚**的文本框中。

---

### 第七单元：宏 (Macro)

#### 1. 宏的概念
*   一系列操作的集合，用于自动化任务，无需编写代码。

#### 2. 宏的类型
*   **单个宏**：顺序执行一系列操作。
*   **宏组**：包含多个独立命名的宏。
*   **条件宏**：根据条件判断执行特定操作（如密码验证）。

#### 3. 常用宏操作
*   `OpenForm`, `OpenReport`, `OpenQuery`, `OpenTable`
*   `Close`, `Quit`
*   `MsgBox` (消息提示)
*   `RunSQL` (执行 SQL)
*   `SetWarnings` (关闭/开启警告信息)

#### 4. 特殊宏
*   **AutoExec**：数据库启动时自动运行的宏，常用于打开登录窗体或主菜单。

#### 5. 运行方式
*   直接运行、双击运行、绑定到控件事件（如按钮单击）。

### 第八单元：数据库系统设计 (综合案例)

#### 1. 设计步骤 (生命周期)
1.  **需求分析**：明确用户需求，收集数据，确定功能边界。
2.  **概念设计**：绘制 E-R 图，确定实体、属性及关系。
3.  **逻辑设计**：将概念模型转换为关系模型（建表、定主键、外键）。
4.  **物理设计**：在具体 DBMS (Access) 中实现，优化存储与性能。

#### 2. 实施流程
1.  创建空数据库。
2.  设计并创建表结构，建立表间关系。
3.  输入测试数据。
4.  创建查询（基础查询、参数查询、动作查询）。
5.  设计窗体（登录窗体、主菜单、数据录入/浏览窗体）。
6.  设计报表（统计报表、明细报表）。
7.  编写宏/VBA 实现导航、权限控制、自动化逻辑。
8.  设置启动项（隐藏数据库窗口，指定启动窗体）。
9.  编写设计文档。

#### 3. 案例参考：工资管理系统
*   **模块**：部门管理、职工信息管理、工资计算、查询统计。
*   **技术点应用**：
    *   利用**更新查询**每月自动计算工龄工资、税款、实发工资。
    *   利用**生成表查询**备份上月工资数据。
    *   利用**宏组**构建主菜单导航。
    *   利用**条件宏**实现简单的密码登录验证。

## 第三部分：学习建议与注意事项

1.  **规范命名**：字段名、对象名建议使用英文或拼音，避免特殊字符，保持一致性。
2.  **完整性优先**：在建表初期务必设定好主键和数据类型，后期修改成本高。
3.  **关系严谨**：多表操作前，务必在“关系”窗口确认关联正确并启用参照完整性。
4.  **备份习惯**：在执行“操作查询”（删除、更新、追加）前，务必备份数据或先在查询视图中预览结果。
5.  **从简到繁**：先掌握单表操作，再过渡到多表查询和窗体联动。
6.  **SQL 思维**：虽然 Access 提供图形化界面，但理解 SQL 语法对于处理复杂逻辑至关重要。
