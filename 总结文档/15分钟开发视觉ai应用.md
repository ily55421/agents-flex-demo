# 15分钟开发视觉AI应用 - 教程总结

## 1. 视觉智能开放平台简介

### 概述
*   **背景**：阿里巴巴集团拥有数千名视觉技术开发人员，在电商、城市大脑、金融、交通等多个行业积累了大量视觉基础原子算法。
*   **平台定位**：由达摩院联合阿里云等多部门创建，面向企业和开发者提供高易用、普惠的视觉 API 服务。
*   **能力范围**：涵盖通用、图像、视频、目标识别、3D、AR/VR等类目，提供100多种视觉 AI 算法能力。
*   **适用场景**：城市大脑、安防、数字营销、身份认证、互联网娱乐等。
*   **官网地址**：`vision.aliyun.com`

## 2. 开发前准备

在开始开发之前，需要完成以下三个步骤：

### 步骤一：开通阿里云视觉智能开放平台
1.  登录阿里云视觉智能开放平台。
2.  选择所需能力类目（如图像识别 > 车型识别），点击“立即开通”。
3.  确认服务地域，点击“立即购买”。
4.  阅读并同意服务协议，完成支付。

### 步骤二：开通 OSS 服务 (Object Storage Service)
视觉 AI 接口通常要求图片位于阿里云 OSS 中（且需同地域）。
1.  登录阿里云官网，进入 OSS 产品详情页并开通。
2.  登录 OSS 管理控制台。
3.  创建 Bucket（存储空间），配置参数后确定。

### 步骤三：创建密钥并安装 Java SDK
1.  **创建 AccessKey**：
    *   登录阿里云管理控制台。
    *   访问 AccessKey 管理中心，创建并保存 `AccessKey ID` 和 `AccessKey Secret`。
2.  **安装 Java SDK**：
    在 Maven 工程的 `pom.xml` 中添加核心依赖：
    ```xml
    <dependency>
        <groupId>com.aliyun</groupId>
        <artifactId>aliyun-java-sdk-core</artifactId>
        <version>4.4.8</version>
    </dependency>
    <dependency>
        <groupId>com.alibaba</groupId>
        <artifactId>fastjson</artifactId>
        <version>1.2.52</version>
    </dependency>
    <!-- 注意：具体功能模块还需添加对应的 SDK 依赖，如下文各章节所示 -->
    ```

## 3. 人脸识别实战教程

### 背景与前提
*   **技术原理**：基于深度学习，提供人脸检测、属性识别、比对及人体检测能力。
*   **前提条件**：
    1.  开通“人脸人体”能力。
    2.  添加人脸人体 SDK 依赖：
        ```xml
        <dependency>
            <groupId>com.aliyun</groupId>
            <artifactId>aliyun-java-sdk-facebody</artifactId>
            <version>1.0.8</version>
        </dependency>
        ```

### 功能一：人脸属性识别 (`RecognizeFace`)
*   **功能**：识别性别、年龄、表情、眼镜佩戴情况，并返回1024维人脸特征向量。
*   **核心代码逻辑**：
    1.  初始化 `DefaultProfile` 和 `IAcsClient`。
    2.  创建 `RecognizeFaceRequest`，设置图片 URL（OSS地址）。
    3.  调用 `client.getAcsResponse` 获取结果。
*   **返回示例解析**：
    *   `faceCount`: 1 (检测到1张脸)
    *   `genderList`: [0] (0代表女性, 1代表男性)
    *   `ageList`: [24] (年龄)
    *   `expressions`: [1] (1代表微笑)
    *   `glasses`: [1] (1代表戴眼镜)

### 功能二：人体计数 (`DetectBodyCount`)
*   **功能**：检测图片中人体的个数。
*   **核心代码逻辑**：
    1.  创建 `DetectBodyCountRequest`。
    2.  设置图片 URL。
    3.  调用接口获取响应。
*   **结果**：返回检测到的人体数量（例如返回3表示有3个人）。

### 功能三：人脸搜索 (`SearchFace`)
*   **流程**：
    1.  **创建人脸样本实体** (`AddFaceEntity`)：在数据库中创建一个 ID（如 `human1`）。
    2.  **添加人脸数据** (`AddFace`)：将具体的人脸图片 URL 绑定到实体 ID 上。每个实体最多添加5张图片。
    3.  **搜索人脸** (`SearchFace`)：输入一张新图片，在库中查找相似人脸。
*   **限制**：公测阶段每个主账号默认创建一个名为 `default` 的数据库，最多存储5万张图片。
*   **核心代码逻辑**：
    *   使用 `AddFaceEntityRequest` 创建实体。
    *   使用 `AddFaceRequest` 添加图片（注意：图片必须是同 Region 的 OSS 地址，且为正面无遮挡单人照）。
    *   使用 `SearchFaceRequest` 进行搜索，设置 `limit` 返回最相似的结果数。
*   **返回示例解析**：
    *   `matchList`: 包含匹配结果。
    *   `entityId`: 匹配到的样本名称（如 `human1`）。
    *   `score`: 相似度得分（如 0.869）。
    *   `faceId`: 匹配到的具体人脸ID。

## 4. 口罩识别实战教程

### 前提条件
*   开通“人脸人体”能力。
*   添加相同的 `aliyun-java-sdk-facebody` 依赖。

### 功能：口罩检测 (`DetectMask`)
*   **功能**：对图片中面积最大的人脸进行口罩佩戴检测。
*   **核心代码逻辑**：
    1.  创建 `DetectMaskRequest`。
    2.  设置图片 URL。
    3.  调用接口获取响应。
*   **返回参数 `mask` 含义**：
    *   `0`: 未检测出人脸或清晰度不够。
    *   `1`: 未戴口罩。
    *   `2`: 已戴口罩。
    *   `3`: 口罩佩戴不规范。
*   **其他返回字段**：
    *   `faceProbability`: 检测结果的可信度。

## 5. 图片内容安全实战教程

### 背景与前提
*   **背景**：利用视觉分析和深度识别技术，降低色情、涉恐、涉政、广告等违规风险，减少人工审核成本。
*   **前提条件**：
    1.  开通“内容安全”能力。
    2.  添加内容安全 SDK 依赖：
        ```xml
        <dependency>
            <groupId>com.aliyun</groupId>
            <artifactId>aliyun-java-sdk-imageaudit</artifactId>
            <version>1.0.6</version>
        </dependency>
        ```

### 功能：图片内容安全检测 (`ScanImage`)
*   **支持场景**：
    *   `porn`: 智能鉴黄
    *   `terrorism`: 涉恐涉政识别
    *   `ad`: 图文违规/广告识别
    *   `live`: 不良场景识别
    *   `logo`: Logo 识别
*   **核心代码逻辑**：
    1.  创建 `ScanImageRequest`。
    2.  构建 `Task` 列表，每个 Task 包含唯一的 `DataId` 和待检测图片的 `ImageURL`。
    3.  设置 `Scenes` 列表，指定需要检测的场景（如同时检测 porn 和 terrorism）。
    4.  调用接口获取响应。
*   **返回结果解析**：
    *   `Results`: 包含每个任务的检测结果。
    *   `SubResults`: 包含各个场景的具体结果。
        *   `Suggestion`: 建议动作 (`pass`: 通过, `block`: 拦截, `review`: 人工复审)。
        *   `Rate`: 置信度分数。
        *   `Label`: 具体标签（如 `normal`, `weapon`, `sexy` 等）。
        *   `Scene`: 对应的检测场景。

## 开发注意事项汇总

1.  **地域一致性**：所有使用的 OSS 图片 URL 必须与开通服务的地域（如 `cn-shanghai`）一致，否则接口可能无法访问图片。
2.  **依赖管理**：不同功能模块（人脸、内容安全）需要引入不同的 SDK artifactId，请根据需求准确引入。
3.  **异步与延迟**：在人脸搜索教程中，添加人脸后建议增加短暂休眠（如 `Thread.sleep(3000)`），以确保数据索引建立完成后再进行搜索，提高搜索准确率。
4.  **异常处理**：代码示例中均包含了 `ServerException` 和 `ClientException` 的捕获，实际开发中应完善日志记录和错误重试机制。
5.  **数据安全**：AccessKey ID 和 Secret 不应硬编码在代码中，建议使用环境变量或配置中心管理。
