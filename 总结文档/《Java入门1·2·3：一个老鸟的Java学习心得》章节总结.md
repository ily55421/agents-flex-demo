## 第1章：让自己的第一个Java程序跑起来

### 核心论点
- **问题**：如何下载、安装、配置JDK，并编写、编译、运行第一个Java程序（HelloWorld）？
- **观点**：本章目的是让读者对Java有感性认识，搭建好开发环境，为后续学习打好基础。

### 关键概念/事件
- **JDK（Java SE Development Kit）**：Java开发工具包，是整个Java世界的基础。
- **JVM（Java虚拟机）**：执行Java程序的核心，通过`java`命令启动。
- **Java编译器（javac）**：将源程序（.java）编译成字节码（.class）。
- **main()方法**：Java程序的入口，Java平台先寻找main()方法再执行。
- **环境变量**：Path、CLASSPATH、JAVA_HOME的配置。

### 逻辑推演/叙事脉络
本章从Java的优势和广泛应用入手，激发学习兴趣。然后分步骤引导读者：下载JDK → 安装 → 配置环境变量 → 测试安装是否成功 → 编写HelloWorld源程序 → 编译 → 运行。遇到编译错误时，给出常见错误类型（中文标点、括号不匹配、单词拼错）及排查方法。最后用流程图解释整个流程（源程序→编译器→字节码→JVM→运行），并简要介绍类、方法、main()的概念。

### 经典金句/数据
> “Java程序的入口是叫做main()的方法。如果执行一个程序的时候Java平台找不到main()方法，就会抛出错误并停止执行。” (p.15)

> 编译命令：`javac HelloWorld.java`；运行命令：`java HelloWorld` (p.11-13)

## 第3章：Java中的基本数据类型和运算符

### 核心论点
- **问题**：Java中有哪些基本数据类型？如何通过运算符操作这些数据？
- **观点**：基本数据类型是Java中的“数据原子”，运算符是对这些原子进行操作的规则。

### 关键概念/事件
- **8种基本类型**：byte、short、int、long、float、double、char、boolean。
- **变量**：变量名、变量类型、变量值三要素，命名规则（字母/下划线开头，不能是关键字）。
- **运算符**：赋值(=)、算术(+、-、*、/、%)、关系(==、!=、>、<、>=、<=)、逻辑(&、&&、|、||、!)、括号()。
- **类型转换**：低精度→高精度自动转换；高精度→低精度需强制类型转换`(type)`，可能丢失精度。
- **String**：不是基本类型，但常用；可用`+`拼接，与基本类型相加时自动转字符串。

### 逻辑推演/叙事脉络
从“数据原子”比喻引入基本类型，逐一介绍各类型的值域和用途。然后引入变量概念，讲解变量命名规则和创建语法。接着分类讲解运算符：赋值、算术、括号、余数、布尔（值对比+逻辑）。之后转入难点：强制类型转换（小数去哪了）、运算中的自动类型提升、等号的返回值、浮点数比较（不能用==，应用差值绝对值）、boolean和char用法、String的“加法”。最后介绍转义符（\n、\t等）。每节后有小结。

### 经典金句/数据
> “Java中，浮点数没有绝对的相等，只有近似的相等。判断两个浮点数是否相等，应使用它们的差的绝对值与一个我们关心的精度进行比较。” (p.54)

> 自增(++)、自减(--)：前加加先自增再使用，后加加先使用再自增。(p.60)

## 第4章：Java中的程序执行流程

### 核心论点
- **问题**：如何让程序根据条件判断、循环执行，从而实现复杂的逻辑？
- **观点**：Java通过顺序、分支（if-else、switch）、循环（while、do-while、for）三种流程控制语句，让程序不再“直肠子”。

### 关键概念/事件
- **if语句**：根据boolean条件决定是否执行代码块。
- **if-else语句**：二选一分支。
- **switch语句**：根据int或char变量的值多路分支，case后必须跟定值，break跳出。
- **while/do-while**：循环执行，do-while至少执行一次。
- **for循环**：适合固定次数循环，包含初始化、条件、迭代三部分。
- **break/continue**：break终止整个循环，continue终止本次循环。

### 逻辑推演/叙事脉络
从顺序执行出发，引出“判断”需求→if语句→if-else→嵌套if-else。然后引入循环：while语句（先判断后执行）→do-while（先执行后判断）→for循环（结构清晰）。接着讲自增自减作为for的辅助。之后是嵌套循环、break和continue的用法。最后用switch语句作多路分支。本章结尾给出一个综合例程：从控制台读取数据模拟超市结账程序（用for+do-while）。

### 经典金句/数据
> “continue关键字用来结束循环体的本次执行；break关键字用来终止整个循环。” (p.88-89)

> switch语句中，case后的条件值必须是确定的int或char值（定值），不能是变量。(p.90)

## 第5章：数组

### 核心论点
- **问题**：如何批量创建相同类型的变量并统一管理？（如存储全班50个学生的成绩）
- **观点**：数组是“0个或多个相同类型的变量组合”，通过下标访问，下标从0开始。

### 关键概念/事件
- **数组声明**：`int[] students;`
- **数组创建**：`students = new int[5];` 或简洁语法 `int[] students = {55,66,77,88,99};`
- **数组下标**：从0到length-1，越界抛出ArrayIndexOutOfBoundsException。
- **数组的“名”与“实”**：数组变量（引用）与数组实体（对象）分离，多个引用可指向同一数组。
- **多维数组**：数组的数组，例如`int[][][] all = new int[5][25][55];`。

### 逻辑推演/叙事脉络
首先通过“需要逐个定义50个变量”的困境引出数组。然后讲解声明、创建、使用数组元素的基本语法，强调下标从0开始和越界错误。接着通过图示深入讲解数组名（引用）与数组实体（对象）的分离关系，以及赋值操作（只改变引用指向，不复制数组）。然后介绍多维数组的本质（数组变量组成的数组）和三维数组模型。最后通过三个综合例程展示数组应用：查询全班最高分、查询全校成绩（三维数组）、生成杨辉三角（二维数组）。

### 经典金句/数据
> “数组下标是从0开始的，所以一个数组的最大合法下标是数组大小减1。” (p.102)

> 多维数组的实质：多维数组是由一级级的一维数组组成的；除了最后一层是真正的数组元素，其余层都是数组变量的数组。(p.115-116)

## 第6章：Java的类（Class）和对象（Object）

### 核心论点
- **问题**：如何将多个相关的变量（如汽车的速度、颜色、名字、方向）封装成一个整体，形成新的数据类型？
- **观点**：类是抽象的定义（“图纸”），对象是具体的实例（“房子”），引用是指向对象的“钥匙”。

### 关键概念/事件
- **类（Class）**：封装数据属性和行为方法的模板。定义语法：`public class Car { int speed; String color; }`
- **对象（Object）**：根据类创建出的具体实例，使用`new 类名()`创建。
- **引用（Reference）**：指向对象的变量，通过`.`操作符访问对象的属性和方法。
- **null**：引用不指向任何对象时的值，使用null引用会抛出NullPointerException。
- **构造方法**：与类同名，创建对象时自动调用，用于初始化属性。

### 逻辑推演/叙事脉络
从“记录汽车信息需要4个独立变量”的痛点出发，引出“如何将它们绑定”的问题。然后给出Car类的定义，讲解类的组成（public、class、类名、属性）。接着展示如何使用Car类：声明引用 → `new Car()`创建对象 → 通过引用.属性赋值和访问。通过图示讲解“名与实分离”（引用 vs 对象）。引入null关键字及NullPointerException的避免方法。最后通过类数组、点操作符技巧等加深理解，并总结：类是对一类物体的抽象，对象是具体的个体。

### 经典金句/数据
> “类是一种抽象，它把一类物体的特征抽象出来，通过适当的数据类型表示。对象是类的具体化。” (p.139)

> 引用指向对象所属的类必须和引用的类型匹配。例如：`Car car = new Car();` 不能 `Car car = new UseCar();` (p.144)

## 第7章：Java中的方法——给汽车丰富多彩的功能

### 核心论点
- **问题**：如何为类添加功能（行为）？如何定义参数、返回值，如何实现方法重载？
- **观点**：方法是类的功能，必须属于某个类；通过方法可以操作调用它的对象的属性。

### 关键概念/事件
- **方法定义**：访问控制符 + 返回值类型 + 方法名 + 参数列表 + 方法体。
- **void**：表示方法无返回值。
- **参数**：形式参数（形参）与实在参数（实参），多个参数用逗号隔开。
- **返回值**：使用`return`关键字返回，方法执行到return或右大括号结束。
- **方法重载（overload）**：同一类中多个方法同名但参数列表不同（与返回值无关）。
- **局部变量 vs 实例变量**：局部变量在方法内定义，使用前必须赋值；实例变量在类中定义，有默认值。
- **this关键字**：指向对象自身的引用，用于区分成员变量与局部变量。

### 逻辑推演/叙事脉络
首先从“汽车应该能开动”引出方法，给出driveCar()方法示例。然后详细拆解方法的5个组成部分（访问控制符、返回值、方法名、参数列表、方法体）。接着通过加速方法讲解带参数的方法，通过超速判断讲解返回值，通过重载的加速方法讲解重载（参数匹配原则：精度最小优先）。然后讲解使用类实例作为方法参数（引用传递）。之后区分局部变量与实例变量，介绍this关键字。最后讲解构造方法（特殊方法，与类同名，无返回值，用于初始化对象）。本章内容极为丰富，是本书篇幅最长的一章。

### 经典金句/数据
> “方法签名是由方法名和参数类型决定的，与方法的返回值无关，与形参名无关。” (p.168)

> “方法重载中的参数匹配原则：第一要符合赋值规则，第二精度最小。” (p.171)

> 构造方法：`public Car() { }`，在`new Car()`时自动调用。(p.181-183)

## 第8章：Java中的包（Package）、命名习惯和注释

### 核心论点
- **问题**：如何组织日益增多的类文件，避免命名冲突？
- **观点**：包（package）是Java中组织类的机制，类似于文件系统的文件夹；import语句用于简化类的引用。

### 关键概念/事件
- **包（package）**：将相关类放在同一包中，全限定名 = 包名 + 类名。
- **import**：引入其他包中的类，避免写全限定名。
- **命名习惯**：包名全部小写（如com.javaeasy），类名首字母大写，方法名首字母小写驼峰。
- **注释**：单行注释`//`、多行注释`/* */`、Javadoc注释`/** */`。

### 逻辑推演/叙事脉络
首先提出问题：当类越来越多时如何组织？引入包的概念，并演示在Eclipse中创建包和类。讲解package语句必须在源文件第一行。然后通过对比说明import的作用（化繁为简），以及import冲突时的全限定名解决。接着回顾命名习惯（标识符规则 + 惯例）。最后介绍三种注释，重点讲Javadoc（可用javadoc工具生成API文档）。

### 经典金句/数据
> “包让Java的类更清晰优雅。建议以域名的倒序作为包名的前缀，如com.javaeasy。” (p.193-194)

> Javadoc注释以`/**`开头，`*/`结尾，可用@author、@param、@return等标签。(p.206-207)

## 第9章：再看数组、字符串和main()方法

### 核心论点
- **问题**：数组也是类吗？String类有哪些常用方法？main()方法的参数和static关键字有何含义？
- **观点**：数组在Java中也是对象，有length属性；String是不可变字符串，常用方法需掌握；static修饰的方法属于类而非实例。

### 关键概念/事件
- **数组的length属性**：获取数组长度（不是length()方法）。
- **final变量**：值不可改变的变量，必须在创建时赋值。
- **String类常用方法**：charAt()、substring()、equals()、split()、indexOf()、replace()等。
- **String vs StringBuffer**：String不可变，StringBuffer可变（适合频繁修改）。
- **main()方法**：`public static void main(String[] args)`，args接收命令行参数。
- **static关键字**：静态方法属于类，可通过类名调用，不能直接访问非静态成员。

### 逻辑推演/叙事脉络
首先回顾数组是类，有length属性和clone()方法，并探讨多维数组的length含义。然后深入String类：遍历字符、获取子串、判断相等（用equals而非==）、分割、查找、替换，并强调String对象的不可变性（“磐石刻字”）。接着介绍StringBuffer作为可变的替代。最后重新审视main()方法：解释String[] args参数（运行时可传入参数），以及static关键字的含义（类级别，无需实例）。

### 经典金句/数据
> “String对象是不可变的，任何对字符串的修改都会产生一个新的String对象。” (p.227)

> main()方法的签名：`public static void main(String[] args)`，JVM通过这个签名找到程序入口。(p.229-230)

## 第10章：继承和多态

### 核心论点
- **问题**：如何实现代码复用，并让子类拥有父类的属性和方法？如何让一个对象表现出多种形态？
- **观点**：继承是面向对象的核心，子类通过extends继承父类，并可以覆盖（override）父类方法；多态允许父类引用指向子类对象，运行时动态绑定方法。

### 关键概念/事件
- **继承（extends）**：子类继承父类的非私有属性和方法，Java只支持单继承。
- **覆盖（Override）**：子类重新定义父类的方法，方法签名必须相同，返回值可协变。
- **super关键字**：调用父类的构造方法或被覆盖的方法。
- **多态（Polymorphism）**：父类引用指向子类对象，调用方法时执行子类的覆盖版本。
- **Object类**：所有类的根父类，有toString()、equals()、hashCode()等方法。
- **instanceof运算符**：判断一个对象是否为某个类的实例。

### 逻辑推演/叙事脉络
从“汽车类、公交车类、跑车类”的重复代码问题入手，引出继承解决方案。先讲解访问控制符对继承的影响，然后定义CarBase父类，Bus子类通过extends继承，并演示如何覆盖speedUp()方法。接着讲解子类对象中隐含父类对象，构造方法调用链（super()）。然后重点讲多态：父类引用指向子类对象，调用覆盖方法时执行子类版本。最后通过Class类和instanceof运算符拨开多态的迷雾。本章配有大量类图和流程图。

### 经典金句/数据
> “继承让代码被最大程度地重用；多态让子类中的方法可以覆盖父类的方法，从而‘屏蔽’自己不想要的代码。” (p.287)

> 子类构造方法的第一行默认有`super()`调用父类无参构造；如果父类没有无参构造，子类必须显式调用`super(参数)`。(p.254-256)

## 第11章：修饰符（Qualifier）

### 核心论点
- **问题**：Java中的public、protected、private、static、final等修饰符分别控制什么？
- **观点**：访问控制符控制可见性（够用就行，尽量缩小范围）；static表示类级别；final表示不可改变。

### 关键概念/事件
- **访问控制符**：public（任何地方）、protected（子类+同包）、默认（同包）、private（仅本类）。
- **final**：修饰类（不可继承）、修饰方法（不可覆盖）、修饰变量（值不可变）。
- **static**：修饰方法（静态方法，类方法）、修饰变量（静态变量，类变量）。
- **成员变量 vs 局部变量**：成员变量有默认值，可用private保护；局部变量只能用final。
- **getter/setter模式**：private成员变量 + public get/set方法，可加入校验逻辑。

### 逻辑推演/叙事脉络
首先将类的组成部分分为成员变量和成员方法，然后分类讲解修饰符。按类、方法、变量的顺序，逐一讲解每个修饰符的作用、语法、典型用法。重点强调：成员变量应尽量用private，通过getter/setter访问；静态方法属于类，不存在多态；final修饰引用时，不可变的是引用本身，而非引用指向的对象。最后用表格汇总可见性。

### 经典金句/数据
> “修饰符就是红绿灯，指挥着马路上的汽车来来往往……正确地使用修饰符会让程序避免不必要的错误。” (p.328)

> 使用private修饰成员变量，然后提供public的get/set方法，可以避免对象状态错误。(p.318-320)

## 第12章：接口

### 核心论点
- **问题**：如何让不相关的类（如汽车和自行车）具备共同的行为规范，同时避免单继承的限制？
- **观点**：接口是一种抽象类型，定义了一组方法规范；类通过implements实现接口，从而获得额外类型，实现“面向接口编程”。

### 关键概念/事件
- **接口（interface）**：所有方法都是抽象的（无方法体），可包含常量（public static final）。
- **implements**：类实现接口的关键字，必须实现接口中所有抽象方法。
- **接口的作用**：斩断程序对外部具体类的依赖，提高可扩展性。
- **接口与类型**：实现接口的类同时具有接口类型，接口引用可指向实现类对象。
- **空接口**：没有方法，仅用于给类增加类型标记（如Serializable）。

### 逻辑推演/叙事脉络
从“记录自行车状态”的需求变化出发，暴露出使用`instanceof`导致代码臃肿的问题。引出“理想参数类型”的设想，然后正式介绍接口：定义Recordable接口，包含getTransportStatus()方法。让CarBase和Bike都实现该接口，从而recordTransport()方法的参数可统一为Recordable类型，无需再判断具体类。接着深入讲解接口的语法（省略abstract和public）、实现多接口、接口中的常量、接口继承、空接口等。最后强调“面向接口编程”的思想。

### 经典金句/数据
> “接口就好比一个屏障，斩断了程序对外部程序的依赖，让外部程序以统一的‘面孔’展现给内部程序。” (p.351)

> 接口中的变量必须是public static final的，这些修饰符可以省略。(p.357)

## 第13章：抽象类和内部类

### 核心论点
- **问题**：如何强制子类必须覆盖某些方法？如何在一个类内部再定义辅助类？
- **观点**：抽象类（abstract class）是包含抽象方法的类，不能实例化，用于强制子类实现抽象方法；内部类（inner class）定义在类或方法内部，用于辅助外部类。

### 关键概念/事件
- **抽象类**：使用abstract修饰，可包含抽象方法和具体方法，不能new。
- **抽象方法**：只有声明没有实现，子类必须覆盖（除非子类也是抽象类）。
- **成员内部类**：定义在类内部的类，可访问外部类的所有成员（包括private）。
- **局部内部类**：定义在方法内部的类，只能访问方法中的final变量。
- **匿名内部类**：没有名字的内部类，常用于实现接口或抽象类，一次性使用。

### 逻辑推演/叙事脉络
从Person类的introduceSelf()方法“空实现但不该被调用”的问题出发，引出抽象方法：将introduceSelf()改为abstract，Person变为抽象类。然后讲解抽象类的语法规则。之后转入内部类：先分类（成员内部类、局部内部类），重点讲成员内部类如何访问外部类成员（通过隐藏的`外部类.this`引用），以及静态内部类与非静态的区别。接着讲局部内部类的作用域和final变量限制。最后讲匿名内部类的语法（new接口/抽象类 { 实现方法 }）。总结部分用图表展示内部类的完整分类。

### 经典金句/数据
> “抽象类的作用：在语法层面上强制其子类覆盖某些方法，让程序避免做一些不应该做的事情。” (p.369)

> 非静态内部类中隐含一个指向外部类对象的引用，名为`外部类名.this`。(p.378)

## 第14章：Java的异常处理机制

### 核心论点
- **问题**：程序运行时如何优雅地处理错误（如除数为零、数组越界、文件不存在）？
- **观点**：Java异常机制通过抛出（throw）、传递（throws）和捕捉（try-catch-finally）三个环节，将错误处理与正常业务逻辑分离。

### 关键概念/事件
- **异常类体系**：Throwable → Error（严重错误，不处理）、Exception（必须处理或声明）、RuntimeException（运行时异常，可不处理）。
- **throw**：在方法内抛出异常实例。
- **throws**：在方法声明中声明可能抛出的异常类型，将异常向上传递。
- **try-catch-finally**：try块包裹可能出错的代码，catch块处理特定异常，finally块始终执行。
- **自定义异常**：继承Exception或RuntimeException，提供构造方法。

### 逻辑推演/叙事脉络
先通过NumberFormatException区分“编译错误”与“运行时异常”。然后讲解异常类的继承关系（Throwable）。接着以Cup类的setCapacity()为例，展示如何用throw抛出异常，用throws声明异常，并创建自定义异常类（CapacityTooBigException等）。然后通过例程展示异常的传递链（从setCapacity → designCupCapacity → main → JVM）。最后重点讲异常处理：try-catch的匹配规则，多catch的顺序，finally的作用（资源释放），以及三种异常类型（Exception、RuntimeException、Error）的不同处理要求。

### 经典金句/数据
> “异常机制是Java语言提供的一个功能，它的目的是：‘与其让错误听之任之地发生，不如把错误明明白白地描述出来，将错误传递到可以处理它的地方进行处理。’” (p.435)

> RuntimeException（如NullPointerException）代表Java平台正常操作可能发生的异常，不强制要求处理。(p.434)

## 第15章：多线程编程

### 核心论点
- **问题**：如何让程序同时执行多个任务（如同时下载多个文件）？如何协调多个线程对共享资源的访问？
- **观点**：线程是代码执行的基本单位；通过继承Thread或实现Runnable创建线程；通过synchronized实现线程同步，避免数据错乱。

### 关键概念/事件
- **线程（Thread）**：执行代码的“机器”，通过start()启动，run()方法存放任务代码。
- **两种创建方式**：继承Thread（覆盖run）或实现Runnable（更灵活）。
- **线程状态**：新建、就绪、运行、挂起（sleep、wait、等待锁）、终止。
- **synchronized**：同步方法/代码块，同一时刻只允许一个线程执行，保证共享数据的原子性。
- **wait/notify**：Object类的方法，用于线程间协作（等待条件满足后唤醒）。
- **锁（Lock）**：每个对象有对象锁，每个类有类锁，synchronized依赖锁机制。

### 逻辑推演/叙事脉络
首先用“CD机模型”和“演奏会模型”类比线程的作用（执行代码）。然后讲两种创建线程的方式，并通过多个线程同时输出数字的例子展示多线程的随机性。接着用“复印社模型”引出线程同步问题：多个员工抢一台复印机。然后引入synchronized关键字解决，并用“银行账户模型”详细演示没有同步时的错误（余额变负数），以及同步后的正确结果。再讲解synchronized的底层机制（锁）。最后讲wait/notify方法用于线程间通信，以及顺序错误导致的死等。

### 经典金句/数据
> “线程是执行Java代码的基本单位，一个线程会从某个方法（如main()）开始，一行行地执行代码，直到方法结束。” (p.438)

> “同步方法的本质是：在多线程环境下，保证变量是由某个线程独享的。” (p.481)

> sleep()是静态方法，让当前线程挂起；wait()是实例方法，释放锁并挂起；notify()唤醒等待线程。(p.453, 488)

## 第19章：Java Socket编程

### 核心论点
- **问题**：如何让运行在不同计算机上的Java程序通过网络通信？
- **观点**：Socket编程基于IP地址和端口号；TCP是面向连接的可靠协议，UDP是无连接的不可靠协议。

### 关键概念/事件
- **IP地址**：计算机在网络中的唯一标识。
- **端口号**：0~65535，标识计算机上特定进程。
- **TCP（传输控制协议）**：面向连接、可靠、有序，类似打电话。使用ServerSocket和Socket。
- **UDP（用户数据报协议）**：无连接、不可靠、效率高，类似寄信。使用DatagramSocket和DatagramPacket。
- **Socket通信流程**：服务器端绑定端口监听，客户端连接，双方通过输入/输出流交换数据。

### 逻辑推演/叙事脉络
先解释IP地址和端口号的概念，以及它们如何定位网络中的进程。然后对比TCP和UDP的特点。接着演示TCP编程：服务端用ServerSocket.accept()等待连接，客户端用Socket.connect()，连接后通过getInputStream()和getOutputStream()收发数据。再演示UDP编程：创建DatagramSocket，用DatagramPacket打包数据发送和接收。最后总结两者区别（TCP可靠但慢，UDP快但可能丢包）。

### 经典金句/数据
> “TCP协议是面向连接的、可靠的、有序的，以字节流形式传输数据；UDP协议是无连接的、不可靠的，以数据报形式传输。” (p.552)

## 第22章：JDBC入门

- **JDBC-ODBC桥**：ODBC是Windows的数据库访问标准，JDBC可通过桥接访问ODBC数据源（如Access）。
- **SQL操作**：SELECT（查询）、INSERT（插入）、UPDATE（更新）、DELETE（删除）。
- **ResultSet**：代表查询结果集，通过next()遍历行，getXXX()获取列值。

### 逻辑推演/叙事脉络
首先解释JDBC是什么——一组Java接口，数据库厂商提供实现（驱动）。然后介绍核心API：DriverManager加载驱动，Connection获取连接，Statement执行SQL，ResultSet处理查询结果。接着以ODBC数据源为例，演示如何配置Access数据库的ODBC数据源。然后编写一个简单的数据库操作窗口：用Swing输入SQL语句，执行后显示结果。通过例程展示加载驱动、建立连接、创建Statement、执行查询、遍历ResultSet、关闭连接的完整流程。最后强调PreparedStatement优于Statement（防SQL注入）。

### 经典金句/数据

## 全书总结

《Java入门1·2·3》是一本面向零基础初学者的Java教材，作者以“老鸟”视角，用大量比喻（汽车、CD机、演奏会、复印社、银行账户等）和流程图，将抽象概念具象化。全书按“基本语法 → 面向对象核心 → 进阶应用”三篇递进：

1. **基本语法篇（第1-5章）**：从HelloWorld、Eclipse安装，到数据类型、运算符、流程控制、数组，打下编程基础。
2. **高级语法篇（第6-15章）**：深入讲解类与对象、方法、继承、多态、修饰符、接口、抽象类、内部类、异常、多线程——这些都是Java的核心特色，尤其是“面向对象三大利器（封装、继承、多态）”的剖析。
3. **进阶应用篇（第16-22章）**：转向实际编程，包括集合框架、文件I/O、Socket网络编程、Swing图形界面、JDBC数据库，并综合运用这些知识开发聊天程序和数据表操作窗口。

全书强调“多想多写多练”，每章配有习题，光盘含源代码和教学视频，是一本扎实、细致、适合自学的Java入门教材。
