## 第1章：Rotate Array in Java (数组旋转)
### 核心论点
本章旨在解决将数组向右旋转 k 步的问题，并探讨了从空间换时间到原地操作的不同优化策略。核心观点是通过三次反转（Reversal）可以在 O(n) 时间和 O(1) 空间内高效完成旋转。

### 关键概念/事件
- **中间数组法**：创建新数组复制元素，再拷贝回原数组。时间 O(n)，空间 O(n)。
- **冒泡旋转法**：类似冒泡排序，每次移动一位。时间 O(n*k)，空间 O(1)。
- **三次反转法**：先反转前 n-k 个元素，再反转后 k 个元素，最后反转整个数组。时间 O(n)，空间 O(1)。

### 逻辑推演/叙事脉络
作者首先提出直观的“中间数组”解法，指出其空间复杂度较高。接着引入“冒泡旋转”以节省空间，但指出其时间效率低。最后引出最优解“三次反转法”，通过数学规律证明其能在保证线性时间的同时实现原地操作，并提供了具体的 Java 实现代码。

### 经典金句/数据
> “Can we do this in O(1) space and in O(n) time? The following solution does.” (p.8)

## 第2章：Evaluate Reverse Polish Notation (逆波兰表达式求值)
### 核心论点
本章解决逆波兰表达式（后缀表达式）的计算问题。核心观点是利用栈（Stack）数据结构，遇到数字入栈，遇到运算符弹出两个数计算后结果入栈。

### 关键概念/事件
- **栈的应用**：利用 LIFO 特性处理运算符优先级。
- **JDK版本兼容性**：指出早期 LeetCode 环境不支持 Switch String，需使用字符索引或 if-else 替代。

### 逻辑推演/叙事脉络
作者先给出基于 Stack 和 Switch String 的直观解法，随后指出在特定 LeetCode 环境下可能存在的编译错误（JDK版本问题），并提供了兼容旧版本的替代方案（使用 `indexOf` 获取运算符索引进行 switch int）。

## 第3章：Solution of Longest Palindromic Substring in Java (最长回文子串)
### 核心论点
本章探讨寻找字符串中最长回文子串的多种方法。核心观点是虽然动态规划和中心扩展法均为 O(n^2)，但中心扩展法空间更优；Manacher 算法虽为 O(n) 但过于复杂，面试中通常不要求。

### 关键概念/事件
- **暴力法**：检查所有子串，O(n^3)，超时。
- **动态规划**：构建二维表 `table[i][j]` 记录子串是否为回文，O(n^2) 时间，O(n^2) 空间。
- **中心扩展法**：以每个字符（或双字符）为中心向两边扩展，O(n^2) 时间，O(1) 空间。

### 逻辑推演/叙事脉络
从超时的暴力法入手，引出动态规划解法，详细解释了状态转移方程。随后介绍了更实用的中心扩展法，对比了其空间优势。最后简要提及 Manacher 算法，建议读者无需深究。

### 经典金句/数据
> “Manacher’s algorithm is much more complicated to figure out... Since it is not typical, there is no need to waste time on that.” (p.15)

## 第4章：Solution Word Break (单词拆分 I)
### 核心论点
本章解决判断字符串是否能由字典中的单词拼接而成的问题。核心观点是使用动态规划，定义 `t[i]` 表示前 i 个字符是否可拆分，通过遍历字典匹配子串来更新状态。

### 关键概念/事件
- **递归回溯**： naive 方法，易超时。
- **动态规划**：`t[0]=true`，若 `t[i]` 为真且 `s.substring(i, end)` 在字典中，则 `t[end]=true`。
- **正则表达式**：理论上可行，但 LeetCode 不支持 Pattern 类。

### 逻辑推演/叙事脉络
首先展示简单的递归解法并指出其效率问题。接着重点讲解动态规划解法，强调初始状态 `t[0]=true` 的重要性以及如何处理重叠匹配情况。最后提及正则解法作为理论补充。

### 经典金句/数据
> “One tricky part of this solution is the case: INPUT: 'programcreek', ['programcree','program','creek']. We should get all possible matches, not stop at 'programcree'.” (p.17)

## 第5章：Word Break II (单词拆分 II)
### 核心论点
本章在 Word Break I 的基础上，要求返回所有可能的拆分句子。核心观点是在动态规划记录可达性的基础上，结合深度优先搜索（DFS）回溯构建具体路径。

### 关键概念/事件
- **DP + DFS**：先用 DP 数组 `dp[i]` 记录能构成 `s[0..i]` 的最后一个单词列表，再用 DFS 从末尾向前回溯生成句子。

### 逻辑推演/叙事脉络
指出单纯 DP 只能判断可行性，无法输出路径。因此引入一个存储 List 的 DP 数组，记录每个位置可由哪些单词结尾。最后通过 DFS 遍历该结构，拼接出所有完整句子。

## 第6章：Word Ladder (单词接龙)
### 核心论点
本章解决从一个单词变换到另一个单词的最短路径问题（每次变一个字母）。核心观点是将单词视为图节点，使用广度优先搜索（BFS）保证找到最短路径。

### 关键概念/事件
- **BFS**：使用队列逐层搜索，确保首次到达目标时路径最短。
- ** visited 集合**：使用 HashSet 记录已访问单词，避免循环和重复计算。

### 逻辑推演/叙事脉络
先展示错误的贪心/ naive  approach，指出其无法保证最优解。随后引入 BFS，解释为何 BFS 适合无权图的最短路径问题。代码中使用两个队列分别存储单词和距离，或在节点中封装距离信息。

## 第7章：Median of Two Sorted Arrays Java (两个有序数组的中位数)
### 核心论点
本章解决在两个有序数组中寻找中位数的问题，要求时间复杂度 O(log(m+n))。核心观点是将问题转化为寻找第 K 小元素，并通过二分排除法每次丢弃一半不可能的区间。

### 关键概念/事件
- **第 K 小元素**：中位数即第 (m+n)/2 小的元素。
- **二分排除**：比较两个数组的第 k/2 个元素，较小者所在的数组前半部分不可能包含第 K 小元素，予以排除。

### 逻辑推演/叙事脉络
将中位数问题泛化为 Find Kth Element。通过递归函数，每次比较 A 和 B 中的特定位置元素，根据大小关系削减 k 值和数组起始索引，直至 k=0 或某个数组为空。

## 第8章：Regular Expression Matching in Java (正则表达式匹配)
### 核心论点
本章实现支持 `.` 和 `*` 的正则匹配。核心观点是递归处理，关键在于判断模式串第二个字符是否为 `*`，从而分情况讨论匹配 0 次或多次。

### 关键概念/事件
- **递归分解**：
    1. 若 `p[1] != '*'`：直接匹配首字符，递归剩余部分。
    2. 若 `p[1] == '*'`：尝试匹配 0 次（跳过 `p[0..1]`）或多次（消耗 `s` 的一个字符并保留 `p`）。

### 逻辑推演/叙事脉络
分析正则匹配的两种基本情况。提供简短递归解法和更易读的长篇递归解法。重点在于处理 `*` 时的循环尝试匹配多个字符的情况。

## 第9章：Merge Intervals (合并区间)
### 核心论点
本章解决合并重叠区间的问题。核心观点是先按区间起点排序，然后线性扫描，若当前区间与前一个重叠则合并，否则加入结果集。

### 关键概念/事件
- **自定义 Comparator**：按 `start` 字段排序。
- **线性合并**：维护一个 `prev` 区间，动态更新其 `end` 或将其存入结果。

### 逻辑推演/叙事脉络
强调排序的重要性。排序后，重叠区间必然相邻。遍历排序后的列表，通过比较 `prev.end` 和 `curr.start` 决定是合并还是新增。

## 第10章：Insert Interval (插入区间)
### 核心论点
本章解决向已排序且不重叠的区间列表中插入新区间并合并的问题。核心观点是一次遍历，将区间分为“完全在左侧”、“重叠”、“完全在右侧”三类处理。

### 关键概念/事件
- **三类处理**：
    1. `curr.end < new.start`：无重叠，直接添加 curr。
    2. `curr.start > new.end`：无重叠，添加 new 并更新 new 为 curr。
    3. 重叠：合并 curr 到 new 中（更新 new 的 start/min 和 end/max）。

### 逻辑推演/叙事脉络
利用输入已排序的特性，无需全局排序。遍历时，先收集左侧无关区间，中间合并所有重叠区间，最后收集右侧无关区间。

## 第11章：Two Sum (两数之和)
### 核心论点
本章解决在数组中找到两个数使其和为目标值。核心观点是使用 HashMap 存储 `target - num`，实现 O(n) 时间复杂度。

### 关键概念/事件
- **HashMap**：Key 为差值，Value 为索引。
- **一次遍历**：遍历时检查当前数是否在 Map 中，若在则找到解；若不在，将差值存入 Map。

### 逻辑推演/叙事脉络
对比暴力 O(n^2) 解法，引入 HashMap 优化。强调只需一次遍历即可完成查找和存储。

## 第12章：Two Sum II Input array is sorted (两数之和 II - 输入有序)
### 核心论点
针对有序数组的两数之和问题。核心观点是使用双指针，分别指向头尾，根据和与 target 的大小关系移动指针。

### 关键概念/事件
- **双指针**：`i` 从头开始，`j` 从尾开始。
- **收缩策略**：和太小则 `i++`，和太大则 `j--`。

### 逻辑推演/叙事脉络
利用有序性，避免 HashMap 的空间开销。双指针法保证了 O(n) 时间和 O(1) 空间。

### 逻辑推演/叙事脉络

## 第14章：3Sum (三数之和)
### 核心论点
本章解决找出数组中所有和为 0 的不重复三元组。核心观点是先排序，固定一个数，然后用双指针在剩余部分寻找两数之和。

### 关键概念/事件
- **排序 + 双指针**：外层循环固定 `num[i]`，内层双指针找 `num[j] + num[k] == -num[i]`。
- **去重**：跳过相同的 `num[i]`、`num[j]` 和 `num[k]`。

### 逻辑推演/叙事脉络
从暴力 O(n^3) 引入优化。排序后，利用双指针将内层查找降为 O(n)，总复杂度 O(n^2)。重点在于如何高效去重以避免重复三元组。

## 第15章：4Sum (四数之和)
### 核心论点
本章解决找出数组中所有和为 target 的不重复四元组。核心观点是两层循环固定前两个数，内层用双指针找后两个数，并用 HashSet 去重。

### 关键概念/事件
- **双层循环 + 双指针**：复杂度 O(n^3)。
- **HashSet 去重**：利用 ArrayList 的 hashCode 特性去重。

### 逻辑推演/叙事脉络
类比 3Sum，增加一层循环。由于去重逻辑较繁琐，文中示例使用了 HashSet 来存储结果以自动去重。

## 第18章：Merge Sorted Array (合并有序数组)
### 核心论点
本章解决将两个有序数组合并到其中一个有足够空间的数组中。核心观点是从后往前填充，避免覆盖未处理的元素。

### 关键概念/事件
- **逆向双指针**：从 A 和 B 的末尾开始比较，较大者放入 A 的末尾。
- **处理剩余**：若 B 还有剩余，复制到 A 前端；若 A 有剩余，已在原位无需移动。

### 逻辑推演/叙事脉络

## 第23章：Longest Consecutive Sequence Java (最长连续序列)
### 核心论点
本章在未排序数组中找最长连续序列长度，要求 O(n)。核心观点是使用 HashSet，遍历时仅从序列起点（即 `num-1` 不在集合中）开始计数。

## 第25章：Spiral Matrix (螺旋矩阵)
### 核心论点

## 第28章：Triangle (三角形最小路径和)
### 核心论点
本章求三角形从顶到底的最小路径和。核心观点是自底向上动态规划，`dp[i] = triangle[i][j] + min(dp[i+1][j], dp[i+1][j+1])`。

### 关键概念/事件
- **自底向上 DP**：避免处理边界条件。
- **空间优化**：只需一维数组存储当前行的最小路径和。

### 逻辑推演/叙事脉络
从倒数第二行开始向上迭代。每个位置的最小路径和等于自身值加上下一行相邻两个位置中较小的那个。最终 `dp[0]` 即为结果。

## 第29章：Distinct Subsequences Total (不同的子序列)
### 核心论点
本章计算 S 中有多少个子序列等于 T。核心观点是二维动态规划，`dp[i][j]` 表示 S 的前 i 个字符中 T 的前 j 个字符出现的次数。

### 关键概念/事件
- **DP 状态转移**：
    - 若 `S[i-1] == T[j-1]`: `dp[i][j] = dp[i-1][j-1] + dp[i-1][j]` (用或不用 S[i-1])。
    - 若不等: `dp[i][j] = dp[i-1][j]`。

### 逻辑推演/叙事脉络
构建 `(lenS+1) x (lenT+1)` 的 DP 表。初始化第一列为 1（空串是任何串的子序列）。逐行填充表格，最后返回 `dp[lenS][lenT]`。

- **全局最大值**：维护一个 `maxSoFar`。

### 逻辑推演/叙事脉络
