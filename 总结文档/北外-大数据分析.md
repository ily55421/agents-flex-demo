# 《大数据分析》课程讲义总结

**时间**：2019年2月

## 第一章：大数据分析入门概论

### 1.1 大数据时代背景

*   **应用价值**：大数据应用于统计学、管理学、计算机科学等领域，用于数据挖掘、机器学习和人工智能。
*   **行业趋势**：IBM、EMC、Teradata等巨头通过收购布局大数据市场，核心目标是从数据中寻找价值以辅助商业决策。
*   **媒体案例**：央视《晚间新闻》、《新闻联播》及两会报道首次结合大数据挖掘与可视化，提升了新闻的客观性与科技感。

### 1.2 数据存储与概念

*   **单位换算**：Bit -> Byte -> KB -> MB -> GB -> TB -> PB -> EB -> ZB -> YB。
    *   例：1 PB ≈ 63万部《红楼梦》；谷歌每小时处理1 PB数据。
*   **大数据定义 (4V)**：
    1.  **Volume (大量)**：数据体量从TB跃升至PB/EB级。
    2.  **Variety (多样)**：类型繁多（日志、视频、交易记录、地理位置等）。
    3.  **Velocity (高速)**：处理速度快，“1秒定律”，快速获得高价值信息。
    4.  **Value (价值)**：价值密度低，但合理利用可带来高回报。

### 1.3 经典案例：啤酒与尿布

*   **背景**：沃尔玛通过Apriori算法分析购物篮数据，发现年轻父亲买尿布时常顺便买啤酒。 an
*   **策略**将啤酒与尿布邻近摆放。
*   **结果**：提升连带销售率，增加收入。
*   **启示**：数据分析能发现隐藏关联，优化运营策略。

### 1.4 数据分析与挖掘的应用

*   **客户信息推送**：基于社交网络和用户行为数据，精准细分用户群。
*   **广告靶向投放**：从面向群体的营销转向个性化营销（正确的时间、正确的用户、正确的内容）。
*   **定制服务**：根据消费者喜好判定，提供个性化产品或服务。

### 1.5 数据分析六步曲

1.  **明确目的**：了解需求方真正想要什么。
2.  **数据采集**：一手数据（问卷）或二手数据（数据库）。
3.  **数据处理**：清洗、加工、抽样。
4.  **数据分析**：使用适当方法和工具。
5.  **数据展现**：图表制作与美化。
6.  **报告撰写**：结构化呈现结论与建议。

### 1.6 典型成功案例

*   **犯罪预测**：洛杉矶警察局利用算法预测犯罪高发区，盗窃案降33%，暴力犯罪降21%。
*   **流感预测**：Google Flu Trends利用搜索关键词预测流感散布。
*   **大选预测**：Nate Silver利用大数据算法准确预测2 as012年美国大选结果。
*   **实时定价**：梅西百货基于SAS系统对7300万种货品实时调价。
*   **客户流失预测**：美国运通通过115个变量识别24%的潜在流失客户。

### 1.7 工具介绍

*   **入门级**：Excel（功能强大，覆盖80日常分析需求）。
*   **专业级**：SPSS Statistics。
*   **高级平台**：Matlab, SAS, Cognos, Oracle BI等。

## 第二章：数据准备和数据处理

### 2.1 数据收集

*   **一手数据**：主要通过调查问卷获取。
    *   **数字化处理 a**：
        *   数值题：直接录入。
        *   单选题：编码录入（如男=1, 女=0）。
        *   多选题：**二分法**（每个选项一列，选中为1，未选为0）或**多重分类法**。
        *   排序题：记录排名顺序。
        *   开放题：文本录入。
*   **二手数据**：来自数据库、互联网、咨询公司。
    *   常见格式：关系型数据库表（Oracle, SQL Server, Access），分布式数据库（Hbase, MongoDB）。
    *   导入方式：ODBC接口、TXT文本导入、网站数据抓取。

### 2.2 数据清洗 (Data Cleaning)

*   **原则**：“多一分则肥，少一分则瘦”，确保数据简洁、完整、正确。
*   **步骤**：
    1.  **清除重复数据**: 使用条件格式、透视表或函数辨别并删除。
    2.  **填充缺失数据**:
        *   定位空值 (`Ctrl+G`) 并批量替换（如填0或平均值）。
        *   处理错误标识符（如 `#DIV/0!`）。
        *   *注意*：缺失阈值通常接受范围较小，严重缺失需剔除。
    3.  **检测逻辑错误**:
        *   使用逻辑函数 (`AND`, `OR`, `NOT`, `IF`) 检查数据合理性（如性别代码是否在范围内）。
        *   使用 `COUNTIF` 统计异常值。

### 2.3 数据加工 (Data Processing)

*   **数据提取**:
    *   截取字段部分信息。
    *   合并字段信息。
    *   **匹配信息**: 使用 `VLOOKUP` 或 `HLOOKUP` 从其他表获取数据。
*   **数据计算**:
    *   公式计算 (+, -, *, /, ^)。
    *   函数计算。
*   **数据分组**:
    *   根据业务规则对数据进行分类（如价格区间、年龄段）。
*   **数据转换**:
    *   行列互换。
    *   多选题格式转换（多重分类法转二分法）。
    *   类型转换（如文本转数值，使用 `ISNUMBER`判断）。

### 2.4 数据抽样

*   **目的**: 当总体过大时，通过样本推断总体，节省成本和时间。
*   **方法**:
    *   **随机抽样**: 使用 `RAND()` 函数生成随机数进行筛选。
    *   **周期/等距抽样**: 按固定间隔抽取。

## 第三章：实用数据分析方法

### 3.1 对比分析法

*   **定义**: 通过对比指标认识事物本质。
*   **可比性原则**: 对象、时间、口径必须一致。
*   **类型**:
    *   **空间对比**: 与同行、先进企业或全国平均水平对比。
    *   **绝对数 vs 相对数**:
        *   绝对数反映规模（如GDP总量）。
        *   相对数反映联系程度（如增长率、占比）。
    *   **横向比较**: 同一时间不同总体（静态）。
    *   **纵向比较**: 同一总体不同时间（动态）。

### 3.2 动态分析法

*   **指标**:
    *   **同比**: 与历史同期比（如2016年1月 vs 2015年1月），反映长期趋势。
    *   **环比**: 与上一统计期比（如2016年2月 vs 2016年1月），反映短期变化。
    *   **增长率**: `(本期-上期)/上期`。
    *   **百分点**: 两个百分数之差（如57.6% - 56.1% = 1.5个百分点）。
    *   **倍数与番数**:
        *   倍数：A是B的几倍。
        *   番数：翻一番=2倍，翻两番=4倍 ($2^n$)。

### 3.3 分组分析法

*   **定义**: 按一定标准将数据分为性质不同的组，研究各组特征。
*   **指标**:
    *   **频数**: 某组出现的次数。
    *   **频率**: 频数/总次数。
*   **工具**: **数据透视表** (Pivot Table)，可进行多维度的快速分类汇总、筛选和排序。

### 3.4 结构分析法

*   **定义**: 静态分析，研究总体中各部分的比重。
*   **指标**:
    *   **比例**: 部分占整体的比重。
    *   **比率**: 不同类别数值之间的对比。
*   **应用**: 市场份额分析、人口性别比例分析。

### 3.5 高级数据分析法简介

*   **时间序列分析**: 研究随时间变化的规律。
*   **相关分析**: 研究变量间是否存在依存关系及密切程度。
*   **回归分析**: 确定变量间定量依赖关系，建立模型进行预测。

## 第四章：突破限量的大数据分析

### 4.1 Excel的数据限制与突破

*   **限制**: 传统Excel处理百万行以上数据性能下降。
*   **解决方案**: **PowerPivot**。
    *   **优势**:
        *   内置于Excel 2013+，无需额外安装。
        *   采用内存引擎压缩算法，可处理数百万行数据。
        *   支持多数据源导入（数据库、文本、Web）。
        *   支持多表关联建模。
    *   **功能**: 创建复杂计算列、度量值，生成高性能数据透视表/图。

### 4.2 Excel数据分析工具库

*   **安装**:文件 -> 选项 -> 加载项 -> 分析工具库。
*   **功能**: 提供19种统计分析方法，包括描述统计、直方图、相关系数、回归、移动平均等。

### 4.3 描述性统计指标

* **集中趋势**:

  *   **平均值 (Mean)**: 易受离群值影响。
  *   **中位数 (Median)**: 排序后中间的值，抗干扰能力强。
  *   **众数 (Mode)**: 出现次数最多的值。

* **离散程度**:

  *   **方差 (Variance)**: 数据偏离平均值的程度。
  *   **标准差 (Standard Deviation)**: 方差的平方根，衡量稳定性（标准差越小越稳定）。

* **分布形态**:

  * **偏度 (Skewness)**:

    * =0: 正态分布（对称）。

    * >0: 右偏（正偏态）。

    * <0: 左偏（负偏态）。

  * **峰度 (Kurtosis)**:

    * =0: 标准正态分布。

    * >0: 尖峰（数据更集中）。

    * <0: 平峰（数据更分散）。

### 4.4 直方图分析

*   **作用**: 展示数据分组分布情况，判断是否符合正态分布。
*   **应用**: 考试成绩分布、产品质量控制。

## 第五章：推断统计数据分析

### 5.1 抽样与概率

*   **推断统计**: 通过样本数据推断总体特征。
*   **抽样方法**: 随机抽样、周期抽样、等距抽样。
*   **概率基础**: 样本必须随机抽取才能保证概率有效性。

### 5.2 相关分析 (Correlation Analysis)

*   **目的**: 发现变量间是否存在依存关系及方向/强度。
*   **相关系数 (r)**:
    *   取值范围: [-1, 1]。
    *   **正相关**: r > 0 (同向变化)。
    *   **负相关**: r < 0 (反向变化)。
    *   **强度判断**:
        *   |r| < 0.3: 低度相关。
        *   0.3 ≤ |r| < 0.8: 中度相关。
        *   |r| ≥ 0.8: 高度相关。
        *   |r| = 1: 完全相关（函数关系）。
*   **可视化**: 散点图、折线图。

### 5.3 回归分析 (Regression Analysis)

*   **区别**: 相关分析不分自/因变量，仅看紧密程度；回归分析区分自变量(X)和因变量(Y)，旨在建立预测模型 $Y = a + bX + e$。
*   **步骤**:
    1.  确定自变量和因变量。
    2.  绘制散点图确定模型类型（线性/非线性）。
    3.  估计参数，建立模型。
    4.  **模型检验**:
        *   **拟合优度 ($R^2$)**: 越接近1，拟合效果越好。
        *   **F检验**: 检验模型整体显著性。
        *   **t检验**: 检验单个回归系数的显著性。
    5.  利用模型预测。
*   **类型**:
    *   一元线性回归 vs 多元线性回归。
    *   线性回归 vs 非线性回归（多项式等）。
*   **Excel实现**:
    *   函数: `SLOPE` (斜率), `INTERCEPT` (截距), `RSQ` ($R^2$).
    *   工具库: 回归分析模块。

## 第六章：预测未来的数据分析法

### 6.1 预测分析概述

*   **目的**: 基于过去和现在的数据，预见未来发展趋势。
*   **特点**: 假设趋势延续，数据具有不规则性，不严格考虑因果关系。

### 6.2 时间序列预测法

#### 6.2.1 移动平均法 (Moving Average)

*   **原理**: 计算最近N期的平均值，消除随机波动。
*   **特点**:
    *   期数少：灵敏度高，但波动大。
    *   期数多：平滑效果好，但滞后明显。
*   **适用**: 短期预测，数据波动不大。
*   **二次移动平均**: 在一次移动平均基础上再次平均，用于修正滞后偏差。

#### 6.2.2 指数平滑法 (Exponential Smoothing)

*   **原理**: 加权平均，近期数据权重高，远期数据权重按指数递减。
*   **公式**: $S_t = \alpha \cdot Y_t + (1-\alpha) \cdot S_{t-1}$
    *   $\alpha$: 平滑系数 (0~1)。
    *   $1-\alpha$: 阻尼系数。
*   **$\alpha$ 的选择**:
    *   数据平稳：$\alpha$ 取小值 (0.1~0.3)。
    *   波动较大：$\alpha$ 取大值 (0.6~0.9)，提高灵敏度。
*   **类型**: 一次指数平滑（水平趋势）、二次指数平滑（线性趋势）、三次指数平滑（曲线趋势）。

### 6.3 假设检验与证伪

*   **证伪法**: 提出假设，试图寻找反面证据推翻它。排除不可能，剩下的即为可能。
*   **应用**: 在产品发布、市场预判中，通过排除错误选项来锁定最可能的结果。

## 第七章：展现数据分析 - 让人看懂你的数据分析

### 7.1 数据突出技巧

*   **条件格式**: 数据条、色阶、图标集，直观标记关键数据。

### 7.2 图表选择指南

*   **比较**:
    *   时间变化: **柱形图**、**折线图**。
    *   项目对比: **条形图**、**柱形图**。
*   **构成**:
    *   静态比例: **饼图** (仅一个系列)。
    *   动态构成: **堆积柱形图**、**面积图**。
*   **联系/关系**:
    *   两个变量: **散点图**、**气泡图** (三个变量)。
    *   相关性: **散点图** + 趋势线。
*   **分布**:
    *   单变量: **直方图**。
    *   多变量: **曲面图**。
*   **其他**:
    *   **股价图**: 显示波动范围（最高/最低/收盘）。
    *   **雷达图**: 多维度指标综合评估（如财务指标、能力模型）。
    *   **复合图**: 柱形图+折线图（如销售额+增长率）。

### 7.3 图表美化原则

1.  **简约**: 去除非数据元素（多余网格线、背景色、边框）。
2.  **整洁**: 字体统一（中文黑体，英文Arial/Times New Roman），对齐整齐。
3.  **对比**: 突出关键数据序列，使用颜色引导视线。
4.  **动态图表**: 利用控件（列表框、滑块）和 `OFFSET` 函数实现数据交互展示。

## 第八章：数据分析报告撰写及其自动化

### 8.1 数据分析报告的价值

*   **目的**: 评估环境与发展情况，为决策者提供科学依据，降低风险。
*   **角色**: 连接数据与决策的桥梁。

### 8.2 报告结构

1.  **标题页**: 题目精简干练，注明日期。
2.  **目录**: 清晰的大纲，体现分析思路。
3.  **前言**:
    *   **背景**: 为什么分析？
    *   **目的**: 解决什么问题？
    *   **思路**: 分析框架与方法简述。
4.  **正文**:
    *   核心部分，图文并茂。
    *   原则：能用图不用表，能用表不用文字。
    *   逻辑：事实 -> 观点 -> 论证。
5.  **结尾**:
    *   **结论**: 明确、鲜明、严谨。
    *   **建议**: 基于结论提出的可行性行动方案。
    *   **局限性说明**。
6.  **附录**: 名词解释、计算方法、原始数据备查。

### 8.3 报告撰写原则

*   **框架清晰**: 层次分明，主次得当。
*   **可视化**: 图表生动，增强视觉冲击力。
*   **结论导向**: 每部分分析必有结论，最终指向建议。
*   **自动化**: 利用Excel链接、Power Query等工具实现报告数据的自动更新。

### 8.4 数据分析师素质

*   **态度**: 严谨负责。
*   **思维**: 逻辑清晰，好奇心强。
*   **能力**: 擅长模仿与创新，具备业务理解力。

## 总结与核心观点

1.  **数据是资产，分析是提炼**: 大数据的核心不在于“大”，而在于从海量、多样、高速的数据中提炼出高价值的信息（Value）。
2.  **流程规范化**: 遵循“明确目的->采集->清洗->加工->分析->展现->报告”的标准流程，其中**数据清洗**和**需求明确**是保证质量的关键。
3.  **方法论组合**:
    *   **描述性分析**: 用对比、分组、结构分析看清现状。
    *   **推断性分析**: 用相关、回归分析挖掘变量间深层关系。
    *   **预测性分析**: 用时间序列（移动平均、指数平滑）预测未来趋势。
4.  **工具进阶**: 从Excel基础功能到PowerPivot处理大数据，再到专业统计软件，工具选择应匹配数据规模和分析深度。
5.  **沟通至上**: 分析的终点不是模型，而是**决策**。报告需通过优秀的可视化和清晰的逻辑，将复杂数据转化为易懂的商业洞察。
