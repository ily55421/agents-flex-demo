### 第1题：588，动态规划分割等和子集

#### 核心论点
- **问题**：给定一个正整数数组，判断是否能将其分割成两个元素和相等的子集。
- **核心观点**：转化为经典的0-1背包问题——判断是否存在一些元素的和等于总和的一半。

#### 关键概念/事件
- **0-1背包问题**：每个物品可选或不选，在容量限制下求最大价值。
- **递推公式**：`dp[i][j] = max(dp[i-1][j], dp[i-1][j-nums[i-1]] + nums[i-1])`。
- **一维优化**：将二维dp改为一维，注意第二个for循环倒序，避免覆盖。
- **位运算解法**：利用二进制位表示可组成的和，通过移位和或运算判断。

#### 逻辑推演/叙事脉络
1. 首先计算数组总和sum，若为奇数则直接返回false。
2. 若为偶数，设置target = sum/2，问题转化为能否从数组中选出若干元素使其和为target。
3. 使用动态规划（二维数组）构建递推关系。
4. 优化为一维数组（倒序更新）。
5. 补充位运算解法——通过二进制移位记录可组成的和。

#### 经典金句/数据
> “假设sum/2是一个背包的容量，我们只需要找出一些元素把他放到背包中，如果背包中元素的最大和等于sum/2，说明我们可以把数组分割成相等的两份。”(p.12)

### 第2题：587，最大的以1为边界的正方形

#### 核心论点
- **问题**：在由0和1组成的二维网格中，找出边界全部由1组成的最大正方形子网格，返回其元素数量。
- **核心观点**：分别统计每个格子横向和竖向连续1的个数，再以每个格子为右下角判断是否能构成正方形。

#### 关键概念/事件
- **二维dp数组**：`dp[i][j][0]`表示(i,j)横向连续1的个数，`dp[i][j][1]`表示竖向连续1的个数。
- **计算方式**：当前位置为1时，`dp[i][j][0] = dp[i][j-1][0] + 1`，`dp[i][j][1] = dp[i-1][j][1] + 1`。
- **正方形判定**：以(i,j)为右下角，取`min(横向连续数, 竖向连续数)`作为候选边长，再检查上边和左边的连续1是否足够。

#### 逻辑推演/叙事脉络
1. 遍历网格，计算每个格子的横向和竖向连续1个数。
2. 遍历每个格子，以该格子为正方形右下角，确定候选边长。
3. 缩小边长检查正方形的左边和上边是否满足条件。
4. 记录并更新最大边长，最后返回面积。

#### 经典金句/数据
> “curSide可以认为是正方形下边和右边的长度，我们还需要根据正方形上边和左边的长度来确认是否满足正方形的条件。”(p.22)

### 第3题：576，动态规划解最长公共子串

#### 核心论点
- **问题**：给定两个字符串，输出它们的最长公共子串（连续）。
- **核心观点**：定义`dp[i][j]`表示以str1第i个字符和str2第j个字符为结尾的最长公共子串长度，当字符相等时`dp[i][j] = dp[i-1][j-1] + 1`。

#### 关键概念/事件
- **子串与子序列的区别**：子串必须连续，子序列可以不连续。
- **递推公式**：`if(s1.charAt(i) == s2.charAt(j)) dp[i][j] = dp[i-1][j-1] + 1; else dp[i][j] = 0;`
- **一维优化**：使用一维数组，注意内层循环倒序。

#### 逻辑推演/叙事脉络
1. 定义二维dp数组记录以每个位置结尾的最长公共子串长度。
2. 遍历两个字符串，当字符相等时递推。
3. 记录最大值及结束位置。
4. 最后截取子串返回。
5. 空间优化为一维数组。

> “子序列可以是不连续的，但子串一定是连续的。”(p.24)

### 第4题：573，动态规划解单词拆分

#### 核心论点
- **问题**：给定字符串s和单词字典wordDict，判断s是否能被拆分成字典中的单词。
- **核心观点**：定义`dp[i]`表示s前i个字符能否被拆分，`dp[i] = dp[j] && dict.contains(s.substring(j, i))`。

#### 关键概念/事件
- **完全背包问题**：字典中的单词可以重复使用，相当于完全背包。
- **递推公式**：`dp[i] = dp[j] && wordDict.contains(s.substring(j, i))`。
- **边界条件**：`dp[0] = true`（空字符串可拆分）。

#### 逻辑推演/叙事脉络
1. 定义dp数组，`dp[0]=true`作为边界。
2. 遍历每个位置i，枚举所有可能的拆分点j。
3. 如果`dp[j]`为true且子串`[j,i)`在字典中，则`dp[i]=true`。
4. 返回`dp[s.length()]`。
5. 也可用DFS/BFS求解（后续章节展开）。

> “我们可以把它看作是一个完全背包问题，背包就是字符串s，而所选择的商品就是字典中的字符串。”(p.31)

### 第5题：572，动态规划分解割回文串 III

#### 核心论点
- **问题**：将字符串s分割成k个非空回文子串，允许修改字符，求最少修改次数。
- **核心观点**：定义`dp[i][j]`表示前i个字符分割成j个回文子串的最少修改次数，`dp[i][j] = min(dp[m][j-1] + change(s, m, i-1))`。

#### 关键概念/事件
- **回文修改计算**：子串`[left, right]`变成回文串所需修改次数——双指针比较，不同则count++。
- **预处理优化**：先计算所有子串的修改次数存储到`palindrome`数组，避免重复计算。
- **递推公式**：`dp[i][j] = min(dp[m][j-1] + palindrome[m][i-1])`。

#### 逻辑推演/叙事脉络
1. 定义`change(s,left,right)`计算子串变成回文所需修改次数。
2. 定义`dp[i][j]`表示前i个字符分割成j个子串的最小修改次数。
3. 枚举最后一个子串的起点m，利用递推公式计算。
4. 优化：预处理所有子串的修改次数，避免重复计算。
5. 最后返回`dp[length][k]`。

> “动态规划最关键的是找出递推公式，当我们要求dp[i][j]的时候，只需要找出前m个字符分割成j-1个子串所修改的最小字符数+最后一个子串所需要修改字符数。”(p.34)

### 第6题：570，动态规划解回文串分割 IV

#### 核心论点
- **问题**：判断字符串s是否能分割成三个非空回文子串。
- **核心观点**：先计算所有子串是否为回文，再枚举分割点判断三个子串是否都是回文。

#### 关键概念/事件
- **回文子串判断**：使用动态规划或中心扩散法预处理所有子串。
- **枚举分割**：两层循环枚举两个分割点，判断`dp[0][i]`、`dp[i+1][j]`、`dp[j+1][length-1]`是否都为true。

#### 逻辑推演/叙事脉络
1. 使用动态规划计算所有子串是否为回文（`dp[i][j]`）。
2. 两层for循环枚举分割点i和j。
3. 检查三个子串是否都是回文。
4. 若找到一组返回true，否则返回false。

> “如果字符串s比较短的话，上面代码是没有问题的，但如果字符串s比较长，很容易超时。我们可以先计算字符串s的所有子串中哪些是回文的，哪些不是，然后再判断。”(p.40)

### 第7题：568，动态规划解最后一块石头的重量 II

#### 核心论点
- **问题**：有一堆石头，每次选出两块互相粉碎，求最后剩下的一块石头的最小可能重量。
- **核心观点**：转化为将数组分为两部分，使两部分和的差值最小——即0-1背包问题，背包容量为总和的一半。

#### 关键概念/事件
- **问题转化**：相当于把数组分成两组，每组总和相差越小越好。
- **背包容量**：`capacity = sum/2`，求背包能容纳的最大价值。
- **递推公式**：`dp[i][j] = max(dp[i-1][j], dp[i-1][j-stones[i-1]] + stones[i-1])`。

#### 逻辑推演/叙事脉络
1. 计算总和sum，背包容量为sum/2。
2. 使用0-1背包动态规划求背包能容纳的最大价值x。
3. 另一组和为sum-x，差值 = `(sum-x) - x = sum - 2x`。
4. 返回差值（即最后一块石头的重量）。
5. 优化为一维数组。

> “这题相当于把一群战斗力各不相同的人分为两组，每组战斗力总和相差越小越好，也就是把数组分为两部分，这两部分的差值尽可能小。”(p.43)

### 第8题：559，动态规划解不相交的线

#### 核心论点
- **问题**：在两条水平线上按给定顺序写下整数，可以绘制连接相等数字的直线，要求直线不相交，求最大连线数。
- **核心观点**：本质是求最长公共子序列（LCS）问题。

#### 关键概念/事件
- **LCS递推公式**：`if(nums1[i] == nums2[j]) dp[i][j] = dp[i-1][j-1] + 1; else dp[i][j] = max(dp[i-1][j], dp[i][j-1])`。
- **空间优化**：使用一维数组，注意保存左上角的值。

#### 逻辑推演/叙事脉络
1. 定义`dp[i][j]`表示nums1前i个和nums2前j个元素的最大连线数。
2. 当元素相等时，对角线加1。
3. 当元素不等时，取左边或上边的最大值。
4. 返回`dp[m][n]`。

> “这题其实就是求最长公共子序列问题，只不过换了一种说法。”(p.49)

### 第9题：557，动态规划解戳气球

#### 核心论点
- **问题**：戳破所有气球，每次戳破获得`nums[i-1]*nums[i]*nums[i+1]`枚硬币，求最大硬币数。
- **核心观点**：定义`dp[i][j]`表示戳破开区间(i,j)中所有气球获得的最大硬币数，选择最后一个戳破的气球k进行划分。

#### 关键概念/事件
- **开区间定义**：`(left, right)`表示区间内气球可戳，left和right是边界（不戳破）。
- **递推公式**：`sum = temp[i]*temp[k]*temp[j] + dp[i][k] + dp[k][j]`。
- **记忆化递归**：用map存储已计算结果，避免重复计算。

#### 逻辑推演/叙事脉络
1. 在数组两端添加1作为虚拟边界。
2. 定义递归/动态规划函数，在开区间(left,right)中选择最后戳破的气球k。
3. 递推计算最大硬币数。
4. 使用记忆化优化。
5. 最终返回`dp[0][length+1]`。

> “如果一个气球被戳破后，本来不挨着的两个气球可能变成挨着的了，这样还是不好计算。我们可以这样来计算，在开区间(i,j)中随便找一个气球，假如是k，我们让k成为最后一个被戳破的气球。”(p.54)

### 第10题：553，动态规划分解割回文串 II

#### 核心论点
- **问题**：将字符串s分割成若干回文子串，求最少分割次数。
- **核心观点**：定义`dp[i]`表示前i个字符的最少分割次数，`dp[i] = min(dp[j-1] + 1)`，其中子串`[j,i]`是回文。

#### 关键概念/事件
- **递推公式**：`dp[i] = min(dp[i], dp[j-1] + 1)`（当`[j,i]`为回文时）。
- **预处理优化**：先计算所有子串是否为回文（`palindrome`数组）。
- **边界条件**：`dp[0]=0`。

#### 逻辑推演/叙事脉络
1. 定义`dp[i]`表示前i个字符的最少分割次数。
2. 若`[0,i]`本身就是回文，`dp[i]=0`。
3. 否则枚举分割点j，若`[j,i]`是回文，则`dp[i]=min(dp[i], dp[j-1]+1)`。
4. 预处理所有子串是否为回文，提高效率。
5. 返回`dp[length-1]`。

> “定义dp[i]表示字符串前i个字符构成的子串能分隔的最少分隔次数，如果要求s的最少分隔次数，只需要返回dp[length-1]即可。”(p.57)

### 第11题：552，动态规划解统计全为1的正方形子矩阵

#### 核心论点
- **问题**：统计矩阵中所有全为1的正方形子矩阵的个数。
- **核心观点**：`dp[i][j]`表示以(i,j)为右下角的最大正方形边长，同时该位置作为右下角的正方形个数就等于`dp[i][j]`。

#### 关键概念/事件
- **递推公式**：`dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1`（当`matrix[i][j]==1`时）。
- **计数方式**：累加所有`dp[i][j]`的值即为正方形总数。

#### 逻辑推演/叙事脉络
1. 定义`dp`数组，比原矩阵多一行一列方便边界处理。
2. 遍历矩阵，遇到1时用递推公式计算`dp[i+1][j+1]`。
3. 将`dp[i+1][j+1]`累加到count中。
4. 返回count。

> “以坐标(i,j)为右下角的最大正方形边长就是以(i,j)为右下角正方形的个数。”(p.63)

### 第12题：548，动态规划解最长的斐波那契子序列的长度

#### 核心论点
- **问题**：在严格递增的正整数数组中找到最长的斐波那契式子序列的长度。
- **核心观点**：定义`dp[i][j]`表示以`A[i]`和`A[j]`结尾的斐波那契数列的最大长度，`dp[i][j] = dp[k][i] + 1`，其中`A[k] + A[i] = A[j]`。

#### 关键概念/事件
- **斐波那契式序列**：满足`X_i + X_{i+1} = X_{i+2}`的序列。
- **递推公式**：`dp[i][j] = dp[k][i] + 1`。
- **优化方法**：使用map存储值和下标，将查找从O(n)降为O(1)；或使用双指针。

#### 逻辑推演/叙事脉络
1. 定义`dp[i][j]`表示以`A[i]`和`A[j]`结尾的斐波那契数列长度。
2. 枚举`A[j]`，往前查找满足`A[k] + A[i] = A[j]`的`A[i]`。
3. 利用map存储已遍历元素的下标，加速查找。
4. 或使用双指针（因为数组有序）。
5. 返回最大长度（需+2）。

> “定义dp[i][j]表示以A[i]和A[j]结尾的斐波那契数列的最大长度。也就是[......，A[i]，A[j]]构成的斐波那契数列的最大长度。”(p.66)

### 第13题：543，剑指Offer-动态规划解礼物的最大值

#### 核心论点
- **问题**：从矩阵左上角走到右下角，每次只能向右或向下，求路径上礼物价值的最大值。
- **核心观点**：`dp[i][j] = max(dp[i-1][j], dp[i][j-1]) + grid[i][j]`。

#### 关键概念/事件
- **递推公式**：每个位置只能从上方或左方到达，取两者最大值加上当前礼物值。

### 第43题：450，什么叫回溯算法，一看就会，一写就废

#### 核心论点
- **问题**：什么是回溯算法？如何理解和应用？
- **核心观点**：回溯算法是不断尝试的过程，配合递归使用，核心是“选择→递归→撤销选择”的模板。

#### 关键概念/事件
- **回溯模板**：
  ```java
  private void backtrack(参数) {
      if (终止条件) { 处理结果; return; }
      for (选择 : 所有可能) {

          backtrack(新参数);

  }
  ```

- **应用案例**：组合总和、八皇后、全排列、子集、解数独。

#### 逻辑推演/叙事脉络
1. 通过组合总和问题引入回溯思想。

3. 总结回溯算法的通用模板。
4. 以八皇后、全排列、子集、解数独为例演示模板应用。
5. 强调终止条件和撤销选择的重要性。

> “回溯算法其实就是一个不断探索尝试的过程，探索成功了也就成功了，探索失败了就在退一步，继续尝试……”(p.225)

### 第44题：448，组合的几种解决方式

#### 核心论点
- **问题**：从1~n中选出k个数的所有组合（顺序无关）。
- **核心观点**：三种解法——回溯、二进制位、递归公式。

#### 关键概念/事件
- **回溯法**：每次从start开始选择，避免重复组合。
- **二进制位法**：用二进制位表示每个数的选/不选状态。
- **递归公式**：`C(n,k) = C(n-1,k-1) + C(n-1,k)`（选第n个或不选）。

#### 逻辑推演/叙事脉络
1. 回溯法：`combine(n,k)`中遍历i从start到n-k+1，加入i并递归`k-1`。
2. 二进制位法：枚举0~2^n，检查二进制位中1的个数是否为k。
3. 递归法：要么选第n个数，递归`C(n-1,k-1)`并在结果上加n；要么不选，递归`C(n-1,k)`。

> “注意这里只能选择后面的数字不能选择前面的数字，比如我选择了2，就不能在选择1了，否则就会出现[1,2]和[2,1]这种重复的组合。”(p.237)

- **核心观点**：DFS/回溯，从每个非0格子出发，向四个方向递归，记录路径和最大值。

3. 递归四个方向，取返回值的最大值。
4. 恢复当前格子值（回溯）。
5. 返回当前格子值 + 四个方向最大值，并更新全局最大。

### 第49题：516，贪心算法解按要求补齐数组

#### 核心论点
- **问题**：给定已排序的正整数数组nums和正整数n，向数组补充最少数字，使[1,n]内的任意数字都能用数组元素的子集和表示。
- **核心观点**：贪心地补充当前无法表示的最小数字，扩大可表示范围。

#### 关键概念/事件
- **贪心策略**：设当前可表示范围为[1, total)。若`nums[index] <= total`，则范围扩大到`[1, total+nums[index])`；否则补充`total`，范围扩大到`[1, 2*total)`。
- **时间复杂度**：O(m + log n)，m为数组长度。

#### 逻辑推演/叙事脉络
1. 初始化total=1（可表示范围[1, total)），count=0。
2. 遍历nums或补充数字，直到total > n。
3. 若`nums[index] <= total`，则`total += nums[index++]`。
4. 否则补充`total`，`total *= 2`，count++。
5. 返回count。

> “如果需要添加一个构成更大范围的，我们应该选择total+1，而不是total。比如可以构成的数字范围是[1,5]，如果需要添加一个构成更大范围的，我们应该选择6而不是选择5。”(p.261)

### 第50题：505，分发糖果（贪心算法解决）

#### 核心论点
- **问题**：N个孩子站成一排，每个孩子至少分1颗糖，评分更高的孩子比相邻孩子获得更多糖，求最少需要多少颗糖。
- **核心观点**：两次遍历——从左到右保证右边比左边分高时多分，再从右到左保证左边比右边分高时多分。

#### 关键概念/事件
- **两次遍历**：
  - 左→右：`if(ratings[i] > ratings[i-1]) left[i] = left[i-1] + 1`
  - 右→左：`if(ratings[i-1] > ratings[i]) right[i-1] = right[i] + 1`
- **最终结果**：每个孩子取max(left[i], right[i])之和。
- **一次遍历法**：统计递增/递减序列长度，按等差数列求和。

#### 逻辑推演/叙事脉络
1. 初始每个孩子1颗糖。
2. 从左到右遍历，若右边评分高则右边糖数 = 左边糖数+1。
3. 从右到左遍历，若左边评分高且左边糖数 ≤ 右边糖数，则左边糖数 = 右边糖数+1。
4. 求和所有糖数。
5. 提供一次遍历（统计山脉）的优化解法。

> “贪心算法（又称贪婪算法）是指，在对问题求解时，总是做出在当前看来是最好的选择。也就是说，不从整体最优上加以考虑，算法得到的是在某种意义上的局部最优解。”(p.269)

### 第53题：586，BFS和DFS解层数最深叶子节点的和

- **核心观点**：BFS——逐层遍历，每层覆盖上一层的和，最后返回最后一层的和；DFS——记录最大深度，遇更大深度时重置和。

2. 结束时res即为最后一层和。
3. DFS：递归函数接收深度参数，若当前深度>最大深度则更新最大深度并重置sum，若等于则累加。
4. 最后返回sum。

> “BFS是从上到下一层一层的遍历，到最后一层的时候我们再把节点的值相加即可。”(p.275)

### 第58题：531，BFS和动态规划解完全平方数

#### 核心论点
- **问题**：给定正整数n，求最少需要几个完全平方数（1,4,9,...）的和等于n。
- **核心观点**：两种解法——BFS（求最短路径）和动态规划（背包问题）。

#### 关键概念/事件
- **BFS解法**：从0开始，每次加上一个完全平方数，直到到达n，层数即为最少个数。
- **动态规划解法**：`dp[i] = min(dp[i], dp[i - j*j] + 1)`。
- **拉格朗日四平方和定理**：任何自然数最多可由4个完全平方数之和表示。

#### 逻辑推演/叙事脉络
1. BFS：队列初始包含0，每层遍历时，对当前值加上所有不超过n的完全平方数，若等于n则返回层数。
2. 动态规划：初始化`dp[i]=i`，遍历i和j，用递推公式更新。
3. 拉格朗日定理法：先判断1个平方数，再判断4个，再判断2个，否则为3个。

> “每一个节点的值都是从根节点到当前节点的累加。而平方数的个数其实就是遍历到第几层的时候累加和等于target。”(p.297)

- **快慢指针原理**：若有环，快慢指针最终会相遇（距离逐渐缩小）。
- **Set方法**：遍历链表，将节点存入Set，若已存在则有环。
- **逐个删除法**：将节点next指向自身，若出现`head.next == head`则有环。

#### 逻辑推演/叙事脉络
1. 快慢指针：slow=head, fast=head，循环中slow走一步，fast走两步，若相遇返回true。
2. 若fast或fast.next为空，返回false。
3. Set方法：遍历节点，若Set中已存在返回true，否则加入Set。
4. 逐个删除法：递归地将节点next指向自身，直到出现`head.next == head`。

> “假如有环，那么快慢指针最终都会走到环上，快慢指针的间距就要缩小一步，当走n次的时候就会相遇。”(p.369)

### 第81题：564，二叉树最大宽度

### 第89题：488，二叉树的Morris中序和前序遍历

#### 核心论点
- **问题**：用Morris方法实现二叉树的中序和前序遍历（空间复杂度O(1)）。
- **核心观点**：利用叶子节点的空闲指针（右指针）临时指向后继节点，遍历完成后恢复。

#### 关键概念/事件
- **Morris中序遍历原理**：
  1. 若当前节点无左子节点，访问当前节点，然后走向右子节点。
  2. 若有左子节点，找到左子树的最右节点pre：
     - 若pre.right为空，则`pre.right=cur`，cur走向左子节点。
     - 若pre.right指向cur，则`pre.right=null`，访问cur，cur走向右子节点。
- **前序遍历**：在pre.right为空时访问当前节点（不同于中序）。
- **空间复杂度**：O(1)，不使用栈或队列。

#### 逻辑推演/叙事脉络
1. 中序遍历：按照上述规则遍历所有节点，访问顺序为左→根→右。
2. 前序遍历：在建立临时连接时访问当前节点（即`pre.right=cur`时访问cur），遍历顺序为根→左→右。
3. 代码实现中注意遍历条件的判断和恢复操作。

> “Morris的实现原理其实就是把叶子节点的指针给利用起来，因为一般情况下，二叉树的叶子节点是没有子节点的，也就是说他们是指向空，这样总感觉有点浪费。”(p.28)

#### 核心论点
- **问题**：求完全二叉树的节点个数。
- **核心观点**：利用完全二叉树性质——若左子树高度等于右子树高度，左子树为满二叉树，可直接用公式计算；否则右子树为满二叉树。

#### 关键概念/事件
- **高度计算**：`height(root) = 1 + height(root.left)`（沿左边界）。
- **满二叉树公式**：`2^h - 1`。
- **递归计算**：
  - 计算左右子树高度
  - 若`height(left) == height(right)`，左子树满，节点数 = `(1<<height(left)) + countNodes(right)`
  - 否则右子树满，节点数 = `(1<<height(right)) + countNodes(left)`

#### 逻辑推演/叙事脉络
1. 计算完全二叉树的高度h（沿左边界）。
2. 计算右子树高度，若等于h-1，则左子树为满二叉树，递归计算右子树；否则右子树为满二叉树，递归计算左子树。
3. 返回节点数。

> “如果右子树的高度等于height-1，说明左子树是满二叉树，可以通过公式(2^(height-1))-1计算，不需要全部遍历。”(p.46)

- **链表遍历法（O(1)空间）**：

> “每一行都可以看成一个链表，每次只遍历一层节点，然后顺便把子节点串成一个链表，接着遍历下一层节点的时候再把下下一层的结点串成一个链表。”(p.69)

### 第96题：457，二叉搜索树的最近公共祖先

- **问题**：给定二叉搜索树和两个节点，求它们的最近公共祖先。
- **核心观点**：利用BST性质——若p和q都小于当前节点，则LCA在左子树；都大于则在右子树；否则当前节点即为LCA。

#### 关键概念/事件
- **BST特性**：左子树所有节点 < 当前节点 < 右子树所有节点。
- **判断条件**：
  - `(root.val - p.val) * (root.val - q.val) <= 0` → 当前节点即为LCA
  - 否则根据大小关系递归左或右子树
- **非递归/递归**：两种实现方式。

#### 逻辑推演/叙事脉络
1. 非递归：while循环，根据`(p.val < root.val && q.val < root.val)`或`(p.val > root.val && q.val > root.val)`决定移动方向，否则返回root。
2. 递归：类似逻辑，判断后递归调用。
3. 一行代码：`(root.val-p.val)*(root.val-q.val) <= 0 ? root : lowestCommonAncestor(p.val<root.val?root.left:root.right, p, q)`

> “如果两个节点值都小于根节点，说明他们都在根节点的左子树上；如果都大于，说明都在右子树上；如果一个大于一个小于，说明根节点就是最近公共祖先。”(p.74)

### 第106题：403，验证二叉搜索树

### 第107题：401，删除二叉搜索树中的节点

2. BFS（双端队列）：用Deque存储节点，根据层数决定取数方向和入队方向。
3. DFS：递归中若`level == res.size()`则新建列表，偶数层（level%2==0）追加到尾，奇数层插入到头。

### 第111题：387，二叉树中的最大路径和

#### 核心论点
- **问题**：给定二叉树，求最大路径和（路径不一定经过根节点）。
- **核心观点**：后序遍历——计算每个节点作为路径最高点的最大贡献值，同时更新全局最大值。

#### 关键概念/事件
- **节点贡献值**：`gain(node) = node.val + max(0, gain(left), gain(right))`。
- **路径和**：`node.val + max(0, gain(left)) + max(0, gain(right))`。
- **全局最大值**：每个节点计算路径和并更新全局最大。

#### 逻辑推演/叙事脉络
1. 后序遍历递归函数`maxGain(node)`：
   - 若node为空返回0
   - 递归计算左右子树贡献值（负数取0）
   - 当前节点路径和 = node.val + leftGain + rightGain
   - 更新全局最大值
   - 返回节点贡献值 = node.val + max(leftGain, rightGain)
2. 最终返回全局最大值。

> “路径被定义为一条从树中任意节点出发，达到任意节点的序列。该路径至少包含一个节点，且不一定经过根节点。”(p.142)

### 第119题：462，找出两个链表的第一个公共节点

#### 核心论点
- **问题**：找出两个链表的第一个公共节点（交点）。
- **核心观点**：双指针——两个指针分别遍历两个链表，当一个到达末尾时切换到另一个链表，最终相遇点即为交点。

#### 关键概念/事件
- **双指针法原理**：设两链表长度分别为L1和L2，公共部分长度为C，则`L1+(L2-C) = L2+(L1-C)`，两指针会在交点相遇。
- **Set法**：遍历第一个链表存入Set，遍历第二个链表查找。
- **长度差法**：先计算长度差，让长链表先走差值，再同步遍历找交点。

#### 逻辑推演/叙事脉络
1. Set法：遍历链表A，将节点加入Set，遍历链表B，若节点在Set中则返回。
2. 长度差法：计算两链表长度，让长链表先走差值，然后同步遍历直到节点相同。
3. 双指针法：pA=headA, pB=headB，循环直到`pA==pB`，若为空则切换到另一个链表。

> “如果A指针走到链表末尾，下一步就让他从链表B开始。同理如果B指针走到链表末尾，下一步就让他从链表A开始。只要这两个链表相交最终肯定会在相交点相遇。”(p.184)

- **核心观点**：快慢指针——先判断是否有环，相遇后将一个指针重置到头节点，两指针每次一步，再次相遇点即为环入口。

#### 关键概念/事件
- **数学推导**：设头到入口距离a，入口到相遇点距离b，环周长为c。相遇时慢指针走a+b，快指针走a+b+nc，得`a = (n-1)c + (c-b)`，故从头出发和从相遇点出发的指针会在入口相遇。
- **Set法**：遍历链表，将节点存入Set，第一个重复的节点即为入口。
- **删除法**：逐个删除节点（将next指向自身），若出现`head.next == head`则有环。

#### 逻辑推演/叙事脉络
1. 快慢指针：slow和fast从头开始，slow一步，fast两步，相遇则有环。
2. 相遇后，将slow重置为head，slow和fast同时一步，再次相遇点即为入口。
3. Set法：遍历节点存入Set，若已存在则返回该节点。

> “在相遇的时候再使用两个指针，一个从链表起始点开始，一个从相遇点开始，每次他们都走一步，直到再次相遇，那么这个相遇点就是环的入口。”(p.193)

#### 逻辑推演/叙事脉络
1. 初始化两个栈stackPush和stackPop。
2. appendTail：`stackPush.push(value)`。
3. deleteHead：
   - 若stackPop为空，while stackPush非空：`stackPop.push(stackPush.pop())`
   - 若stackPop仍为空，返回-1
   - 否则返回`stackPop.pop()`

> “栈是先进后出的，队列是先进先出的。把stackPush中的元素全部出栈放到stackPop中，然后再删除stackPop中的元素，就可以保证stackPop中的元素永远都是比stackPush中的元素更老。”(p.265)

### 第138题：Manacher(马拉车)算法

#### 核心论点
- **问题**：在线性时间内找出字符串的最长回文子串。
- **核心观点**：通过在字符间插入特殊字符（如#）将奇偶回文统一处理，利用已计算的回文半径避免重复计算。

#### 关键概念/事件
- **预处理**：在每个字符间及首尾插入#，使字符串长度变为奇数。
- **回文半径**：以每个位置为中心的回文子串长度（半径）。
- **核心公式**：
  - 利用对称性：若`p[j] < maxRight - i`，则`p[i] = p[j]`
  - 否则`p[i] = maxRight - i`，再中心扩展
- **时间复杂度**：O(n)。

#### 逻辑推演/叙事脉络
1. 预处理字符串，插入#，得到新字符串res。
2. 初始化p数组（回文半径），maxRight（当前最右边界），maxCenter（对应中心）。
3. 遍历每个位置i：
   - 若i < maxRight，利用对称性初始化`p[i] = min(maxRight-i, p[2*maxCenter-i])`
   - 否则`p[i]=1`
   - 中心扩展直到不等
   - 更新maxRight和maxCenter
   - 更新最长回文半径和中心
4. 计算原字符串中回文子串的起止位置，截取返回。

> “如果i在maxRight的左边，并且j的最大回文长度左边没有到达left，根据对称性，i的最大回文长度就等于j的最大回文长度。”(p.268-269)

### 第142题：371，背包问题系列之-基础背包问题

#### 核心论点

3. 返回`dp[N][V]`。
4. 空间优化为一维数组，注意内层倒序。
5. 提供递归解法。

### 第174题：104，排序-快速排序

#### 核心论点
- **问题**：介绍快速排序算法的原理和多种实现方式。
- **核心观点**：通过分治法，选择基准值（pivot），将小于基准的放左边，大于放右边，递归处理左右。

#### 关键概念/事件
- **基本思路**：选基准，分区，递归。
- **分区方法**：
  - 挖坑法：基准值不动，左右指针交换。

#### 逻辑推演/叙事脉络

3. 双指针交换法：左右指针向中间移动，交换。
4. 非递归实现：栈存储区间边界。

> “快速排序原理是首先要找到一个中枢，把小于中枢的值放到他前面，大于中枢的值放到他的右边，然后再以此方法对这两部分数据分别进行快速排序。”(p.61)

> “归并排序是把待排序序列分为若干个子序列，每个子序列是有序的。然后再把有序子序列合并为整体有序序列。”(p.67)

### 第180题：110，排序-计数排序

#### 核心论点
- **问题**：介绍计数排序算法的原理和实现。
- **核心观点**：统计每个值的出现次数，根据累积计数确定元素位置，是非比较排序，时间复杂度O(n+k)。

#### 关键概念/事件
- **适用范围**：数据范围小（k较小）且为非负整数。
- **步骤**：
  1. 找最大值和最小值
  2. 创建计数数组，长度`max-min+1`
  3. 统计每个值出现次数
  4. 计算累积计数（确定每个值在排序后数组中的位置）
  5. 从后往前填充（保证稳定）
- **稳定性**：从后往前填充可保持稳定。

#### 逻辑推演/叙事脉络
1. 找最大值和最小值。
2. 创建计数数组，统计频次。
3. 计算累积计数（前缀和）。
4. 从原数组末尾开始，根据累积计数填充到新数组，对应计数减1。
5. 将新数组复制回原数组。

> “计数排序是一个非基于比较的排序算法，他首先要找到数组的最大值和最小值然后再根据最大值和最小值申请频率表。”(p.85)

- **核心观点**：用bit位表示数字是否存在，一个bit位代表一个数字，节省内存。

5. 若原数组有重复，输出后长度会变小。

### 第190题：585，最大升序子数组和

#### 核心论点
- **问题**：给定正整数数组，求升序子数组的最大可能元素和。
- **核心观点**：遍历数组，当递增时累加，否则重置sum，记录最大值。

#### 关键概念/事件
- **遍历规则**：
  - 若`nums[i] > nums[i-1]`，`sum += nums[i]`
  - 否则`sum = nums[i]`
  - `max = Math.max(max, sum)`
- **时间复杂度**：O(n)。

- **问题**：书店老板有持续X分钟不生气的秘密技巧，求最多满意的顾客数。
- **核心观点**：滑动窗口——先计算本来就满意的顾客数，再找连续X分钟内不满意顾客和的最大值（因为这段时间内老板不生气可使这些顾客变满意）。

#### 关键概念/事件
- **本来就满意**：`grumpy[i]==0`时的`customers[i]`。
- **可挽回的不满**：`grumpy[i]==1`时的`customers[i]`，求长度为X的滑动窗口最大和。
- **答案**：本来满意和 + 最大可挽回和。

#### 逻辑推演/叙事脉络
1. 遍历数组，累加`grumpy[i]==0`的顾客数。
2. 滑动窗口求`grumpy[i]==1`时customers[i]的最大连续X和。
3. 返回两者之和。

> “老板可以控制K分钟不生气，这个K分钟我们可以把它当做一个窗口，题目就转化为求这个新的数组中连续K个数字的最大和。”(p.166)

### 第210题：521，滑动窗口解最大连续1的个数 III

#### 核心论点
- **问题**：给定0/1数组，最多可将K个0变成1，求最长连续1子数组的长度。
- **核心观点**：滑动窗口——维护窗口内0的个数≤K，右指针扩展，超过时左指针收缩。

#### 关键概念/事件
- **窗口维护**：
  - 右指针移动，若遇到0则zeroCount++
  - 当zeroCount>K时，左指针移动，若左边移出的是0则zeroCount--
  - 窗口大小`right-left`即为当前最长
- **优化**：当zeroCount == K且新加入的是0时，左指针右移，窗口大小不变，直接返回`right-left`。

#### 逻辑推演/叙事脉络
1. 滑动窗口法：right遍历，left和right维护窗口，zeroCount记录0的个数。
2. 当zeroCount > K时移动left。
3. 更新max。
4. 返回max。

> “我们只需要把窗口内0的个数不大于K即可。”(p.169)

### 第211题：518，托普利茨矩阵

#### 核心论点
- **问题**：判断矩阵是否满足每条左上到右下对角线上的元素相同。
- **核心观点**：遍历每个元素，检查是否与其右下角元素相等。

#### 关键概念/事件
- **检查规则**：`matrix[i][j] == matrix[i+1][j+1]`（对于所有非最后一行最后一列的元素）。
- **复杂度**：O(m×n)。

#### 逻辑推演/叙事脉络
1. 两层循环，遍历到`m-1`和`n-1`为止。
2. 若`matrix[i][j] != matrix[i+1][j+1]`，返回false。
3. 返回true。

> “除了最后一行和最后一列外，其他的每个元素都要和右下角的比较，如果不相同直接返回false。”(p.174)

- **步骤**：
  1. Map统计每个数字出现次数
  2. 将Map的values()存入Set

> “集合set是不能有重复元素的，如果有重复的就会被替换掉，那么set的大小肯定和出现次数的数组长度不一样。”(p.177)

### 第213题：509，数组中的第K个最大元素

#### 核心论点
- **问题**：在未排序的数组中找到第k个最大的元素。
- **核心观点**：三种解法——排序、最小堆、快速选择。

#### 关键概念/事件
- **排序法**：`Arrays.sort(nums)`，返回`nums[n-k]`。
- **最小堆法**：维护大小为k的最小堆，遍历数组，堆大小>k时弹出堆顶，最后堆顶即为第k大。
- **快速选择**：利用快排分区，若分区点从后数是第k个则返回，否则在相应侧继续。

#### 逻辑推演/叙事脉络
1. 排序法最简单。
2. 最小堆法适合大数据流。
3. 快速选择法平均O(n)。

> “快速排序是先选择一个中枢，最终会把数组分为两部分，前面部分比中枢值小，后面部分大于或等于中枢值。”(p.179)

### 第214题：506，无重叠区间

#### 核心论点
- **问题**：给定区间集合，求移除最少区间使剩余区间互不重叠。
- **核心观点**：贪心——按区间右端点排序，遍历时若当前区间左端点<前一个右端点，则需移除一个（保留右端点较小的）。

#### 关键概念/事件
- **排序**：按区间右端点升序排序。
- **贪心选择**：
  - 初始化end=intervals[0][1]
  - 遍历后续区间，若`intervals[i][0] < end`，有重叠，count++，`end = min(end, intervals[i][1])`
  - 否则无重叠，`end = intervals[i][1]`

#### 逻辑推演/叙事脉络
1. 按右端点排序。
2. 遍历，遇到重叠则移除右端点较大的区间（保留较小右端点）。
3. 返回移除数量。

> “如果后面区间的头小于当前区间的尾，说明这两个区间有重叠，必须要移除一个，应该移除尾部比较大的，保留尾部比较小的。”(p.182)

### 第215题：504，旋转数组的3种解决方式

#### 核心论点
- **问题**：将数组向右移动k个位置。
- **核心观点**：三种解法——临时数组、三次反转、环形替换。

#### 关键概念/事件
- **临时数组**：新数组`(i+k)%n`位置存入原数组值。
- **三次反转**：
  1. 反转全部
  2. 反转前k个
  3. 反转剩余
- **环形替换**：逐个替换，需要处理循环情况（用visited标记）。

#### 逻辑推演/叙事脉络
1. 临时数组法最简单，需O(n)空间。
2. 三次反转法O(1)空间。
3. 环形替换法O(1)空间，需处理`n%k==0`时的循环问题。

> “先反转全部数组，在反转前k个，最后在反转剩余的。”(p.185)

### 第217题：487，重构字符串

#### 核心论点
- **问题**：重新排列字符串，使相邻字符不同，返回任意可能结果。
- **核心观点**：若某字符出现次数 > (len+1)/2，则不可能；否则先按偶数位填入出现次数最多的字符，再填其他字符到剩余位置。

#### 关键概念/事件
- **临界值**：`threshold = (len + 1) >> 1`。
- **填充策略**：
  1. 统计频次，找出最多字符
  2. 若`max > threshold`返回空
  3. 先填奇数位或偶数位（从0开始，步长2）
  4. 填满后从1开始继续
- **注意**：必须将最多字符先填到偶数位。

#### 逻辑推演/叙事脉络
1. 统计频次，找出最大值及其字符。
2. 检查是否超过阈值，超过则返回空。
3. 创建结果数组，先从0开始步长2填充最多字符。
4. 再填充其他字符，若偶数位填满则从1开始步长2。

> “出现次数最多的那个字符数量的临界值是threshold = (length+1)>>1。”(p.196)

- **核心观点**：双指针——慢指针指向已处理部分的末尾，快指针遍历，遇到非零则交换到慢指针位置。

2. 后面补0。
3. 或用交换法。
