## 第2章：使用手册
### 核心论点
- **主要问题**：如何正确搭建 Guns 项目的运行环境并完成初始化部署？
- **核心观点**：Guns 依赖特定的 JDK、Maven 及 MySQL 版本，需严格配置开发工具（Eclipse/IDEA）及数据库脚本才能成功运行。

### 关键概念/事件
- **环境要求**：JDK 1.8，Maven 3.3.9+，MySQL 5.7，推荐使用阿里云 Maven 镜像。
- **项目导入**：详细描述了在 Eclipse 和 IDEA 中作为 Maven 项目导入的步骤及注意事项（如 settings.xml 配置）。
- **初始化流程**：执行 `guns.sql` 脚本初始化数据库，修改 `application.yml` 中的数据库连接配置。
- **打包部署**：支持 Jar 和 War 两种打包方式，需在 `guns-parent` 目录下执行 Maven 打包命令。

### 逻辑推演/叙事脉络
本章按照软件生命周期的初始阶段展开：首先明确软硬件环境约束，接着分 IDE 类型讲解项目导入流程，随后指导数据库初始化与配置文件修改，最后说明如何启动项目及进行生产环境的打包部署。逻辑清晰，侧重于操作层面的规范性。

## 第3章：开发手册
### 核心论点
- **主要问题**：如何在 Guns 框架下进行高效的业务功能开发？
- **核心观点**：遵循“建表-代码生成-添加菜单-编写业务”的开发三部曲，利用框架内置的代码生成器、权限控制、多数据源及分页机制，可大幅减少重复工作量。

### 关键概念/事件
- **模块结构**：`guns-admin`（业务模块）、`guns-core`（核心通用模块）、`guns-generator`（代码生成）、`guns-rest`（RESTful API模块）。
- **开发三部曲**：
    1. **建表**：定义数据库表结构。
    2. **代码生成**：使用生成器一键生成 Entity、DAO、Service、HTML、JS 等代码。
    3. **添加菜单与权限**：通过执行生成的 SQL 或手动添加菜单，并为角色分配权限。
- **权限控制**：基于 Shiro，通过 `@Permission`注解控制接口访问，前端通过 `shiro.hasPermission()` 控制按钮显示。
- **多数据源**：通过 `@DataSource` 注解动态切换数据源，底层基于 AOP 实现。
- **分页机制**：集成 MyBatis-Plus，支持简单查询自动分页及复杂查询手动传入 `Page` 对象。
- **数据范围**：通过 `DataScope` 实现部门级数据隔离，底层利用 MyBatis 拦截器包装 SQL。
- **REST模块**：基于 JWT 鉴权及 MD5 签名机制保障接口安全。
- **工作流**：集成 Flowable 引擎，支持业务流程审批（如报销流程）。
- **日志记录**：通过 `@BussinessLog` 注解记录业务操作日志，支持字典翻译；统一异常拦截记录异常日志。
- **缓存使用**：支持 Ehcache 和 Redis，可通过工具类 `CacheKit` 或 Spring Cache 注解操作。
- **热部署**：配置 Spring Boot DevTools 实现 HTML 和 Java 类的热加载。

### 逻辑推演/叙事脉络
本章是文档的核心，首先介绍框架模块划分，随后以“订单业务”为例演示标准开发流程。接着深入讲解各项高级特性：从权限控制的内外联动，到多数据源、分页、数据范围等后端常见需求的解决方案，再到 REST 接口安全、工作流集成、日志与缓存机制。最后补充了枚举使用及热部署配置，形成了完整的开发知识体系。

## 第4章：扩展与高级配置
### 核心论点
- **主要问题**：如何根据项目实际需求对 Guns 框架进行定制化改造与环境适配？
- **核心观点**：通过修改包名、配置白名单、调整资源路径、扩展多数据源、开启分布式 Session 及 XSS 过滤等手段，可使框架适应更复杂的生产环境。

### 关键概念/事件
- **项目重构**：修改项目名及包名的步骤，涉及 POM 文件、配置文件及 AOP 扫描路径的调整。
- **权限白名单**：在 `ShiroConfig` 中配置无需登录即可访问的接口。
- **资源路径变更**：自定义静态资源和模板文件的存放位置。
- **多数据源扩展**：配置三个及以上数据源的方法，需新增配置类及枚举。
- **安全增强**：开启登录验证码、配置 XSS 过滤器及放过特定 URL。
- **环境隔离**：使用 Spring Profile 区分 dev/test/prod 环境配置。
- **分布式部署**：开启 Spring Session 并将 Session 托管至 Redis，实现多机器共享会话。
- **Redis 集成**：配置 RedisTemplate 用于缓存或分布式存储。

### 逻辑推演/叙事脉络
本章针对框架的灵活性与安全性进行扩展说明。从基础的项目重命名开始，逐步深入到权限豁免、资源路径定制等配置项。随后讲解了如何突破默认的双数据源限制，以及如何通过 Profile 和 Redis 支持多环境部署与分布式架构。最后强调了 XSS 防护等安全配置，体现了框架在企业级应用中的可配置性。

## 第5章：核心思想
### 核心论点
- **主要问题**：Guns 框架背后的设计哲学与架构原则是什么？
- **核心观点**：通过清晰的分包策略、统一异常处理、结果包装器及前端布局抽象，实现高内聚低耦合，提升代码的可维护性与开发效率。

### 关键概念/事件
- **分包策略**：推荐 `config`（配置）、`core`（核心机制/扩展）、`modular`（业务模块）的分层结构，业务模块内再细分为 controller/service/dao/warpper。
- **统一异常拦截**：利用 `@ControllerAdvice` 全局捕获异常，避免业务代码中充斥 try-catch，提升代码整洁度。
- **结果包装器（Warpper）**：继承 `BaseControllerWarpper`，将数据库中的状态码/ID 转换为前端易读的中文描述，实现数据展示层的解耦。
- **前端思想**：
    - **布局**：使用 Beetl 的 `@layout` 继承机制，统一页面框架。
    - **标签**：封装重复 HTML 片段为自定义标签，简化页面编写。

### 逻辑推演/叙事脉络
本章从代码组织、错误处理、数据展示及前端渲染四个维度提炼框架的设计精髓。首先阐述分包带来的结构清晰性，接着说明统一异常处理对业务逻辑的净化作用。随后介绍结果包装器如何解决“数据存贮”与“数据展示”的差异。最后解析前端如何利用模板引擎特性实现布局复用与组件化，体现了全栈层面的架构思考。

## 第6章：常见问题答疑
### 核心论点
- **主要问题**：开发者在使用 Guns 过程中遇到的典型障碍及其解决方案有哪些？
- **核心观点**：通过汇总社区高频问题，提供快速排查指南，涵盖默认账号、权限报错、分页机制、SQL 兼容性等实操痛点。

### 关键概念/事件
- **默认凭证**：admin/111111。
- **权限异常**：通常因未分配菜单权限或 URL 不匹配导致。
- **分页机制**：解释为何部分页面采用前端分页（数据量小），而日志等采用服务端分页。
- **上下文路径**：`${ctxPath}` 由 Beetl 引擎自动处理。
- **SQL 兼容性**：MySQL 5.7 以下版本需移除 `DEFAULT CURRENT_TIMESTAMP` 以避免报错。
- **DAO/Mapper 分离**：Mapper 由 MP 自动生成，DAO 用于自定义业务，避免代码覆盖。
- **模板引擎选择**：选用 Beetl 因其语法简洁、性能高且文档完善。

### 逻辑推演/叙事脉络
本章以问答形式呈现，直接针对开发者在实际操作中可能遇到的“拦路虎”。从最基础的登录问题入手，逐步深入到权限配置、分页策略选择、环境兼容性调整及架构设计疑问（如为何有无 Service 层、为何分离 DAO/Mapper）。每个问题均给出直接的原因分析或解决步骤，具有极强的实用价值。
