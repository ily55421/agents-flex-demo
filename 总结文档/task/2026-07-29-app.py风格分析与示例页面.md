## app.py 风格分析

### 1. 整体风格
- 使用中文注释，符合项目语境。
- 代码结构简单，主要完成“启动后台服务 + 打开桌面窗口”的职责。
- 采用全局变量 `APP_ROOT` 与运行时常量 `HOST`、`PORT`。

### 2. 存在的问题

| 问题 | 说明 |
|------|------|
| 全局副作用 | `sys.path.insert(0, APP_ROOT)` 在模块导入时产生副作用。 |
| 导入位置 | `import server` 写在函数内部，不利于静态分析和 IDE 提示。 |
| 硬编码配置 | `HOST`、`PORT`、`debug=True` 直接写在代码中。 |
| 启动等待不健壮 | `time.sleep(3)` 是固定等待，不能确保服务已就绪。 |
| 缺少日志 | 使用 `print` 输出信息，缺少结构化日志。 |
| 缺少异常处理 | 服务启动失败时，窗口仍会打开。 |

## 优化建议

1. **配置外部化**：将 `HOST`、`PORT` 等写入 `config.json` 或通过环境变量读取。
2. **使用 `pathlib`**：替换 `os.path`，使路径拼接更清晰、跨平台。
3. **添加日志模块**：使用 `logging` 替代 `print`。
4. **健康检查替代 sleep**：在启动窗口前轮询检测服务是否可用。
5. **异常处理**：捕获 `server.main()` 或窗口创建异常，给出友好提示。
6. **类型注解**：为主函数添加类型提示，提升可维护性。
