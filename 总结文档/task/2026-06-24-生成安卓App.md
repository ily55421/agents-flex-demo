# 任务记录：Python 项目生成安卓 App

日期：2026-06-24

## 任务目标
将基于 Python + SQLite + Web 前端的文档博客系统打包为安卓 App，要求：
- 内嵌 SQLite 数据库并保留初始数据（550+ 篇文档）
- Web 前端适配移动端
- 完全离线运行

## 技术方案
采用 **Chaquopy (Python on Android) + WebView** 架构：
- Chaquopy：在安卓上运行 Python HTTP 服务器
- WebView：加载移动端适配后的 Web 前端
- SQLite 数据库：打包时 ZIP 压缩，首次启动解压到应用私有目录

## 构建步骤

### 前置要求
- Android Studio (Flamingo+)
- JDK 17
- Android SDK 34
- Python 3.10+

### 构建命令
```bash
# 1.（可选）更新数据库
cd d:\阅读\总结文档\web-app
python server.py  # 等待导入完成后 Ctrl+C

# 2. 生成图标和打包资源
cd d:\阅读\总结文档\web-app\android
python create_icons.py
python prepare_assets.py

# 3. 用 Android Studio 打开 android 目录，Build APK
```

生成的 APK 位置：`app/build/outputs/apk/debug/app-debug.apk`

## 注意事项
- APK 预计体积：80-100MB（含 Python 运行时）
- 首次启动需解压数据库，约需 3-5 秒
- 仅支持 arm64-v8a 和 x86_64 架构
- 后续更新文档只需重新运行 `prepare_assets.py` 并构建
