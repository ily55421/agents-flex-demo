# 《数据库原理与应用》课程讲义总结

## 第一部分：课程简介

### 1. 课程定位与目标
*   **定位**：大学计算机基础公共核心课，连接理论与应用的桥梁。
*   **工具**：以 Microsoft Access 为具体的数据库管理系统 (DBMS)。
*   **目标**：掌握数据库基础理论、设计方法；熟练使用 Access 创建表、查询、窗体、报表、宏；能够独立完成小型实用数据库程序设计。

### 2. 课程结构（七篇）
1.  **基本理论**：数据库概念、术语。
2.  **建立数据库与表**：创建库、表及技巧。
3.  **建立查询**：各类查询及 SQL。
4.  **建立窗体**：窗体类型及控件使用。
5.  **建立报表**：各类报表制作。
6.  **建立宏**：自动化操作、菜单、密码验证。
7.  **综合设计**：完整的小型数据库系统案例。

## 第二部分：核心知识点详解

### 第一单元：数据库与表

#### 1. 基本概念
*   **数据 (Data)**：信息的物理符号表现。
*   **信息 (Information)**：经过加工的数据，具有决策价值。
*   **数据处理**：将数据转化为信息的过程。
*   **数据模型三要素**：
    *   数据结构（静态特征）
    *   数据操作（动态特征）
    *   完整性约束（实体、参照、用户自定义）
*   **数据模型分类**：关系型（二维表）、层次型、网状型、面向对象型等。
*   **数据库 (DB) 特点**：永久存储、有组织、可共享、低冗余、高独立性。
*   **数据库系统 (DBS) 组成**: DB, DBMS (如 Access), 应用系统, 人员 (DBA/用户)。

#### 2. Access 基础
*   **文件扩展名**：`.mdb` (Access 2003及以前) 或 `.accdb` (新版，文中主要提及 mdb)。
*   **七大对象**：表、查询、窗体、报表、页、宏、模块。

#### 3. 表 (Table) 的设计
*   **结构**：由字段（列/属性）和记录（行/元组）组成。
*   **主键 (Primary Key)**：唯一标识记录，非空且唯一。类型：单字段、多字段、自动编号。
*   **十种数据类型**：
    1.  **文本**：1-255字符，默认50。
    2.  **备注**：<64K，长文本。
    3.  **数字**：整型、长整型、单精度、双精度等。
    4.  **日期/时间**：8字节。
    5.  **货币**：8字节，高精度固定小数。
    6.  **自动编号**：4字节，系统自动生成。
    7.  **是/否**：逻辑值 (Yes/No, -1/0)。
    8.  **OLE对象**：多媒体数据 (<1G)。
    9.  **超级链接**：URL地址。
    10. **查阅向导**：从列表选择值。
*   **字段属性**：字段大小、格式（仅影响显示）、输入掩码（控制输入格式，如电话、身份证）、标题、默认值、有效性规则/文本、必填字段。

### 第二单元：表间关系与表操作

#### 1. 表间关系 (Relationships)
*   **定义**：基于公共字段建立的连接。
*   **建立步骤**：
    1.  主表必须设主键。
    2.  子表必须有对应字段（类型、长度一致）。
    3.  关闭所有表。
    4.  在“关系”窗口中，将主表主键拖拽至子表对应字段。
*   **参照完整性**：
    *   **级联更新**：主表主键变，子表外键同步变。
    *   **级联删除**：删主表记录，自动删子表相关记录。
*   **关系类型**：
    *   **一对一 (1:1)**：双方公共字段均为主键。
    *   **一对多 (1:n)**：主表主键 -> 子表非主键（最常见）。
    *   **多对多 (m:n)**：需通过中间表转化为两个一对多关系。

#### 2. 数据录入原则
*   先建关系，后录数据。
*   先录主表，后录子表。

#### 3. 表的操作
*   **导入 vs 链接**：
    *   **导入**：数据复制进当前库，与源文件断开。
    *   **链接**：保留源文件位置，数据实时同步，节省空间。
*   **导出**：支持 Excel, TXT, HTML, FoxPro等格式。
*   **复制**：可复制结构+数据，或仅复制结构。

### 第三单元：创建选择查询

#### 1. 查询概述
*   **定义**：从表中筛选数据形成的动态集合，不改变原表数据。
*   **视图**：数据表视图（结果）、设计视图（构建）、SQL视图（代码）。
*   **数据源**：可以是表，也可以是其他查询。多表查询需确保关系正确。

#### 2. 查询类型
*   **选择查询**：基本条件筛选。
*   **交叉表查询**：行列转换统计（如：班级为行，民族为列，统计人数）。
*   **参数查询**：运行时提示用户输入条件（使用 `[提示信息] as 方括号`）。
*   **计算字段**：`新字段名: 表达式`。

#### 3. 表达式与运算符
*   **分界符**：
    *   数值：无。
    *   字符串：`" "` (双引号)。
    *   日期：`# #` (井号)。
    *   字段名：`[ ]` (方括号，建议始终使用)。
*   **运算符**：
    *   算术：`+ - * / \ (整除) Mod (求余) ^ (乘幂)`
    *   连接：`&` (强制连接), `+` (同类型连接)
    *   关系：`=, <>, <, <=, >, >=`
    *   逻辑：`AND, OR, NOT`
    *   特殊：`Between...And`, `In(...)`, `Is Null`, `Like` (`*`多字符, `?`单字符)
*   **常用函数**：
    *   数值：`Int()`, `Round()`, `Sqr()`
    *   字符：`Len()`, `Trim()`, `Left()`, `Mid()`, `Space()`
    *   日期：`Date()`, `Year()`, `Month()`, `Day()`, `Now()`
    *   其他：`Iif(条件, 真值, 假值)`, `Ucase()`, `Str()`

### 第四单元：汇总查询、操作查询、SQL查询

#### 1. 汇总查询 (总计行)
*   **启用方式**：设计视图点击 `∑`。
*   **聚合函数**：`Sum` (总和), `Avg` (平均), `Min`, `Max`, `Count` (计数), `StDev` (标准差), `Var` (方差).
*   **选项**：
    *   `Group By`：分组依据。
    *   `Where`：条件筛选（不出现在结果中）。
    *   `Expression`：包含聚合函数的计算字段。
    *   `First/Last`：首/末记录。

#### 2. 操作查询 (动作查询)
*   **特点**：直接修改数据，运行后不可逆（建议先备份），不显示结果集。
*   **类型**：
    1.  **生成表查询**：根据条件创建新表。
    2.  **追加查询**：将记录添加到现有表末尾。
    3.  **删除查询**：批量删除符合条件的记录。
    4.  **更新查询**：批量修改字段值（注意字段名加方括号）。

#### 3. SQL 查询
*   **基本结构**：
    ```sql
    SELECT [DISTINCT] 字段列表 [AS 别名]
    FROM 表名列表
    [WHERE 行条件]
    [GROUP BY 分组条件]
    [HAVING 组条件]
    [ORDER BY 排序字段 [ASC|DESC]];
    ```
*   **关键点**：
    *   `DISTINCT`：去重。
    *   多表连接：在 `WHERE` 中写明连接条件 (`表1.字段 = 表2.字段`)。
    *   `HAVING`：必须配合 `GROUP BY` 使用，用于过滤分组后的数据。

### 第五单元：创建窗体 (Form)

#### 1. 窗体功能
*   数据显示与编辑、流程控制、信息提示、打印预览。
*   **区别**：窗体重在交互（输入/输出），报表重在打印（只读输出）。

#### 2. 窗体结构 (5个节)
1.  **窗体页眉**：标题、按钮（每窗体顶部显示一次）。
2.  **页面页眉**：列标题（每页打印时显示）。
3.  **主体**：核心数据区域（每条记录显示一次）。
4.  **页面页脚**：页码、日期（每页打印时显示）。
5.  **窗体页脚**：底部信息（每窗体底部显示一次）。

#### 3. 常用控件
*   **标签 (Label)**：非结合型，显示静态文本。
*   **文本框 (Text Box)**：
    *   结合型：绑定字段。
    *   计算型：绑定表达式。
    *   非结合型：无数据源。
*   **命令按钮 (Command Button)**：触发宏或 VBA 事件。
*   **组合框 (Combo Box) vs 列表框 (List Box)**：
    *   组合框：可输入，节省空间，下拉选择。
    *   列表框：不可输入，多行显示，占用空间大。
*   **选项卡控件**：实现多页界面。

### 第六单元：报表 (Report)

#### 1. 报表特点
*   主要用于格式化打印。
*   数据源通常为表或查询（多表建议先用查询整合）。

#### 2. 报表结构 (7个节)
1.  **报表页眉**：整个报表首页顶部（如标题）。
2.  **页面页眉**：每页顶部（如列头）。
3.  **组页眉**：每组开头（如部门名称）。
4.  **主体**：详细记录数据。
5.  **组页脚**：每组结尾（如部门小计）。
6.  **页面页脚**：每页底部（如页码）。
7.  **报表页脚**：整个报表最后一页底部（如总计）。

#### 3. 排序与分组
*   最多支持10个层级排序/分组。
*   统计计算（Sum/Avg等）通常放在**组页脚**或**报表页脚**。

### 第七单元：宏 (Macro)

#### 1. 宏的概念
*   一系列操作的集合，无需编程即可实现自动化。

#### 2. 宏的分类
*   **单个宏**：顺序执行一系列操作。
*   **宏组**：包含多个独立命名的宏序列。
*   **条件宏**：根据条件判断执行特定操作。

#### 3. 常用宏操作
*   `OpenForm`, `OpenReport`, `OpenQuery`, `OpenTable`
*   `Close`, `Quit`
*   `MsgBox` (消息框)
*   `RunSQL` (执行SQL语句)
*   `SetWarnings` (关闭/开启警告信息)

#### 4. 特殊宏
*   **AutoExec**：数据库启动时自动运行的宏（常用于打开登录窗体或主菜单）。

#### 5. 应用场景
*   按钮事件绑定。
*   登录密码验证（条件宏）。
*   自定义菜单栏。

### 第八单元：数据库系统设计

#### 1. 设计步骤 (SDLC)
1.  **需求分析**：收集用户需求，确定数据流和功能。
2.  **概念设计**：绘制 E-R 图，确定实体、属性及关系。
3.  **逻辑设计**：将 E-R 图转换为关系模式（表结构），规范化处理。
4.  **物理设计**：在具体 DBMS (Access) 中实现，包括索引、存储优化等。

#### 2. 综合案例：工资管理系统
*   **表设计**：部门表、职称表、职工信息表、工资表。
*   **查询设计**：
    *   基础查询（作为窗体/报表数据源）。
    *   更新查询（计算职务工资、税款、实发工资等）。
    *   生成表查询（归档上月工资）。
*   **界面设计**：
    *   登录窗体（宏验证密码）。
    *   主菜单窗体（导航各模块）。
    *   数据录入/编辑窗体。
    *   统计报表。
*   **系统优化**：
    *   设置数据库密码。
    *   隐藏数据库窗口。
    *   设置启动窗体。

## 第三部分：学习建议与总结

1.  **理论结合实践**：不仅要背诵概念，更要通过 Access 实际操作每个对象。
2.  **规范命名**：字段名、对象名建议统一规范，避免特殊字符。
3.  **重视关系**：多表操作前，务必检查“关系”窗口中的关联是否正确，这是查询准确性的基石。
4.  **备份习惯**：在执行“操作查询”（删除、更新、追加）前，务必备份数据。
5.  **从模仿到创新**：先完成教材案例，再尝试自行设计一个贴近生活的微型系统（如图书管理、个人记账）。
