# 《网站设计与管理》课程内容总结

## 一、 课程概况
*   **课程定位**：电子商务和信息管理类专业的专业基础课，涵盖 Dreamweaver 网页设计、HTML 制作、JavaScript 编程等。
*   **课程目标**：掌握网站系统设计与管理技术，熟练运用 HTML、Dreamweaver 和 JavaScript，具备独立设计小型 Web 站点的能力。
*   **核心工具**：Dreamweaver (DW), HTML, CSS, JavaScript, Photoshop/Fireworks/Flash (辅助)。

---

## 二、 章节详细内容总结

### 第一讲：网站设计与管理概述
**核心知识点：**
1.  **基本概念**：
    *   **WWW**：万维网，信息检索服务工具。
    *   **URL**：统一资源定位符，由协议名、服务器地址、路径、文件名组成。
    *   **浏览器**：通过 HTTP 协议与服务器交互（如 Chrome, Firefox）。
    *   **HTML**：超文本标记语言，构成网页文档的主要语言，结构分为头部 (`<head>`) 和主体 (`<body>`)。
    *   **静态 vs 动态网页**：
        *   静态：`.htm/.html`，无交互，内容固定。
        *   动态：`.asp/.jsp/.php`，可与用户交互，由服务器端程序生成。
2.  **网站类型**：门户网站、导航网站、搜索引擎、电子商务、公司宣传、政府网站、个人网站。
3.  **网页构成元素**：文本、图像 (JPG/GIF/PNG)、动画 (GIF/Flash)、音频/视频、超链接、导航栏、表单。
4.  **常用软件**：Dreamweaver (设计), Fireworks (切图), Flash (动画), Photoshop (平面)。
5.  **HTML 基础标记**：
    *   结构：`<html>`, `<head>`, `<body>`
    *   文本：`<h1>-<h6>` (标题), `<p>` (段落), `<br>` (换行), `<pre>` (预格式化), `<!-- -->` (注释)
    *   样式：`<font>` (字体/颜色/大小), `<b>/<i>/<u>` (粗/斜/下划线)
    *   列表：`<ol>` (有序), `<ul>` (无序), `<dl>` (定义列表)
    *   其他：`<hr>` (水平线), `<table>` (表格基础)

### 第二讲：使用 Dreamweaver 制作基本网页
**核心操作：**
1.  **工作环境**：熟悉插入栏、文档工具栏、属性面板、浮动面板组。
2.  **站点管理**：
    *   规划站点（目录结构统一，合理命名）。
    *   创建本地站点与远程站点。
3.  **文档操作**: 新建、打开、保存、预览网页。
4.  **页面属性设置**：标题、背景色/图、文本颜色、边距。
5.  **添加文本**：
    *   普通文本输入、导入。
    *   特殊字符插入 (©, ®, ¥ 等)。
    *   空格处理 (`Shift+Ctrl+Space`)。
    *   水平线、日期时间、上标/下标。
    *   列表创建与属性设置。
    *   文本样式：标题格式、段落对齐、字号(px/pt)、字体、颜色、粗体/斜体。
6.  **添加图像**：
    *   格式：GIF (少色/透明), JPEG (照片/真彩), PNG (压缩好/透明)。
    *   操作：直接插入、占位符、鼠标经过图像 (Roll-over)。
    *   属性：替换文本 (Alt), 对齐方式, 边距, 大小调整。
7.  **多媒体元素**：
    *   Flash 对象 (按钮/文本/动画)，设置透明背景 (`wmode=transparent`)。
    *   视频：ActiveX 控件, Flash Video (.flv)。
    *   音频：MP3, WMA, WAV, MIDI；通过“行为”面板添加背景音乐。
8.  **超链接**：
    *   类型：内部、外部、锚点 (书签)、电子邮件 (`mailto:`)。
    *   路径：绝对路径、根目录相对路径、文档相对路径。
    *   图像热点链接：矩形、椭圆、多边形热点。
    *   空链接：`#` 或 `javascript:;`。
    *   目标窗口：`_blank` (新窗口), `_self` (当前), `_parent`, `_top`。

### 第三讲：网站的框架设计
**核心布局技术：**
1.  **常见布局结构**：“T”字型、“口”字型、“三”字型、海报型、标题文本型、框架型、综合型。
2.  **框架 (Frames)**：
    *   概念：框架 (Frame) 显示独立内容，框架集 (Frameset) 定义结构。
    *   操作：创建预定义/自定义框架集，嵌套框架，保存框架及框架集，设置边框/滚动条属性。
3.  **层 (Layers/AP Div)**：
    *   特点：精确定位，可重叠，Z轴顺序。
    *   操作：创建普通层/嵌套层，调整大小/位置，对齐，可见性 (visible/hidden)，溢出处理 (scroll/auto)，Z-index 堆叠次序。
    *   转换：层与表格相互转换（注意兼容性）。
4.  **模板 (Templates)**：
    *   作用：统一风格，提高效率 (.dwt文件)。
    *   区域：锁定区域 (不可改), 可编辑区域, 可选区域, 重复区域, 可编辑标签属性。
    *   应用：从模板新建，套用模板到现有页，分离模板，修改模板并更新全站。
5.  **库 (Library)**：
    *   作用：复用特定元素 (如版权信息、导航条)。
    *   操作：创建库项目，应用库项目，更新库项目 (全站同步更新)。

### 第四讲：布局表格的使用方法
**核心技巧：**
1.  **表格基础**：
    *   插入：普通表格，嵌套表格 (内层常用百分比宽度)。
    *   编辑：选择行列/单元格，插入/删除行列，合并/拆分单元格。
    *   调整：拖动控制点或属性面板精确设置宽高。
    *   数据：导入/导出表格式数据，表格排序。
2.  **格式化表格**：设置边框、背景、对齐方式；应用预设样式。
3.  **布局视图 (Layout View)**：
    *   模式切换：标准视图 <-> 布局视图。
    *   绘制：布局表格，布局单元格 (自动捕捉，不可重叠但可嵌套)。
    *   调整：移动表格/单元格，调整大小，利用网格线辅助。
    *   属性：设置单元格/表格的对齐、宽高、背景色。

### 第五讲：表单的应用
**交互功能实现：**
1.  **创建表单**：
    *   `<form>` 标签是容器。
    *   属性：Action (处理程序路径), Method (GET/POST), Target (目标窗口), ID/Name。
2.  **表单元素**：
    *   **文本字段**：单行、多行、密码域 (显示为*)。属性：字符宽度, 最大字符数, 初始值。
    *   **复选框 (Checkbox)**：多项选择。属性：选定值。
    *   **单选按钮 (Radio)**：单项选择，需分组。可使用“单选按钮组”快速创建。
    *   **列表/菜单 (Select)**：列表 (多选), 菜单 (单选)。
    *   **跳转菜单**：选择选项后跳转到指定 URL。
    *   **文件域**：用于上传文件路径选择 (需后端支持才能真正上传)。
    *   **按钮**：提交 (Submit), 重置 (Reset), 命令 (Command/Script)。
    *   **图像域**：以图片形式作为提交按钮。

### 第六讲：Javascript 的应用
**动态交互脚本：**
1.  **JS 概述**：简单、动态、跨平台、安全。用于特效、表单验证、窗口操作。
2.  **JS 与 HTML 结合**：
    *   内联：直接在标签事件中写代码 (如 `onmouseover="..."`)。
    *   嵌入：`<script>...</script>` 块。
    *   外联：`<script src="file.js"></script>`。
3.  **JS 语法基础**：
    *   数据类型：数字, 字符串, 布尔, null。
    *   变量：`var` 声明，弱类型，区分大小写。
    *   运算符：算术 (+,-,*,/,%), 逻辑 (&&,||,!), 比较 (==,!=,>,<), 赋值, 条件 (?:)。
    *   流程控制：`if-else`, `switch-case`, `for`, `while`, `do-while`, `break/continue`。
4.  **行为 (Behaviors)**：
    *   构成：事件 (Event) + 动作 (Action)。
    *   常见事件：`onLoad`, `onClick`, `onMouseOver/Out`, `onSubmit`, `onChange` 等。
    *   DW 内置行为：交换图像, 弹出信息, 打开浏览器窗口, 控制 Flash, 改变属性, 拖动层, 显示-隐藏层, 弹出菜单, 检查表单, 设置文本/状态栏。
5.  **JS 特效实例**：
    *   滚动公告 (`<marquee>` 标签)。
    *   自动变换文字颜色。
    *   打字机效果。
    *   页面自动关闭/跳转。

### 第七讲：网页的排版布局 (CSS)
**样式与内容分离：**
1.  **CSS 简介**：层叠样式表，控制表现 (字体、颜色、布局)。
2.  **选择符**：
    *   标记选择符 (如 `p {}`)。
    *   类选择符 (`.class {}`)，可多次使用。
    *   ID 选择符 (`#id {}`)，唯一标识。
    *   复合/伪类选择符 (如 `a:link`, `a:hover`)。
3.  **插入方式**：
    *   内嵌样式 (`style="..."`)。
    *   内部样式表 (`<style>...</style>` 在 head 中)。
    *   链入外部样式表 (`<link rel="stylesheet" href="...">`)，推荐方式。
    *   导入外部样式表 (`@import`)。
4.  **CSS 属性分类**：
    *   类型 (字体/大小/颜色/行高)。
    *   背景 (颜色/图像/位置/重复)。
    *   区块 (对齐/缩进/间距)。
    *   方框 (Margin/Padding/Width/Height)。
    *   边框 (Width/Style/Color)。
    *   列表 (样式/图像)。
    *   定位 (Position/Z-index/Visibility)。
    *   扩展 (打印/滤镜/鼠标指针)。
5.  **应用与冲突规则**：
    *   就近原则：内嵌 > 内部 > 外部。
    *   特异性：ID > Class > Tag。
6.  **实战技巧**：使用 CSS 制作细线框表格 (利用 `border-collapse` 或背景色反差法)。

### 第八讲：网站的整合与测试发布
**上线流程：**
1.  **网站设计流程**：需求分析 -> 策划与设计 -> 制作 (美工/程序) -> 测试 -> 发布 -> 推广 -> 维护。
2.  **网站测试**：
    *   链接测试：检查死链。
    *   兼容性测试：不同浏览器 (IE, Chrome, Firefox) 及分辨率下的显示效果。
    *   DW 工具：检查链接，浏览器兼容性检查器。
3.  **发布准备**：
    *   域名申请。
    *   主机空间购买 (虚拟主机) 或自建服务器。
4.  **上传发布**：
    *   配置远程站点 (FTP 信息)。
    *   连接远程服务器。
    *   上传文件 (注意关联文件如图片/CSS 同步上传)。
    *   同步站点：保持本地与远程一致。
5.  **自建服务器 (IIS/Apache)**：
    *   Windows 下 IIS 安装与配置。
    *   设置主目录、默认文档、权限 (读取/写入/执行)。
    *   主机头设置 (同一 IP 区分不同站点)。
6.  **网站推广**：
    *   搜索引擎登录 (SEO)。
    *   网络广告 (Banner/Flash)。
    *   友情链接交换。
    *   其他：电子邮件、传统媒体等。

## 三、 学习建议与重点
1.  **工具结合**：虽然 Dreamweaver 提供了可视化操作，但必须理解底层的 HTML/CSS/JS 代码逻辑，以便进行精细控制和故障排查。
2.  **标准化**：养成规划站点目录、规范命名文件、使用模板和库的习惯，这对于大型网站维护至关重要。
3.  **兼容性**：在设计和测试阶段，务必考虑不同浏览器的兼容性，特别是 CSS 渲染差异。
4.  **交互体验**：合理利用 JavaScript 行为和 CSS 特效提升用户体验，但避免过度使用影响加载速度。
5.  **全流程意识**：从需求分析到后期维护推广，建立完整的网站生命周期管理思维。
