# 《互联网软件应用与开发》课程内容总结

**来源机构**：北京外国语大学网院教育学院  
**发布时间**：2019年2月  
**核心目标**：以 Access 数据库和 ASP/Web 开发技术为背景，培养学生从数据库设计到 Web 应用开发的全流程能力。

## 第一部分：课程简介

### 1. 课程定位与目标
*   **定位**：计算机基础教学的核心课程，连接理论与应用的桥梁。
*   **工具**：主要使用 Microsoft Access 作为 DBMS，结合 Web 开发技术。
*   **目标能力**：
    *   掌握数据库基础理论（表、查询、窗体、报表、宏）。
    *   掌握 SQL 基础及 Access 对 Internet 的支持。
    *   能够独立完成小型实用数据库程序及简单 Web 应用的设计。

### 2. 课程结构（七篇）
1.  **数据库基本理论**：概念、术语。
2.  **建立数据库与表**：Access 建库、建表操作。
3.  **建立查询**：各类查询及 SQL。
4.  **建立窗体**：界面设计与控件使用。
5.  **建立报表**：数据打印与展示。
6.  **建立宏**：自动化操作与菜单定制。
7.  **综合设计**：完整的小型数据库系统案例。

## 第二部分：核心知识点详解

### 第一章：数据库与表
*   **基本概念**：
    *   **数据 vs 信息**：数据是信息的载体，信息是数据的内涵。
    *   **数据模型三要素**：数据结构、数据操作、完整性约束。
    *   **DBS组成**：数据库 (DB)、数据库管理系统 (DBMS)、应用系统、用户/管理员。
*   **关系型数据库**：
    *   基于二维表结构。
    *   **三种关系运算**：选择 (Selection)、投影 (Projection)、联接 (Join)。
*   **Access 对象**：表、查询、窗体、报表、页、宏、模块。
*   **表的设计**：
    *   **字段属性**：数据类型（文本、备注、数字、日期/时间、货币、自动编号、是/否、OLE对象、超级链接、查阅向导共10种）。
    *   **主键**：唯一标识记录，不允许重复或空值。
    *   **常用属性**:字段大小、格式、输入掩码、默认值、有效性规则。

### 第二章：表间关系与操作
*   **建立关系步骤**:
    1. 主表建立主键。
    2. 子表建立对应字段（类型一致）。
    3. 在“关系”窗口拖拽建立关联。
*   **参照完整性**：
    *   **级联更新**：主表主键更改，子表同步更改。
    *   **级联删除**：主表记录删除，子表相关记录同步删除。
*   **关系类型**：
    *   **一对一 (1:1)**：公共字段均为主键。
    *   **一对多 (1:n)**：主表主键对应子表非主键（最常见）。
    *   **多对多 (m:n)**：需通过中间表转化为两个一对多关系。
*   **数据导入/链接**：
    *   **导入**：数据复制到当前库，与源文件断开。
    *   **链接**：保留源文件数据，当前库仅存映像，保持同步。

### 第三章：创建选择查询
*   **查询分类**：
    *   **选择查询**：筛选数据，不改变原表。
    *   **操作查询**：修改原表数据。
*   **视图模式**：数据表视图、设计视图、SQL 视图。
*   **查询类型**：
    *   条件查询（AND同行，OR不同行）。
    *   交叉表查询（行列汇总）。
    *   参数查询（使用 `[]` 提示输入）。
    *   计算查询（新增字段表达式）。
*   **表达式与运算符**：
    *   **分界 a**：字符串用 `""`，日期用 `#`，字段名用 `[]`。
    *   **特殊运算符**：`Between...And`, `In`, `Is Null`, `Like` (`*`多字符, `?`单字符)。
*   **常用函数**：
    *   算术：`Int()`, `Round()`, `Sqr()`。
    *   字符：`Len()`, `Trim()`, `Left()`, `Mid()`。
    *   日期：`Date()`, `Year()`, `Month()`, `Now()`。
    *   逻辑：`Iif()`。

### 第四章：汇总查询、操作查询与 SQL
*   **汇总查询**：
    *   使用总计行 (`∑`)。
    *   **函数**：`Sum`, `Avg`, `Min`, `Max`, `Count`, `StDev`, `Var`。
    *   **选项**：`Group By` (分组), `Where` (条件，不显示在结果中)。
*   **操作查询 (Action Queries)**：
    1.  **生成表查询**：创建新表。
    2.  **追加查询**：添加记录到现有表。
    3.  **删除查询**：批量删除记录。
    4.  **更新查询**：批量修改记录。
*   **SQL 基础语法**：
    ```sql
    SELECT [DISTINCT] <字段列表>
    FROM <表列表>
    [WHERE <条件>]
    [GROUP BY <分组>]
    [HAVING <组条件>]
    [ORDER BY <排序> [ASC|DESC]];
    ```
    *   `HAVING` 必须配合 `GROUP BY` 使用。
    *   多表查询需在 `WHERE` 中指定连接条件。

### 第五章：创建窗体
*   **功能**：数据显示、编辑、流程控制、打印预览。
*   **结构（5个节）**：
    1.  窗体页眉（标题、按钮）。
    2.  页面页眉（打印时每页顶部显示）。
    3.  **主体节**（核心数据区域）。
    4.  页面页脚（打印时每页底部显示）。
    5.  窗体页脚（底部信息）。
*   **常用控件**：
    *   **标签**：静态文本，非结合型。
    *   **文本框**：结合型（绑定字段）、计算型（表达式）、非结合型。
    *   **命令按钮**：通过宏或 VBA 触发事件。
    *   **列表框 vs 组合框**：组合框可输入且节省空间；列表框仅选择且显示多行。

### 第六章：多页控件及报表
*   **多页控件**：选项卡式界面，用于组织复杂窗体。
*   **窗体 vs 报表**：
    *   **窗体**：重在交互（输入/输出），屏幕显示。
    *   **报表**：重在打印（只读输出），格式化排版。
*   **报表结构（7个节）**：
    *   报表页眉/页脚（整个报表首尾）。
    *   页面页眉/页脚（每页首尾）。
    *   组页眉/页脚（分组统计）。
    *   主体节（详细记录）。
*   **排序与分组**：最多支持10个字段排序；统计控件通常放在组页眉/页脚。

### 第七章：宏
*   **定义**：一系列操作的集合，用于自动化任务。
*   **分类**：单个宏、宏组、条件宏。
*   **运行方式**：
    1.  直接运行。
    2.  双击对象。
    3.  **事件触发**（最常用）：绑定到按钮单击等事件。
*   **AutoExec 宏**：数据库启动时自动运行的特殊宏。

### 第八章：数据库系统设计举例
*   **设计步骤**：
    1.  **需求分析**：收集用户需求。
    2.  **概念设计**：E-R图，概念模式。
    3.  **逻辑设计**：转换为具体 DBMS 模型（如关系表）。
    4.  **物理设计**：存储结构优化。
*   **其他设置**：数据库密码、启动窗体、隐藏数据库窗口。

## 第三部分：Web 开发讲义核心内容

### 第一章：互联网软件应用与开发概述
*   **Web 技术基础**：
    *   **HTTP 协议**：无状态协议，浏览器默认协议。
    *   **URL**：统一资源定位器。
    *   **HTML**：超文本标记语言。
*   **架构模式**：
    *   **C/S (Client/Server)**：传统客户端服务器模式。
    *   **B/S (Browser/Server)**：浏览器/服务器模式，互联网软件主流架构。
*   **执行过程**：
    1.  浏览器发送请求至 Web 服务器。
    2.  Web 服务器转发至应用服务器。
    3.  应用服务器执行脚本，生成 HTML。
    4.  返回 HTML 给浏览器解析显示。
*   **常见服务器**：IIS (Windows), Apache (跨平台), Tomcat (Java)。

### 第二章：开发环境搭建
*   **浏览器设置**：
    *   开启“显示每个脚本错误的通知”。
    *   关闭“显示友好 HTTP 错误信息”。
    *   关闭“禁用脚本调试”。
*   **IIS 配置**：
    *   安装 IIS 组件。
    *   配置默认网站、主目录、默认文档。
*   **Dreamweaver 站点管理**：
    *   区分本地站点（开发环境）和远程站点（服务器环境）。

### 第三章：客户端程序开发 (JavaScript)
*   **JavaScript 特性**：解释型、基于对象、弱类型、嵌入 HTML 执行。
*   **嵌入方式**：
    *   `<script>` 标签内部。
    *   `<script src="...">` 外部引用。
    *   HTML 事件属性 (如 `onclick`)。
*   **核心对象**：
    *   **Window**：顶层对象，`alert()`, `confirm()`, `open()`, `close()`。
    *   **Document**：当前文档，`write()`, `forms`, `all`。
*   **语法要点**：
    *   **变量**：`var` 声明，动态类型。
    *   **运算符**：`==` (值相等), `===` (严格相等), `&` (位与), `&&` (逻辑与)。
    *   **流程控制**：`if-else`, `switch`, `for`, `while`, `do-while`, `break/continue`。
    *   **函数**：`function name(args) { ... }`，支持 `arguments` 对象。
    *   **内置对象**：`Math`, `String`, `Date`, `Array`。
    *   **正则表达式**：`/pattern/flags`，用于字符串匹配。

### 第四章：服务器端程序开发 (ASP/VBScript)
*   **ASP 基础**：
    *   代码包裹在 `<% ... %>` 中。
    *   默认脚本语言：VBScript。
*   **VBScript 语法**：
    *   **变量**：`Dim` 声明，弱类型，Variant 类型。
    *   **数组**：下标从 0 开始，可混合类型。
    *   **流程控制**：`If...Then...Else`, `Select Case`, `For...Next`, `Do...Loop`, `While...Wend`。
    *   **过程/函数**：`Sub` (无返回值), `Function` (有返回值)。
*   **核心对象**：
    *   **Request** (获取客户端数据)：
        *   `Request.Form`：POST 数据。
        *   `Request.QueryString`：GET 数据。
        *   `Request.Cookies`：读取 Cookie。
        *   `Request.ServerVariables`：环境变量 (IP, URL, Method等)。
    *   **Response** (向客户端发送数据)：
        *   `Response.Write`：输出内容。
        *   `Response.Redirect`：页面重定向。
        *   `Response.End`：停止脚本执行。
        *   `Response.Cookies`：写入 Cookie。

### 第五章：互联网软件与数据库
*   **集成方式**：Web 应用通过 ODBC/OLEDB 连接 Access 或其他数据库。
*   **作用**：实现动态内容、用户管理、数据存储。
*   **常见应用场景**：后台管理、留言板、客户管理、试题库。

### 第六至八章：综合案例开发
*   **通用开发流程**：
    1.  **建立数据库**：设计表结构、关系。
    2.  **创建网站页面**：HTML/CSS 静态布局。
    3.  **客户端开发**：JS 验证、交互。
    4.  **服务器端开发**：ASP 处理业务逻辑、数据库读写。
    5.  **测试与维护**。
*   **案例涵盖**：
    *   简单网站后台管理。
    *   留言板与客户信息管理。
    *   网络试题库管理。

## 总结与建议

该文档是一份典型的**早期 Web 开发入门教程**，具有以下特点：
1.  **技术栈较旧**：主要围绕 **Access + ASP (VBScript) + JavaScript (ES3/5前)** 展开。现代开发已转向 Java/Python/Node.js + MySQL/PostgreSQL + Vue/React。
2.  **侧重基础原理**：虽然技术陈旧，但其关于**数据库范式、关系代数、HTTP 无状态特性、B/S 架构原理、SQL 基础**的描述依然具有核心价值。
3.  **适合人群**：初学者理解数据库与 Web 交互的基本逻辑，或需要维护遗留 ASP/Access 系统的开发人员。

**对于现代开发的启示**：
*   **数据库设计原则**（主键、外键、参照完整性）依然通用。
*   **SQL 语法**（SELECT, JOIN, GROUP BY）是标准通用的。
*   **B/S 交互模型**（Request/Response）是所有 Web 框架的核心。
*   **前端逻辑**（DOM 操作、事件驱动）的思想在 modern JS 中依然延续，只是实现方式更规范化。
