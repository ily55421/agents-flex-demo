# 📚 文档博客 Web 服务 - 技术文档

## 1. 项目概述

文档博客是一个基于 Python 标准库构建的轻量级文档浏览与全文检索 Web 应用，用于管理和搜索 Markdown 格式的学习笔记与技术文档。

| 属性 | 说明 |
|------|------|
| 项目名称 | 文档博客 Web 服务 |
| 技术栈 | Python 3.14 + SQLite FTS5 + 原生 HTML/CSS/JS |
| 部署方式 | 本地单机运行，零外部依赖 |
| 数据存储 | SQLite 数据库（WAL 模式） |
| 文档总数 | ~155 篇 |
| 总字数 | ~135 万字 |

## 4. 后端技术详解

### 4.1 HTTP 服务层

| 组件 | 说明 |
|------|------|
| 服务器类 | `DocHandler`，继承自 `http.server.SimpleHTTPRequestHandler` |
| 监听地址 | `0.0.0.0:8080` |
| 静态文件 | 自动从 `static/` 目录提供 |
| API 格式 | RESTful JSON，UTF-8 编码 |

### 4.2 数据库设计

#### categories（分类表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增主键 |
| slug | TEXT UNIQUE | 分类标识（如 `java`, `ai`） |
| name | TEXT | 显示名称 |
| icon | TEXT | Emoji 图标 |
| sort_order | INTEGER | 排序权重 |

#### documents（文档表）

| 字段 | 类型 | 说明 |
|------|------|------|
| id | INTEGER PK | 自增主键 |
| category_id | INTEGER FK | 关联分类 |
| filename | TEXT | 原始文件名 |
| title | TEXT | 文档标题（从首行 `#` 提取） |
| filepath | TEXT UNIQUE | 绝对路径 |
| content | TEXT | 纯文本内容（用于搜索） |
| html_content | TEXT | HTML 渲染内容 |
| word_count | INTEGER | 字数统计 |
| file_mtime | REAL | 文件修改时间（增量判断用） |
| created_at | TEXT | 创建日期 |
| updated_at | TEXT | 更新日期 |

#### docs_fts（FTS5 全文检索虚拟表）

| 字段 | 说明 |
|------|------|
| title | 文档标题 |
| content | 搜索内容 |
| category_name | 分类名称 |
| tokenize | `trigram`（支持中文子串匹配） |

### 4.3 API 接口清单

| 接口 | 方法 | 参数 | 说明 |
|------|------|------|------|
| `/api/stats` | GET | - | 统计信息 |
| `/api/categories` | GET | - | 分类列表（含文档计数） |
| `/api/documents` | GET | `category`, `page`, `limit` | 文档列表 |
| `/api/search` | GET | `q`, `page`, `limit` | 全文搜索 |
| `/api/document` | GET | `id` | 文档详情 |
| `/api/sync` | GET | - | 增量同步（新增/变更） |
| `/api/reindex` | GET | - | 全量重建索引 |
| `/api/recategorize` | GET | `id`, `slug` | 修正文档分类 |

### 4.4 文档导入机制

**增量导入（默认）**
- 通过 `filepath + mtime` 判断文件是否变更
- 仅处理新增或修改的文件，保留已有数据
- 启动时自动执行

**全量重建**
- 清空所有数据后重新扫描导入
- 通过 `/api/reindex` 触发

**扫描范围**
1. `docs/` 子目录：按目录结构决定分类
2. 根目录 `*.md`：自动智能分类

### 4.5 智能分类规则

采用**双重匹配策略**，优先级从高到低：

1. **文件名关键词匹配** — 检查文件名是否包含分类关键词
2. **内容关键词匹配** — 取前 500 字内容，检查是否包含分类关键词
3. **兜底分类** — 未匹配则归入 `other`

内置 15 个分类规则：AI与机器学习、移动端开发、Java与JVM、数据库与存储、大数据与分布式、前端与Web、架构与设计、操作系统与底层、哲学与人文、管理与经营、数学与算法、面试与求职、工具与实践、教育与考试、网络与安全。

### 4.6 Markdown 渲染引擎

内置轻量级 Markdown → HTML 转换器，支持：

| 元素 | 支持状态 |
|------|---------|
| 标题（H1-H6） | ✅ 含锚点 ID |
| 代码块 | ✅ `<pre><code>` |
| 行内代码 | ✅ `<code>` |
| 无序列表 | ✅ `<ul>` |
| 有序列表 | ✅ `<ol>` |
| 表格 | ✅ `<table>` |
| 引用块 | ✅ `<blockquote>` |
| 分隔线 | ✅ `<hr/>` |
| 粗体/斜体 | ✅ `<strong>` / `<em>` |
| 链接/图片 | ✅ `<a>` / `<img>` |

## 5. 前端技术详解

### 5.1 技术选型

| 技术 | 说明 |
|------|------|
| 框架 | 无框架依赖，纯原生 JavaScript |
| 样式 | 纯 CSS，暗色主题 |
| 路由 | Hash 路由（`#/category/xxx`, `#/article/xxx`） |
| 状态管理 | 全局 `App.state` 对象 |

### 5.2 前端架构

```
App
├── state              # 全局状态
├── init()             # 初始化
├── bindEvents()       # 事件绑定
├── handleRoute()      # 路由处理
├── api()              # API 请求封装
├── renderHome()       # 首页渲染
├── renderCategory()   # 分类页渲染
├── renderArticle()    # 文章页渲染
├── doSearch()         # 搜索执行
└── 工具函数            # escapeHtml, highlightText, formatNumber
```

### 5.3 交互特性

| 特性 | 说明 |
|------|------|
| 快捷键 | `Ctrl+K` 聚焦搜索框 |
| 实时搜索 | 输入 300ms 防抖后自动搜索 |
| 分页 | 智能分页条（最多显示 7 页） |
| 移动端 | 侧边栏抽屉式菜单 |
| 返回顶部 | 滚动超过 400px 显示按钮 |
| 高亮 | 搜索结果关键词高亮显示 |

## 7. 配置说明

### 7.1 核心配置项（server.py）

| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| `PORT` | `8080` | 服务端口 |
| `BASE_DIR` | `web-app/` | 应用根目录 |
| `DATA_DIR` | `BASE_DIR/data` | 数据库目录 |
| `DB_PATH` | `DATA_DIR/docs.db` | 数据库文件路径 |
| `DOCS_SRC` | `BASE_DIR.parent` | Markdown 文件扫描根目录 |
| `DOCS_CATEGORIES_DIR` | `DOCS_SRC/docs` | 分类文档目录 |

### 7.2 添加新分类

编辑 `server.py` 中的 `CATEGORY_RULES` 列表：

```python
CATEGORY_RULES = [
    # (slug, 显示名, icon, [关键词列表])
    ("newcat", "新分类", "🆕", ["关键词1", "关键词2"]),
    # ... 其他分类
    ("other", "其他", "📁", []),
]
```
