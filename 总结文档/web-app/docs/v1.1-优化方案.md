## 3. 前端工程化（优先级：高）

### 3.1 模块化拆分

**问题**：`app.js` 单文件超过 800 行，职责混杂。

**方案**：
- 拆分为独立模块：
  ```
  static/js/
  ├── app.js          # 主应用入口（精简到 ~100 行）
  ├── router.js       # 路由管理
  ├── search.js       # 搜索相关逻辑
  ├── theme.js        # 主题切换
  ├── toc.js          # 章节导航
  ├── ui.js           # UI 组件（Modal, Toast, Dropdown）
  ├── storage.js      # localStorage 封装
  └── utils.js        # 工具函数
  ```
- 使用 ES6 Module (`type="module"`)，无需构建工具即可运行

### 3.2 构建工具引入（可选）

**问题**：生产环境加载未压缩的 JS/CSS。

**方案**：
- 引入 Vite 作为可选构建工具
- 开发时：直接使用 ES6 Module，HMR 热更新
- 生产时：`vite build` 打包压缩
- 保持核心零依赖，构建为可选步骤

### 3.3 类型安全

**问题**：纯 JS 无类型提示，重构易出错。

**方案**：
- 添加 JSDoc 类型注释
- 定义核心类型：
  ```javascript
  /**
   * @typedef {Object} Document
   * @property {number} id
   * @property {string} title
   * @property {string} category_name
   * @property {number} word_count
   */
  ```

## 4. 性能优化（优先级：高）

### 4.1 静态资源缓存

**问题**：每次刷新都重新加载 JS/CSS，无缓存控制。

**方案**：
- 后端：为静态文件添加 `Cache-Control` 响应头
- 文件名添加内容哈希（构建时）或版本号查询参数
- API 响应添加 `ETag` 支持条件请求

### 4.2 图片懒加载

**问题**：文章图片一次性全部加载，首屏慢。

**方案**：
- 使用 `loading="lazy"` 属性
- 自定义懒加载：IntersectionObserver 实现
- 占位符：低质量模糊图或纯色占位

### 4.3 路由预加载

**问题**：切换页面时按需加载数据，有延迟感。

**方案**：
- 鼠标悬停链接时预加载数据
- 首页加载完成后预加载常用 API 数据
- 预渲染首屏内容到 HTML

## 5. 数据管理（优先级：中）

### 5.1 数据导出导入

**问题**：收藏、阅读进度、搜索历史等数据绑定浏览器，无法迁移。

**方案**：
- 提供「导出数据」功能：将所有 localStorage 数据打包为 JSON 文件下载
- 提供「导入数据」功能：上传 JSON 文件恢复数据
- 数据格式版本控制，确保兼容性

### 5.2 阅读进度云同步（可选）

**问题**：多设备间阅读进度不同步。

**方案**：
- 后端新增 `user_progress` 表（基于设备指纹或简单 token）
- 自动同步阅读进度到服务端
- 切换设备时自动恢复进度

## 6. 用户体验（优先级：中）

### 6.1 移动端优化

**问题**：移动端部分交互不够流畅。

**方案**：
- 侧边栏滑动手势支持（左滑关闭）
- 搜索框自动聚焦时避免页面缩放（iOS）
- 底部固定导航栏（移动端）
- 触摸反馈优化

### 6.2 骨架屏加载

**问题**：数据加载时白屏或显示「加载中」文字。

**方案**：
- 为文章列表、文章详情设计骨架屏
- 使用 CSS 动画实现脉冲加载效果
- 首屏内容优先渲染

### 6.3 操作反馈优化

**问题**：收藏、删除等操作无明确反馈。

**方案**：
- 引入 Toast 轻提示组件
- 操作成功/失败动画反馈
- 撤销操作支持（如误删收藏）

### 6.4 键盘快捷键扩展

**问题**：仅支持 Ctrl+K 搜索。

**方案**：
- `?` 显示快捷键帮助面板
- `Esc` 关闭弹窗/返回上一页
- `j/k` 上下浏览文档列表（Vim 风格）
- `g` 快速跳转到首页

## 8. 技术方案详情

### 8.1 JS 模块化拆分示例

**router.js**：
```javascript
/**
 * 路由管理模块
 */
export const Router = {
  routes: {},
  
  register(path, handler) {
    this.routes[path] = handler;
  },
  
  navigate(path) {
    window.location.hash = path;
    this.handle(path);
  },
  
  handle(path) {
    const handler = this.routes[path] || this.routes['default'];
    if (handler) handler();
  }
};
```

**storage.js**：
```javascript
/**
 * 本地存储封装，带版本控制和命名空间
 */
const STORAGE_KEY = 'docblog_v1';
const STORAGE_VERSION = 1;

export const Storage = {
  get(key, defaultValue = null) {
    try {
      const data = JSON.parse(localStorage.getItem(`${STORAGE_KEY}_${key}`));
      return data !== null ? data : defaultValue;
    } catch {
      return defaultValue;
    }
  },
  
  set(key, value) {
    localStorage.setItem(`${STORAGE_KEY}_${key}`, JSON.stringify(value));
  },
  
  export() {
    const data = {};
    for (let i = 0; i < localStorage.length; i++) {
      const key = localStorage.key(i);
      if (key.startsWith(STORAGE_KEY)) {
        data[key] = localStorage.getItem(key);
      }
    }
    return {
      version: STORAGE_VERSION,
      timestamp: Date.now(),
      data
    };
  },
  
  import(backup) {
    if (backup.version !== STORAGE_VERSION) {
      throw new Error('版本不兼容');
    }
    Object.entries(backup.data).forEach(([key, value]) => {
      localStorage.setItem(key, value);
    });
  }
};
```
