## 第1章：ECS常见问题（一）——实例

### 核心论点
本章主要解决用户在购买、配置、连接及管理 ECS 实例过程中遇到的基础操作性问题。核心观点是：用户应根据业务需求选择合适的实例规格（企业级 vs 共享型），并掌握实例生命周期内的状态管理、网络连接及故障排查方法，以确保业务的稳定运行。

### 关键概念/事件
- **企业级实例 vs 共享型实例**：企业级实例采用固定 CPU 调度，性能稳定且有 SLA 保证；共享型实例资源争抢，性能波动大但成本低。
- **持久内存型实例**：兼具内存速度与持久性，可作为内存降低 TCO，或作为本地盘提供极致低延时 I/O，适用于 Redis 等场景。
- **抢占式实例**：通过竞价模式获取低成本算力，但存在被释放风险（市场价格高于出价或库存不足），适合无状态、容错率高的业务。
- **预留实例券 (RI)**：一种抵扣券，可抵扣按量付费实例账单并预留库存，分为可用区级（强一致性）和地域级（灵活性高）。
- **连接故障排查**：包括 Workbench 连接超时、VNC 黑屏、SSH/RDP 端口未开放、安全组规则配置错误等常见连接问题的诊断流程。

### 逻辑推演/叙事脉络
本章首先从**购买阶段**入手，解答如何选型、资源售罄处理及付款问题；接着深入**实例类型**，详细对比企业级、共享型、持久内存型及弹性裸金属服务器的特性与适用场景；随后聚焦**抢占式实例**与**预留实例券**，阐述其计费逻辑、释放机制及抵扣规则；最后转向**运维管理**，涵盖实例连接（Workbench/VNC）、升降配操作、实例安全管理及 Linux/Windows 系统的具体使用限制与故障修复。逻辑上遵循“选购 -> 选型 -> 计费优化 -> 日常运维”的用户使用路径。

### 经典金句/数据
> “企业级实例采用固定 CPU 调度模式。每个 vCPU 绑定到一个物理 CPU 超线程，实例间无 CPU 资源争抢，实例计算性能稳定且有严格的 SLA 保证。” (p.9)
> “抢占式实例的小时单价是在各个实例的小时（自然）初始时设定的，适用于整个小时。” (p.18)

## 第2章：ECS常见问题（二）——计费

### 核心论点
本章旨在澄清 ECS 及其关联资源（镜像、块存储、网络）的复杂计费规则，帮助用户优化成本。核心观点是：理解不同计费方式（包年包月、按量付费、抢占式）的适用场景及转换限制，合理利用节省计划、预留实例券和存储容量单位包（SCU），可在保障业务灵活性的同时显著降低云资源支出。

### 关键概念/事件
- **节省计划 (Savings Plans)**：承诺一定期限内的消费金额以换取折扣，分为通用型（灵活）和 ECS 计算型（折扣更高），支持叠加使用。
- **按量付费停机计费**：专有网络下启用“节省停机模式”可停止收取计算资源费用，但云盘、EIP 等仍计费；经典网络或未启用该模式则继续计费。
- **预留实例券 (RI) 抵扣逻辑**：优先匹配可用区、规格一致的实例；地域级 RI 支持可用区灵活性和实例大小灵活性（如 1 张大券抵扣多张小实例）。
- **镜像市场计费**：镜像市场镜像通常需单独购买，自定义镜像若基于付费镜像创建，使用时仍需支付镜像费用；包年包月镜像需与实例周期一致。
- **存储容量单位包 (SCU)**：预付费存储抵扣包，可抵扣 ESSD/SSD 云盘、快照及部分 NAS/OSS 费用，提高存储性价比。

### 逻辑推演/叙事脉络
本章从**账号与基础计费**问题出发，解释实名认证、发票开具及欠费影响；重点剖析**实例计费**，详细对比包年包月、按量付费、抢占式实例的费用构成、转换规则及停机计费差异；随后引入**成本优化工具**，深入讲解节省计划、预留实例券的购买、抵扣逻辑及灵活性应用；最后覆盖**附属资源计费**，包括镜像市场、块存储（SCU）、快照及网络带宽的计费细节与账单查询方法。整体逻辑围绕“基础规则 -> 核心资源计费 -> 优化手段 -> 附属资源计费”展开。

### 经典金句/数据
> “节省计划是一种折扣权益计划，您通过承诺在一定期限（1年或3年）内使用稳定数量的资源（以元/小时为单位衡量），来换取较低的按量付费折扣。” (p.54)
> “预留实例券用于抵扣按量付费实例的计算资源（vCPU 和内存）的账单，同时 Windows 类型的预留实例券还可以抵扣镜像的账单。” (p.75)

## 第3章：ECS常见问题（三）——镜像与快照

### 核心论点
本章重点阐述 ECS 数据备份与系统模板的核心机制——镜像与快照。核心观点是：快照是云盘在某一时间点的数据备份，主要用于数据恢复；镜像是包含系统盘数据的模板，主要用于创建新实例或更换系统盘。两者紧密关联（镜像基于快照创建），但应用场景不同，需根据数据安全性、迁移需求及跨地域部署策略合理使用。

### 关键概念/事件
- **快照与镜像的区别**：快照不可直接创建实例，仅用于数据恢复或创建镜像；镜像可直接创建实例，包含系统盘数据，支持跨地域复制。
- **自定义镜像**：基于实例或快照创建，可用于批量部署、系统迁移。注意：数据盘快照不能单独创建自定义镜像，必须包含系统盘。
- **镜像复制与共享**：自定义镜像不支持跨地域直接使用，需先复制；镜像可共享给其他账号，但存在数据泄露风险，且共享镜像被删除后无法重新初始化系统盘。
- **导入/导出镜像**：支持将本地虚拟机镜像导入阿里云，或将云上镜像导出到 OSS 进行本地测试或迁移，需注意许可证类型（BYOL vs Aliyun）。
- **快照容量与计费**：快照采用增量备份，但删除文件不立即减少快照容量（因文件系统元数据及块存储机制）；快照按量付费，无免费额度。

### 逻辑推演/叙事脉络
本章首先界定**镜像与快照的基本概念**及应用场景差异；接着深入**自定义镜像**的生命周期管理，包括创建、查看、卸载数据盘、跨地域复制及共享风险；随后探讨**镜像市场**相关议题，如商业化镜像的购买、退款、包年包月镜像的使用限制；最后聚焦**快照技术细节**，涵盖快照容量计算、删除策略、自动快照设置、回滚云盘操作及与 OSS 的关系。逻辑上从“基础定义”到“高级操作（复制/共享）”，再到“底层机制（容量/回滚）”。

### 经典金句/数据
> “镜像可直接用来创建 ECS 实例，而快照不可以。” (p.7)
> “删除文件操作相当于在需要删除的文件头部做删除标记，并不会减少云盘本身的空间占用……因此，您看到快照容量比文件系统内展示的数据量要大。” (p.46)

## 第4章：ECS常见问题（四）——块存储，安全，网络，运维与监控

### 核心论点
本章涵盖 ECS 底层存储、网络安全、网络配置及日常运维监控四大维度。核心观点是：高性能业务需选择匹配的块存储类型（如 ESSD）并正确挂载；网络安全依赖安全组的精细化规则配置；网络性能受带宽类型、IP 类型及底层架构影响；高效运维需利用云助手等自动化工具，并建立定期备份与监控机制。

### 关键概念/事件
- **块存储类型与性能**：ESSD 云盘提供百万级 IOPS，性能随容量线性增长；云盘只能挂载到同一可用区的实例；支持扩容但不支持缩容。
- **安全组机制**：虚拟防火墙，状态检测。入方向/出方向规则总数上限 200 条/组。优先级数值越小越高，拒绝策略优先于允许策略。
- **网络性能与带宽**：入网带宽免费，出网带宽计费。按固定带宽适合流量稳定业务，按使用流量适合波峰波谷明显业务。VPC 内网通信低延迟。
- **云助手 (Cloud Assistant)**：原生运维工具，无需 SSH/RDP 即可批量执行命令。支持 Windows/Linux，需安装客户端并确保护进程正常运行。
- **运维最佳实践**：定期创建快照备份；利用云监控识别异常流量；Linux 数据盘需配置 `/etc/fstab` 实现开机自动挂载；避免在实例内直接修改内核参数导致启动失败。

### 逻辑推演/叙事脉络
本章按技术领域划分为四个板块。**块存储**部分详解云盘类型、挂载/卸载、扩容、快照关联及性能测试；**安全**部分聚焦安全组规则配置、优先级逻辑及主机违规处罚；**网络**部分涵盖带宽计费、IP 地址管理、DNS 解析、跨地域通信及常见连通性问题；**运维与监控**部分介绍云助手的使用、故障排查日志路径及网站托管的日常维护建议。整体逻辑遵循“基础设施（存储/网络）-> 安全防护 -> 自动化运维”的技术栈层次。

### 经典金句/数据
> “安全组是一种虚拟防火墙。用于设置单台或多台云服务器的网络访问控制，它是重要的网络安全隔离手段。” (p.68)
> “ESSD 云盘的性能与容量线性相关，容量越大性能越高，相比 SSD 云盘有大幅的性能提升。” (p.55)
> “阿里云 ECS 云盘使用了分布式文件系统作为云服务器的存储……为了避免当系统资源不足时进一步降低 ECS 云磁盘的 I/O 性能，所以 Windows 系统实例默认没有启用虚拟内存，Linux 系统实例默认未配置 Swap 分区。” (p.38)
